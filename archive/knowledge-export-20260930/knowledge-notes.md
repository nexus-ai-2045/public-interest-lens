# 保存国会資料の文書化と限定全文検索

既存の3議案と国立国会図書館（`NDL`）の附録1件を有限入力とする。新しい資料取得・人物評価・公開・モデル導入は行わない。ノートは表示用の派生物であり、原本や確認ノートを正本として維持する。

## 書き出し

`scripts/export_knowledge_notes.py` は`Python`標準ライブラリだけを使う。保存済み要約、確認ノート、取得記録、原本の対応とハッシュ・時差付き観測時刻を検証する。資料参照の親ディレクトリ脱出、シンボリックリンク、ジャンクションを拒否する。原本の提出日で2022-09-24〜2026-09-24を判定し、取得日で代用しない。

最初に、元リポジトリと専用`Projects`作業場所のノート出力先を明示して差分を確認する。

```text
python scripts/export_knowledge_notes.py export --source-root <元repo> --output-dir <ノート出力先> --state-dir <元repo内の.local/knowledge/出力先専用状態ディレクトリ> --dry-run
```

`--dry-run`を外すと資料一覧、`references/`内の3資料ノート、初回だけ考察・疑問ノートを生成する。複数出力先に投影する場合は状態ディレクトリを分ける。本文は出力先に依存しない。状態の既定は元リポジトリの`.local/knowledge/diet-export-state`。

生成対象に未知の既存ファイルや人の編集があると、書込み前に停止する。考察ノートは上書きしない。書込みはファイルごとに一時ファイルと置換を用い、全読み戻し後だけ状態を更新する。途中失敗は今回生成した内容だけを戻す。書込後に別の担当が編集した内容は保全し、`rollback incomplete`として失敗を報告する。その場合、元の状態を根拠に再生成を自動継続せず、残った編集を人が照合する。

## 出典照合と検索

```text
python scripts/export_knowledge_notes.py resolve --source-root <元repo> --material-id bill-221-41
python scripts/export_knowledge_notes.py query --source-root <元repo> --output-dir <ノート出力先> --helper-path <既存search_obsidian_memory.py> --query 有償化
```

原本照合は登録・ハッシュ・観測時刻を再検証し、非公開原本パスと引用行を返す。保管庫（`Vault`）ノートには原本の個人絶対パスや原本コピーを入れない。

検索は既存の`shared/scripts/search_obsidian_memory.py`へ`references/`だけを渡す。3資料の完全一致ファイル名と検索結果の行・本文を照合し、公式出典、ハッシュ、引用位置、観測時刻を添える。考察、附録、未知ノートは検索根拠に使わない。ヒット0件は`unknown`。文字列一致なので、質問の言い換えで漏れる。ヒットがあっても、そのまま質問への回答を確定しない。回答するチャットは根拠の記載範囲を読んで、未取得の個人賛否・政策効果を補完しない。

## 成功件数と未達範囲

保存レコード4件、読める政策資料本文3件、読める発言本文0件、個人行動評価の確認済み根拠0件を別々に表示する。空の要旨、メタデータのみ、提出日不明、期間外は保留し、本文件数を増やさない。`NDL`附録は欠落テスト用として維持する。成立法・提出法案・修正案・個人別投票結果・政策効果は未確認。

知識表示の完成と収集経路全体の受入を区別する。`NDL`経路は追加取得の別承認後、目的・期間に合う読める発言本文を少なくとも1件取得し、出典・日時・観測時刻・ハッシュ・引用位置を揃えるまで未達。

## 回帰検証

`python -m unittest discover -s tests`で実行する。有限入力、日時と出典対応、ハッシュ、要約正本束縛、保留判定、`dry-run`書込ゼロ、同入力再生成、人編集・衝突保護、途中書込失敗、読み戻し失敗、別担当の編集保全、出力先別状態、原本照合、限定検索を検証する。テスト資料は一時ディレクトリの架空本文を用い、実資料や個人パスをテストへ持ち込まない。
