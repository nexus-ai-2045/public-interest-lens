# 議員連盟の名簿（memberships.csv）

列：議連名、氏名、役職、分野（その議連が推進する所管省庁）、出典種別（公表名簿・政治資金収支報告書・会議録）、出典URL、取得日。
- 名簿が公表されていない議連は足さない。推測で埋めない。出典URLが無い行・分野が空の行は判定が読まない。
- 議連名の候補は、政治資金収支報告書の関係団体（団体名に「議員連盟」「議連」を含むもの）と国会会議録の発言から機械的に拾える。

## 会議録からの拾い方（scripts/fetch_diet_leagues_kokkai.py）
「私は◯◯議員連盟の会長（事務局長・幹事長・副会長）を務めて」と本人が述べた発言だけを機械で拾う（5,516発言から109件、整形後55件）。`kokkai-candidates.csv` は候補の全体（分野が決まらないものは判定に読まれない）。分野がキーワード表で決まった5件だけ `memberships.csv` に入れた（出典種別＝会議録、出典URLは該当発言）。古い発言も含むので、現職の加盟とは言わない。
