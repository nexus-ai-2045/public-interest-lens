# コロナ対応の法律に結びつく支出の規模（一次資料）

covid-benefit-v1 の入力。官公庁の資料から読み取った金額を、法律ごとに項目として残す（取得日 2026-10-29）。

- `spending.csv`：項目ID（`法律ID#番号`）・金額（円）・区分（予算額／決算・実績額／見込み／上限）・年度・法律に直接結びつくか・出典URL・原文の抜粋・備考。
- `params.csv`：乗数・限界消費性向・国保の差押世帯数など、換算に使う値と出典。
- 数字は取得したページ・PDFに書いてあったものだけ。記憶からは入れていない。独立した2系統目の照合で、使った項目は金額と意味が一致（照合で意味を確認できなかった `閣法-201-59#9` は計算に使わない）。
- 閣法-203-1（ワクチン）は成立法の台帳に無く macro.csv の対象外。規模だけここに残す。
- 計算は `python3 scripts/build_covid_benefit.py`。式は docs/計算式.md の「コロナ対応の法律の費用便益」。
