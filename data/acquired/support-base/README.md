# 議員の支持基盤（団体の公表された推薦・支持・支援）

入れてよいもの：団体自身（労働組合・業界団体・政治連盟など）または選挙管理機関が公表した、議員・候補者への推薦・支持・組織内候補・支援の記録。1行につき公表の一次資料の URL が要る。
入れないもの：有権者個人の属性・投票先、報道の推測、宗教・出自・国籍など個人の属性、出典の無い噂。

列：人物ID（data/derived/person-ids/persons.csv）・氏名・団体・団体区分（労働組合／業界団体／政治連盟／その他）・関係（推薦／支持／組織内候補／支援）・年・出典URL・確度（`原本照合済み` で始まる行だけ使う。AI 2系統の一致と機械の照合、設計決定0007）。
取り込みは scripts/build_support_base.py。まだ行は無い（取得は後の PR。入った分だけ表に出る）。
