# 圧力団体・ロビー活動の記録（positions.csv）

公表された声明・要望・陳情・ヒアリング出席・審議会委員・意見公募への意見・署名運動だけを、1行1事実で足す。
列：団体名、団体区分（業界団体・運動団体・メディア・議員連盟・自治体・労働団体・その他）、分野（所管省庁）、法律ID、立場（推進／反対）、行動種別、要旨、出典URL、確度（「原本照合済み」で始まる行だけ判定が読む。2系統一致、設計決定0007）。
- メディアは、放送・新聞・出版の業界としての要望や審議会での発言だけ。記事・番組の論調には点も印も付けない。
- 属性・思想では記録しない。出典URLが無い行は判定が読まない。
- 足し方：審議会・検討会は data/acquired/blocking-actors/2_shingikai/、ホットライン・ヒアリングは 1_regulatory-requests/ に既にある原本照合済みの行から、2系統照合（設計決定0007）を通したものを写す。
