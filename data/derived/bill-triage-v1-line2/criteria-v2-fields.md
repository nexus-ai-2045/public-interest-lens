# bill-triage 系統2 の基準への追加：新分野（field-expansion-v1）

`criteria.md`（8分野・170本のとき固定）は変えません。この文書は、`docs/提案/分野の拡張-v1.md` の新分野を足したときに、系統2が新しい法律（約648本の見込み。施行日の取得後に評価へ入る）へラベルを付けるための追加の基準です。ラベルを付ける前に固定し、付けたあとで変えません（変えるときは版を上げ、全件を付け直します）。

**この文書は基準だけです。ラベルは付けていません。** 新しい法律の `labels.csv` の行は後の工程で付けます。付くまでは、系統2の行が無い法律は `bill-triage-v2` の一致の表で「系統2の振り分けが無い」となり、保留のまま評価に入りません（これまでと同じ扱い）。

## 独立性と範囲

- 系統1（`data/derived/bill-triage-v1/triage.csv`、`data/derived/bill-triage-v2/labels-line1.csv`、`data/derived/field-expansion-estimate/estimate.csv`）は、系統2のラベルを書いてコミットするまで開きません。見積り `estimate.csv` は系統1の側の語の当てはめなので、見ません。
- 入力は一次資料だけです：題名と付託委員会（`data/acquired/bill-census-full/enacted.csv`）。
- 範囲：`enacted.csv` のうち、`criteria.md` の170本・`labels.csv` の349本にまだ行が無い法律。系統2の役目は、種類と分野が系統1と一致するかを独立に確かめることです。
- 限界：系統1と同じ系列のモデルが、別のセッションで付けます。

## 1. 種類

`criteria.md` の1と同じです（組織手続／定型改正／新規／実質改正を、上から順に当てる）。

## 2. 分野

8分野（`criteria.md` の2の表）に**はっきり当たるなら、これまでどおり8分野**にします（既存優先）。8分野のどれにも当たらないときだけ、次の9つの新分野のどれかに当たるかを見ます。主題が2分野にまたがるときは、題名の最初に出る主題の分野です。

- 同じ位置で2つの新分野の主題が重なって決められないときは、推測せず、分野に「保留」と書きます。

## 3. 指標（分野が新分野のときだけ）

新分野の指標は、分野ごとに1本です（産業の付加価値。`分野の拡張-v1.md` の3の表の「指標名」）。主題が**直接**の語に当たるなら指標名そのまま、**代理**の語に当たるなら指標名の末尾に「（代理）」を付けた別の指標にします。教育・医療・福祉・住宅・不動産・文化・娯楽・生活サービスは代理の語しか無いので、常に「（代理）」付きです。

| 分野 | 指標（直接） | 指標（代理） |
|---|---|---|
| 農林水産 | 農林水産業の付加価値 | 農林水産業の付加価値（代理） |
| 建設 | 建設業の付加価値 | 建設業の付加価値（代理） |
| 住宅・不動産 | （なし） | 不動産業の付加価値（代理） |
| 教育 | （なし） | 教育の付加価値（代理） |
| 医療・福祉 | （なし） | 保健衛生・社会事業の付加価値（代理） |
| 製造業 | 製造業の付加価値 | 製造業の付加価値（代理） |
| 商業 | 卸売・小売業の付加価値 | 卸売・小売業の付加価値（代理） |
| 専門サービス・研究開発 | 専門・科学技術、業務支援サービス業の付加価値 | 専門・科学技術、業務支援サービス業の付加価値（代理） |
| 文化・娯楽・生活サービス | （なし） | その他のサービス業の付加価値（代理） |

代理の指標は「参考」扱いです（貢献・悪影響と読まず「上昇／低下」と書き、合計に入れず、公開せず、議員への配分に使わない）。

## 4. 判定と出力

- 評価対象外：種類が定型改正か組織手続、または分野が対応表なし。
- 評価対象：それ以外。
- 出力は `criteria.md` と同じ列の `labels.csv` に、入力の順（`enacted.csv` の順）で行を足します。付けた行の分野の列には、8分野・9つの新分野・対応表なし・保留のどれかを書きます（`bill-triage-v2` は、分野の列が定義にない値のときだけ保留にし、分野そのものは題名の語で決め直します）。
