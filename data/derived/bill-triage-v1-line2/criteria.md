# bill-triage-v1 振り分け・系統2（設計決定0007の2系統目）の基準

この基準は、ラベルを付ける前に固定したものです。ラベルを付けたあとで変えません（変えるときは版を上げ、全件を付け直します）。

## 独立性と範囲

- 系統1（`data/derived/bill-triage-v1/triage.csv` の結果・種類・分野・指標・A_*・B_* の列）は、系統2のラベルを書いてコミットするまで開いていません。
- 入力は一次資料だけです：題名と付託委員会（`data/acquired/bill-census-full/enacted.csv`）。語彙と判定の考え方は `data/derived/bill-triage-v1/spec.md` に従います。
- **範囲**：施行日を原文で確定できた170本（`data/acquired/enforcement-dates/enforcement.csv` の施行日が空でない行）。この170本は系統1が「評価対象」とした法律の中から選ばれているため、系統2の役目は「評価対象・分野・指標が系統1と一致するか」を独立に確かめることです。系統1が評価対象外とした法律（約3,200本）は付けていません。
- 限界：系統1と同じ系列のモデルが、別のセッションで付けています。

## 1. 種類（どれか1つ）

上から順に当て、最初に当たったもの。

1. **組織手続**：題名に「設置法」「定員」「整備に関する法律」「整備等に関する法律」（関係法律の整備）、「機構法」「公団法」「公庫法」などの組織の設立・廃止・再編だけを述べるもの、「手続」「事務」の整理。ただし、組織の業務の範囲（何をするか）を広げ・変える改正は実質改正。
2. **定型改正**：毎年の税法の定例改正（「所得税法等の一部を改正する法律案」「地方税法等の一部を改正する法律案」など）、給与法（一般職・特別職・裁判官・検察官・防衛省職員の給与）、期限の延長だけ（題名に「期限」「延長」）、名称・字句の整理だけ。
3. **新規**：題名が「…の一部を改正する法律案」でなく、廃止・整備の法律でもないもの。
4. **実質改正**：上のどれにも当たらない改正。

## 2. 分野（どれか1つ）

題名の主題で決め、迷うときだけ付託委員会を補助に使う。8分野のどれにもはっきり当たらなければ「対応表なし」。

| 分野 | 題名の主題 |
|---|---|
| 金融 | 銀行・信用金庫・協同組織金融・保険・証券・金融商品・金融機関・預金保険・貸金・融資・信用保証・資産の流動化・金融の再生と健全化・政策金融機関（公庫・政策投資銀行など） |
| 交通・移動 | 鉄道・道路運送・自動車・航空・空港・港湾・船舶・海上運送・旅客の輸送 |
| 宿泊・観光 | 観光・旅行業・通訳案内・宿泊・旅館・ホテル・観光施設区域 |
| 通信・ネット | 電気通信・電波・放送・郵便事業（通信）・情報通信・インターネット・サイバーセキュリティ・電話 |
| 半導体・電子 | 半導体・電子部品・情報処理の産業 |
| エネルギー | 電気事業・ガス事業・石油・原子力・再生可能エネルギー・省エネルギー |
| 労働市場 | 労働基準・労働者派遣・職業安定・雇用・賃金・職業能力開発・労働契約 |
| 行政のデジタル化 | 行政手続のオンライン化・電子申請・デジタル手続・行政の情報システム |

- 税・財政一般、農林水産、医療・介護・年金、教育、防衛、司法、選挙、外交、環境（エネルギー以外）、住宅・都市は「対応表なし」。
- 主題が2分野にまたがるときは、題名の最初に出る主題の分野。

## 3. 指標（分野が8分野のときだけ。分野ごとに上から順に当て、当たらなければ既定）

| 分野 | 条件 → 指標 | 既定 |
|---|---|---|
| 金融 | 預金保険・破綻・不良債権・金融機能の再生や早期健全化・債権の管理回収 → 不良債権比率。倒産・再生手続・中小企業の信用保証 → 企業倒産件数 | 貸出残高 |
| 交通・移動 | 船員・運転者・乗務員の労働 → 就業者数。運送・鉄道・航空の「事業」の規制や会社の形態 → 旅客輸送の付加価値 | 利用件数 |
| 宿泊・観光 | 旅館・ホテル・宿泊施設の基準 → 客室数。宿泊業の事業者の規制 → 宿泊業の付加価値 | 宿泊者数 |
| 通信・ネット | ネットワーク・基盤の整備（ブロードバンド・光ファイバ・高度情報通信ネットワークの整備） → ブロードバンド普及率。電子商取引・インターネット上の取引 → ネット企業の時価総額 | 通信業の付加価値 |
| 半導体・電子 | 輸出・国際競争力 → 世界輸出シェア | 生産額 |
| エネルギー | 再生可能エネルギー・原子力・電源の構成 → 発電構成。省エネルギー・エネルギーの使用の合理化 → エネルギー効率 | 電力価格 |
| 労働市場 | 最低賃金・賃金・労働時間・労働基準 → 賃金。職業能力開発・職業訓練 → 労働生産性 | 雇用の流動性 |
| 行政のデジタル化 | 手続の簡素化・迅速化（電子化を述べないもの） → 行政手続きの時間 | 電子申請率 |

## 4. 判定

- 評価対象外：種類が定型改正か組織手続、または分野が対応表なし。
- 評価対象：それ以外。
- 理由：短く1文。

## 出力

`labels.csv`：id, 題名, 付託委員会（衆／参）, 系統2_種類, 系統2_分野, 系統2_指標, 系統2_判定, 系統2_理由。入力の順（`enforcement.csv` の順）で170行。
