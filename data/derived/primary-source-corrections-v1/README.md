# 一次資料で直したサイトの値（primary-source-corrections-v1）

振り分け（bill-triage）と経済の区分（econ-relevance）の AI の記録は書き換えない。一次資料の読み直しで合わないと分かった値だけを `corrections.csv` に置き、`scripts/primary_source_corrections.py` が1か所で読む。読み直してサイトの値が正しかった項目は `confirmed.csv`。

## 項目

| 項目 | 値 | 効くところ |
|---|---|---|
| 類型 | 新規・実質改正・定型改正・組織手続 | 全法律の結果の「種類」、定例の規則 RT8、種類による対象外 |
| 経済に効くか | 経済に効く・制度・判定不能 | 制度：評価対象外。経済に効く：題名の型・定例の規則などに当てない。判定不能：定例の規則で効果なしに確定させない |
| 分野 | 読み直しの指示文の「主な産業分野」の並び（`FIELDS`） | 参考額の産業と曝露ランキングの群（`macro-v1`、題名でそろえる処理・結び直しより強い）、全法律の結果の「分野」。個別の額の法律は、額が振り分けの分野の産業で計算してあるので、直した分野で計算し直すまで額を付けない（経路「市場（一次資料で分野を直した）」、公開ランキングも額なし） |

## 行の出どころ（「記録」の列）

1. #208 の6本：`evaluation-ledger-v1/reverification-v1/`。
2. 誤りの型の全件検査の候補 582 本の読み直し：`reread-v1/`（README に手順と結果）。規則 K2 の 88 本は `error-type-check-v1/README.md（K2）`。
3. 抜き取り検証の2回目（`evaluation-ledger-v1/sample-v2/`、#223）の訂正候補 49 本（60 項目）。読むのは写しの `sample-v2-candidates.csv`（#223 の決着の時点）。`sample-v2/correction-candidates.csv` は今のサイトの値でまだ合わない項目だけに作り直されるので、それを読むと訂正が入るたびに候補と訂正が一緒に消える。決め方（Haiku 2系統→Sonnet の裁定→Opus）は `scripts/resample_verification.py` の resolve にあり、ここでは繰り返さない。`scripts/resolve_error_candidates.py` の `merge_sample` が足すのは次の3つ：
   - 読み直し（2）と重なる 19 項目の突き合わせ。18 項目は同じ値で、行の「判定者」に「抜き取り検証2回目でも同じ値」を書き足した（独立な2回目の読み）。閣法-183-7 の類型だけが割れた（読み直し 新規、2回目 組織手続）ので、Opus が一次資料で組織手続と裁定した（`sample-v2-rulings.json`）。
   - 制度と決めた項目への `unread()`（読み直しと同じ規則）。制度と読んだ記録の判断が読めていない条文に懸かる 5 項目は「判定不能」にした（閣法-183-7・閣法-155-46・衆法-197-6・閣法-171-44・閣法-211-46）。
   - 連鎖（`sample-v2-cascade.csv`）：類型の訂正で効果なし（定例）から参考額に移り、新しく分野を照合した 2 本（衆法-163-21・閣法-216-1）。2系統が一致した値（労働市場）を使う。
   - 退けた候補：衆法-201-10（給付の差押禁止）の「制度」は Opus が一次資料で退け、サイトの値（経済に効く）のまま `confirmed.csv` に置いた（`sample-v2-rulings.json` の `退ける`）。同じ型の5本は `covid-benefit-v1` が帰属の幅で額を出しており、1本だけ制度にすると扱いが割れるため。

## 抜き取り検証2回目の訂正後（109 本、#223 の判定し直しの仕組みで、訂正を当てた台帳の値から数えた）

- 標本2の不合格 60 本のうち、訂正（読み直し）で合格 28・参考に下げた 31・不合格のまま 11。不合格のままのうち 10 本は、#223 の規則で2系統が割れて裁定者1人だけが決めた項目（「割れ（独立の確認待ち）」、`sample-v2/split-queue.json`）で、この訂正表の候補ではない。訂正表の候補で不合格のまま残るのは **1 本**（閣法-211-46、下）。数は `check_design_consistency.py` の条件3（`build_evaluation_ledger.py build` → `resample_verification.py resolve` → `report` の後）。
- 訂正候補のまま残る 6 本：
  - 判定不能 5 本（閣法-183-7・閣法-155-46・衆法-197-6・閣法-171-44・閣法-211-46）。読み手と裁定は制度としたが、その判断が読めていない条文に懸かる。不合格のままの 1 本は額の無い閣法-211-46 で、残り 4 本は額を参考に下げてある。本法まで読む当て直し（#228）に回す。
  - 衆法-201-10。Opus が候補を退けた（上の「退けた候補」）。額は参考に下げてある。
- 産業の節が無い分野（労働市場・行政のデジタル化）に直した法律は、全産業（_T）の差で測る。分野の欄は直した分野のまま、指標は「全産業の実質付加価値」。
