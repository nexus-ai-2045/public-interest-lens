# benefit-v1 目的の分類・系統2（設計決定0007の2系統目）の基準

この基準は、ラベルを付ける前に固定したものです。ラベルを付けたあとで変えません（変えるときは版を上げ、全件を付け直します）。

## 独立性

- 系統1（`app/src/benefit-classification.ts` の系統A・系統Bと、その一致の結果、`data/derived/benefit-v1/classification.csv`、報告書の分類の表）は、系統2のラベルを書いてコミットするまで開いていません。
- 使った入力は一次資料だけです：法律の題名（`data/derived/loss-v1/loss.csv` の id・題名・指標の列）と、第1条の原文（`data/acquired/law-purposes/purposes.csv`）。
- 読んだのはラベルの語彙と判定の考え方（`data/derived/benefit-v1/spec.md`、提案 2-4 の対応表、`app/src/benefit-rule.ts` の `BENEFIT_KINDS`）だけです。
- 限界：系統1と同じ系列のモデルが、別のセッションで付けています。`spec.md` の本文には系統1の一致の数と不一致の3本の名前が書かれており、基準を読む過程でそれを目にしました。ラベルはこの基準だけで機械的に付けています。

## 入力の選び方

1. 対象は `loss-v1/loss.csv` の全行（法律ごと1行）。
2. 法律ごとに、`purposes.csv` の同じ id の行から、改正対象の法令ごとに「施行時」の版（取得状況＝取得、原文あり）を使い、無ければ「現行」の版を使う。
3. どの改正対象にも原文が無ければ、ラベルは `原文なし`（種類は空）。
4. 第1条の見出しが「目的」「趣旨」を含まない（例：禁止規定）なら、その法令からは種類を取らない。
5. 改正対象が複数あれば、法令ごとに付けた種類の和集合を法律の種類とする。

## 目的として数える句

- **数える**：直接の目的（「…により（によつて）…を図り」「…を確保し」）と、最終の目的（「もって（もつて）…に資する／寄与する／を目的とする」）。株式会社・機構の法律の「…を目的とする株式会社とする」も同じ。
- **数えない**：背景の句（「…に鑑み」「…にかんがみ」）、他の法律の題名の引用、決まり文句の「公共の福祉」（「公共の福祉の増進」だけでは種類を付けない）、手段だけの句（「…を定め」「…を設置し」）。
- **例外**：目的の句が成果を何も挙げず、体制・手続を定める・行うことだけを目的にしている場合に限り、背景の句（「…に鑑み」）の成果を目的とみなす。背景の句も無ければ種類は空。
- 「趣旨」の条で、目的の句が無く、税・交付金などの仕組みを定めることだけを述べる場合は、その仕組みから「移転」だけを付ける。

## 種類の当てはめ（句 → 種類）

| 句の内容 | 種類 |
|---|---|
| 国民経済・経済社会・地域経済の発展・活性化・成長、産業の国際競争力、需要の拡大、資金調達・資金供給・金融の円滑、貯蓄・資産形成、市場の機能・価格形成・流通の円滑、資源（電波など）の能率的な利用、観光の振興 | 経済（内包） |
| 海外の事業・海外の需要から我が国の事業者が得る収益（国内の付加価値の外の所得） | 経済（付加価値の外） |
| 消費者・顧客・投資者・預金者・利用者の保護 | 消費者保護 |
| 信用の維持、信用秩序・金融システムの安定、金融機関の健全性・監督の適正 | 金融の安定 |
| 事故・災害の防止、生命・身体の安全（犯罪によらないもの） | 安全（事故） |
| 犯罪・不正アクセス・サイバー攻撃の防止、サイバーセキュリティの確保、「国民が安全で安心して暮らせる社会」（犯罪・攻撃を防ぐ文脈のとき） | 安全（犯罪） |
| 個人情報・プライバシーの保護 | プライバシー |
| 環境の保全、温室効果ガスの削減 | 環境 |
| 手段として税・交付金・納付金・補助金・財源の特別の措置を設ける。財政の改善 | 移転 |
| 上のどれにも当たらない成果（例：安全保障・国際平和、障害者等の自立・福祉、教育、文化） | 対応表外（内容の語） |

- 1つの句が2つの行に当たるときは、両方を付ける。
- 政府の出資・資金供給そのものは「移転」に数えない（税・交付金・補助金・財源の措置だけ）。
- 「公平」「公正」が手段の形容（「取引等を公正にし」「公平且つ能率的な利用」）として出てくるときは、別の種類を立てない。

## 向きの矛盾（directionConflict）

- 損失額の指標（`loss.csv` の指標の列）を、目的の句が明示的に「減らす・抑える・制限する」ことを狙う場合だけ「抑える」。例：指標が貸出残高で、目的が貸付の抑制・制限。指標が宿泊者数で、目的が旅客の抑制。
- 見出しが目的・趣旨でない条（禁止規定）からは判定しない（「なし」）。
- それ以外は「なし」。

## 出力

`labels.csv`：id, 題名, 指標, 使った第1条, 系統2_種類（「・」区切り、空は目的の記述なし）, 系統2_向きの矛盾（抑える／なし）, 引用（判断に使った句）, 注記。
