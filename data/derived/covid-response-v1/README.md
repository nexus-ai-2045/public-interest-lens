# コロナ対応の法律の振り分け（covid-response-v1）

`labels.csv`：2020年以降に施行した法律385本を「コロナ対応か」で振り分けた表（設計決定0014 の決定4）。

- コロナ対応（はい）＝新型コロナの流行、またはその影響（経済・生活・雇用・資金繰り・税・医療・行政手続き）への対応が、その法律の**主な目的**のもの。目的の一部にコロナが出てくるだけのものは「いいえ」。
- 決め方：法律の題名と概要（laws-detail の「何をする」「目的」）を Haiku 2系統が別々に判定 → 割れたものを Sonnet が判定 → 「はい」の一覧を Opus が点検（1本を外した）。振り分けで漏れた5本は点検役が直接判定。各行の「決め方」に記録。
- 使い道：`scripts/build_macro_amounts.py` が「はい」の法律に全体指標の参考の額を付けず、理由を出す。比べるべきは「コロナはあったが、その法律が無かった場合」で、定説では落ち込みを和らげる向き（便益）。額は財政支出の一次資料を取ってから付ける。
- 列：id・題名・コロナ対応（はい／いいえ）・種類・理由・決め方。
