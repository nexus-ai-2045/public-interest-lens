# 振り分けの当て直し（primary-triage-v1、2026-11-19）

測る側の法律（到達点が評価対象外でない 2,554 本、`all/targets.csv`）の **類型・経済に効くか・主な産業分野** を、題名ではなく一次資料（衆議院の議案本文＋国会会議録）から決め直す手順と、その記録。
根本原因の裁定（プロジェクトの共有フォルダ `analysis/抜き取り不合格の根本原因_2026-11-19.md`）の 1-2 で、誤りの主因とされた「入力が題名だけ」「割れを空・経済全体・判定不能のまま後段へ流す」を直す。

## 手順（`scripts/primary_triage.py`。AI はスクリプトからは呼ばない）

1. `targets`：台帳（`evaluation-ledger-v1/ledger.csv`）から測る側を全件 → `all/targets.csv`。サイトの主張（類型、到達点で読む経済に効くか、額のある到達点の分野）を一緒に写す。
2. `fetch --set S`：議案本文と会議録を取り、1本1ファイル `.local/primary-triage-v1/sources/{id}.txt`（Git に入れない。原資料は `fetch_law_source.py` が外部資料として登録）。
3. `prompts --set S`：読み手の指示文（`prompt-v1.md`）を1本×2系統ぶん書く。
4. 読み手：Haiku（effort medium）を1本1件で並行。**系統A は議案本文を先に、系統B は会議録を先に**読む（同じ入力の2系統を独立とみなさない、への対策）。結果を `S/lineA.json`・`S/lineB.json` に集める。
5. `queue --set S`：次の項目を Sonnet の裁定に回す。2系統が割れた／どちらかが判定不能／どちらかの確信が低／2系統が一致してもサイトの値と違う（**値の変更**）。サイトに値が無い項目（類型の空、額に使っていない到達点の分野）は、2系統が一致すれば埋めるだけで裁定に回さない。
6. 裁定者：Sonnet が `prompt-adjudicate-v1.md` で、サイトの値と2系統の判定と理由を見て一次資料で決める。`S/rulings.json` に集める。
7. `apply --set S`：`labels.csv` に書く（`primary-source-corrections-v1/corrections.csv` と同じ列。判定者・指示文の版・記録の場所つき）。類型・分野が判定不能なら行を置かない。経済に効くかの判定不能は行に残す（後段で「判定済み」に数えない）。
8. `estimate`：試走の実測（`pilot/usage.json`）から全件の費用と所要時間 → `pilot/estimate.json`。

## 後段へのつなぎ（別の PR）

- `labels.csv` は、`corrections.csv`（抜き取り検証の読み直し）より下、AI の振り分け（bill-triage・econ-relevance・ai-field）より上の順位で読む。
- 参考の額・曝露ランキングの群・個別の額に入る条件を「経済に効くと判定済み」にする（今は「除外に当たらなければ全部」で、参考額 1,930 本中 1,296 本は経済に効くかを一度も聞いていない）。
- 分野は一次資料の値を、題名の語表（D1）・題名だけの AI・同じ題名へのそろえ・結び直しより優先する（#226 の `source_fields` の順位に、この表を足す）。
- 全件（2,554 本）の実行は、費用と所要時間をねくに確認してから（`--set all`）。

## 試走（`pilot/`、10 本、種 20261120）

到達点の層で抜いた（参考額で経済に効くかが空 4、参考額で判定済み 1、効果なし（定例）2、保留 1、測定できない 1、額 1）。初回の抜き取り（`sample.csv`）と `corrections.csv` に載る法律は除いた。結果と見積もりは下（`pilot/` の各ファイル）。

### 結果（測定。定義：試走の 10 本、項目は類型・経済に効くか・分野の 30）

- 一次資料：10 本とも議案本文と会議録を取れた（直列で 22 秒）。読み手 20 件は全件 JSON を返した。
- 2系統の一致：30 項目中 30 で系統A・Bが一致（割れ 0、判定不能 0）。確信「低」は 0、「中」は 4 本（議案本文が資料の先頭で切れていた）。
- 裁定に回したのは 3 本・5 項目（すべて「値の変更」）。裁定の結果：
  - 閣法-146-65（一般職給与法、サイトは効果なし（定例））：福祉職俸給表の新設と期末手当の支給割合の変更があり、定例だけではない → 類型は実質改正、経済に効く（読み手が正しい）。
  - 閣法-157-3（特別職給与法、サイトは効果なし（定例））：一般職に合わせた定例の改定だけ → 定型改正・制度のまま（サイトが正しい）。
  - 閣法-177-25（産業活力再生法の改正、サイトは参考額・金融）：再編・承継・資金供給は業種を問わない → 分野は経済全体（どちらでもない）。
- サイトの主張と違う値は 30 項目中 3（上の 146-65 の2項目と 177-25 の分野）。
- 経済に効くかを一度も聞いていなかった 7 本（参考額 4・保留 1・額 1・定例 1）は、6 本が一次資料で「経済に効く」、定例の 1 本（157-3）は制度と決まった。

### 試走で分かったこと（直した点）

- 裁定の指示文に、標本2の裁定にあった「給与の定例改定は定例に当たる。額が動くだけでは外れない」の文が抜けていた。最初の裁定（2 件）は額が動くことを理由に 157-3 も実質改正としたので、文を戻して 2 件を裁定し直した（最初の 2 件の記録は捨て、費用は `usage.json` の「捨てた呼び出し」に残した）。
- 読み手も同じ理由で給与法を実質改正と読んだ（157-3 は2系統とも）。全件ではこの型が定例の 319 本で多く出て裁定が増えるので、読み手の指示文の定型改正に給与法の定例改定の例を1行足した（`bill-triage-v1/spec.md` と定例の規則 RT8 にそろえる）。この1行は試走の読み手には入っていない。
