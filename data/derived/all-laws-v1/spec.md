# all-laws-v1：成立した全ての法律の結果一覧

成立した法律 3,415 本（`data/acquired/bill-census-full/enacted.csv`、並びは `data/derived/bill-triage-v1/triage.csv`）の1本ごとに、必ず1つの結果を付けた台帳です。評価の対象を絞らず、v2 の流れ（振り分け・影響・損失・便益・公開条件）に載らない法律にも「なぜ載らないか」を書き、黙って落とす法律をなくします。

生成：`python3 scripts/build_all_laws_outcomes.py` → `outcomes.csv`。確認：`tests/test_all_laws_outcomes.py`（3,415行・id の重複なし・額あり以外の理由が空でない・コミット済みの台帳が生成結果と同じ）。

## 列

`id, 題名, 分野, 指標, 確かさ, 結果, 理由, 経路, 施行日, 種類, 段階, 向き, 損失または便益の額, 単位, 公開可否, 指標の系列`

- 結果（5つ）：額あり／保留／効果なし（定例）／測定できない／評価対象外。
- 理由は額あり以外の全行で必須。経路は結果を決めた規則の符号（下記）。
- 確かさ：マクロ指標で代理した行は「低（マクロ指標で代理）」。v2 の後段を通った行は影響の判定（段階1〜3、損失が参考なら「・参考」）。
- 指標の系列：マクロ指標の行だけ、使う既存の系列（ファイルと項目）。

## 結果を決める順序

1. 額あり：`loss-v1-triage-v2/loss.csv` に損失または便益の額がある。後段の出力を優先し、題名の規則で打ち消さない。参考フラグと公開可否（`publish-v1-triage-v2/publish.csv`）は列に残す。額の使い方（合計・公開・配分に使うか）はここで決めない。
2. 効果なし（定例）：題名の語の規則 RT1〜RT8 に当たる。
3. 市場の経路がある法律（下の判定）：
   - 施行日が未取得 → 保留、理由「施行日が未取得」。
   - 施行日はあるが v2 の影響の表に未反映 → 保留（v2 の一連の再実行待ち）。
   - 影響の判定が 系列なし／国内系列なし／比較群なし → 測定できない（影響の表の理由を載せる）。
   - 段階はあるが額が出ない → 保留（損失の理由のうち保留・対応なしの部分）。
   - その他（保留、2系統の不一致など）→ 保留（影響の表の理由）。
4. 市場の産業がない法律：
   - 題名の語がマクロ規則 MA1〜MA11 に当たる → 保留。指標に代理のマクロ指標、確かさ「低（マクロ指標で代理）」。影響の指標表（`app/src/impact-batch.ts` の INDICATOR_MAP）にマクロ指標が無く、影響の計算が未実装のため保留（施行日が無ければその旨も書く）。
   - 当たらず、種類が定型改正か組織手続（両系統）→ 評価対象外。
   - それ以外 → 測定できない（代理指標を決められない）。

### 市場の経路があるかの判定

- 施行日があり `bill-triage-v2/agreement.csv` に載る行：両系統が採用で評価対象外なら市場の経路なし。それ以外（評価対象、保留、食い違い、系統欠落）は市場の経路あり。
- それ以外の行：`bill-triage-v1/triage.csv` で、結果が評価対象外、または系統A・B とも分野が対応表なしなら市場の経路なし。他は市場の経路あり。

## 定例の規則（題名の語。上から当て、最初の行で決める）

| 符号 | 内容 | 題名の語 |
|---|---|---|
| RT1 | 給与・報酬・歳費などの定例改定 | 一般職の職員の給与／特別職の職員の給与／防衛省・防衛庁の職員の給与／検察官の俸給／裁判官の報酬／国会議員の秘書の給与／国会議員の歳費／外務公務員の給与／国家公務員の給与の改定 |
| RT2 | 地方交付税の定例改正 | 地方交付税法／地方交付税の総額の特例 |
| RT3 | 公債の発行の特例（年度ごと） | 公債の発行の特例 |
| RT4 | 決算上の剰余金の処理の特例（年度ごと） | 決算上の剰余金の処理の特例 |
| RT5 | 年金・手当の額の改定の特例（年度ごと） | の額等の改定の特例 |
| RT6 | 用語・字句の整理だけ | 用語の整理 |
| RT7 | 選挙の執行経費の基準 | 執行経費の基準 |
| RT8 | 時限の特別措置法の改正で、両系統とも種類が定型改正（期限の延長だけ） | 臨時措置法／特別措置法／特別措置に関する法律／緊急措置法／臨時特例（かつ系統A・Bの種類がどちらも定型改正） |

題名に「延長」「期限」の語は無いため、期限延長は RT8 のように時限立法の名と振り分けの種類の組で判定する。税法（所得税法・地方税法・関税定率法）の年次改正は税率や対象を変えうるので定例に含めない。

## マクロ指標の規則（市場の産業がない法律。上から当て、最初の行で決める）

使う系列は `data/acquired/domestic-stats/` にある既存の系列だけで、`tests/test_all_laws_outcomes.py` が存在を確かめる。

| 符号 | 分類 | 指標 | 系列 |
|---|---|---|---|
| MA1 | 出入国・外国人 | 就業者数 | 労働力調査 jsic12-14「総数」 |
| MA2 | 司法・治安 | 公務の付加価値（実質） | 国民経済計算2020基準「13.公務」実質（連鎖方式） |
| MA3 | 選挙・政治 | 公務の付加価値（実質） | 同上 |
| MA4 | 防衛・安全保障 | 公務の付加価値（実質） | 同上 |
| MA5 | 医療・福祉 | 保健衛生・社会事業の付加価値（実質） | 同「15.保健衛生・社会事業」 |
| MA6 | 年金・社会保障・援護 | 実質GDP | 同「合計」 |
| MA7 | 教育 | 教育の付加価値（実質） | 同「14.教育」 |
| MA8 | 農林水産・食料 | 農林水産業の付加価値（実質） | 同「1.農林水産業」 |
| MA9 | 建設・住宅・土地・港湾・道路 | 建設業の付加価値（実質） | 同「5.建設業」 |
| MA10 | 行政組織・公務員・地方自治・戸籍など | 公務の付加価値（実質） | 同「13.公務」 |
| MA11 | 租税・財政 | 実質GDP | 同「合計」 |

語の一覧は `scripts/build_all_laws_outcomes.py` の MACRO_RULES。題名の語だけで決め、1本ごとの判断はしない。

限界：
- 代理指標は「その分野の産業・経済全体の動き」であって、その法律の効果を測るものではない。確かさは常に低。
- 国民経済計算に一般政府の実質の付加価値は無い（名目のみ）ので、一般政府の支出や付加価値は使わず、公務（実質）で代える。
- 規則に当たらない法律（知的財産・民商事・環境・国際機関への加盟・地域振興など）は、代理指標を作らず「測定できない」にする。
- 語の表は題名を見て作ったもので、未知の法律への妥当性は未検証。

## 施行日の台帳に行を足す

`data/acquired/enforcement-dates/enforcement.csv` は、評価対象の349本のほか、台帳外の法律の行を後から足してよい（施行日が空の行はそのまま「未取得」）。

- 日付を推測で埋めない。取れない行は空のまま、備考に理由を書く。
- `scripts/fetch_enforcement_dates.py --scope 台帳外` は台帳にまだ無い全ての成立法を取る。どの対象でも既存の行は消さず、同じ id の行だけ置き換え、無い id は末尾に足す。
- 日付の入った行は、`run-triage-v2-line1.mjs`（triage.csv の id なら自動）と `triage_v2_line2.py`（`bill-triage-v1-line2/labels.csv` の行）を通り、系統2のラベルがまだ無い行は影響の段で「系統2の振り分けが無い」として保留になる。ラベルが揃えば通常の一致判定に進む。
- 台帳や後段を更新したら `python3 scripts/build_all_laws_outcomes.py` を再実行して outcomes.csv を作り直す。

## 系統2のラベル（全3,415本）

`bill-triage-v1-line2/labels.csv` は全3,415本に付けてよい（`tests/test_line2_labels.py` は、triage.csv の順、または台帳の行が台帳順で先に並ぶ順を受け付ける）。`triage_v2_line2.py` は labels.csv の全行に指標の規則を当てるので、`bill-triage-v2/labels-line2.csv` も同じ行数になる。振り分けの一致の表・影響の表は施行日のある行だけを扱う。
