# コロナ対応の法律の費用便益（covid-benefit-v1）

`benefit.csv`：コロナ対応の法律23本（covid-response-v1 の「はい」から、台帳に無い閣法-203-1 を除く）に、額か規模つきの理由を付けた表。`rules.csv` が法律ごとの式の入力（支出の項目・帰属・乗数・根拠）で、金額は `data/acquired/covid-spending/spending.csv` を引く。

- 額が出たもの（8本）：給付の差押禁止5本、雇用保険の特例（閣法-201-59）、納税猶予の特例（閣法-201-54）、雇用保険料率の引下げ（閣法-208-14）。確かさは常に「参考」で、議員への配分に使わない。
- 額を出さないもの（15本）：規模は一次資料で取れたが、便益に換算する乗数・単価が定番の資料に無い、または法律に固有の支出が見つからない。規模と理由を残す。
- 読み方の注意：帰属と乗数は仮定の幅（下・中・上）。財源調達の超過負担は官公庁の単価が見つからず未控除（総便益）。
- 反映：`python3 -m scripts.build_macro_amounts`（原本が無い環境では `--covid-only`）で macro.csv のコロナ対応の行に入り、公開ランキングの「全体指標-コロナ費用便益」グループになる。
