# 抜き取り検証2回目の読み手への指示（版 v2、2026-11-19）

新しい標本（`sample.csv`、種 20261119）の法律を、一次資料から独立に判定するための指示。読み手には、評価サイトの値も、初回の判定も見せない（題名と資料のファイルだけを渡す）。初回（2026-10-30）の項目と同じ4項目を判定させる。定義は `../reverification-v1/prompt-v1.md` の類型・経済に効くかを引き継ぎ、分野と範囲を足した。

## 役割

あなたは法律1本の読み手です。次の法律を一次資料で読み、4項目を判定してください。推測で埋めず、読めた資料に書いてあることだけで決めます。

- 法律の ID：{id}
- 題名：{title}
- 資料のファイル：`.local/sample-v2/sources/{id}.txt`（衆議院の議案本文と、国会会議録の検索結果）
- 読む順番：{order}
  - 系統A：議案本文（理由と条文）を先に読み、会議録で補う。
  - 系統B：会議録（提案理由の説明・委員長報告）を先に読み、議案本文で補う。
- 足りなければ `python3 scripts/fetch_law_source.py url <URL>` か `python3 scripts/fetch_law_source.py kokkai "語" 回次` で読んでよい（3回まで）。「取得できない」と出たら読めなかったと記録する。ほかのファイルは読まない・書き換えない。

## 判定する項目と定義

1. 類型（1つ）
   - 新規：新しい法律を定める。
   - 実質改正：すでにある法律の中身（対象、要件、税率、給付、規制、罰則）を変える。税法の年度ごとの改正はここ。
   - 定型改正：期限の延長だけ、または毎年くり返す決まった形の改正で、枠組みを変えない。
   - 組織手続：組織の設置・改組、施行に伴う整備、名称や手続の整理だけ。
   - 判定不能：資料が読めず決められない。
2. 経済に効くか（1つ）
   - 経済に効く：事業者や家計の費用・価格・税負担、補助や給付の額、規制の強さ、市場への参入を、この法律が実際に変える（続けなければ無くなる補助・特例の延長も含む）。
   - 制度のみ：組織・手続・名称・理念・計画づくり・努力義務・配慮規定など。この法律だけでは経済の量が動かない。
   - 判定不能：資料が読めず決められない。
3. 主な産業分野（1つ）：農林水産、労働市場、金融、医療・福祉、交通・移動、教育、通信・ネット、専門サービス・研究開発、文化・娯楽・生活サービス、エネルギー、行政のデジタル化、建設、製造業、住宅・不動産、商業、宿泊・観光、半導体・電子、鉱業・採石、経済全体（産業を特定できない）
4. 範囲（1つ）
   - その産業全体：選んだ分野の産業の大部分に効く。
   - 産業の一部（狭い特例）：特定の地域・業態・事業者・品目だけに効く。
   - 産業を特定できない：特定の産業に向かない（全体の税、手続、理念など）。

## 出力（構造化して返す）

id、系統、何をする（60字以内）、類型、類型の理由（80字以内）、経済に効くか、経済の理由（80字以内）、主な産業分野、範囲、引用（資料の原文20〜80字、2つまで）、出典URL（実際に読めたもの）、読めなかった資料、確信（高：議案本文の理由と条文の両方／中：片方／低：会議録の一部か題名だけ）。

## 運用

- モデル：Haiku（effort medium）。1本1件、系統ごとに別の読み手。
- 2系統が割れて合否が変わる項目は、Sonnet が同じ資料で裁定する（サイトの値は見せない）。それでも決まらなければ Opus が裁定する。
