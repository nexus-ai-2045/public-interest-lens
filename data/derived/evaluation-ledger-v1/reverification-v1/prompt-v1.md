# 再判定の読み手への指示（版 v1、2026-11-19）

抜き取り検証で不合格のまま残った法律を、一次資料から読み直すための指示。読み手には、評価サイトの値も、前回の判定も見せない（題名と資料の場所だけを渡す）。

## 役割

あなたは法律1本の読み手です。次の法律を一次資料で読み、類型と「経済に効くか」を判定してください。推測で埋めず、読めた資料に書いてあることだけで決めます。

- 法律の ID：{id}
- 題名：{title}
- 読む順番：{order}
- 資料の場所の手がかり（前回の読み手が使った URL。判定の中身ではない）：{hints}

## 資料の読み方（この道具だけを使う。ほかのファイルは読まない・書き換えない）

- 議案本文と理由：`python3 scripts/fetch_law_source.py honbun {id}`
- 会議録（提案理由の説明、委員長報告）：`python3 scripts/fetch_law_source.py kokkai "題名の主な語 提案" 回次`（語を変えて3回まで）
- URL を直接読む：`python3 scripts/fetch_law_source.py url <URL>`
- 「取得できない」と出たら、その資料は読めなかったと記録する。読めたふりをしない。

## 判定する項目と定義

1. 類型（1つ選ぶ）
   - 新規：新しい法律を定める。
   - 実質改正：すでにある法律の中身（対象、要件、税率、給付、規制、罰則）を変える。税法の年度ごとの改正は税率や対象を変えうるので、ここに入る。
   - 定型改正：期限（有効期限・適用期限）の延長だけ、または毎年くり返す決まった形の改正で、中身の枠組みを変えない。
   - 組織手続：組織の設置・改組、ほかの法律の施行に伴う整備、名称や手続の整理だけ。
   - 判定不能：資料が読めず決められない。
2. 経済に効くか（1つ選ぶ）
   - 経済に効く：事業者や家計の費用・価格・税負担、補助や給付の額、規制の強さ、市場への参入を、この法律が実際に変える（国の補助や特例を続ける延長も、続けなければ無くなるお金が動くなら含む）。
   - 制度のみ：組織・手続・名称・理念・計画づくり・努力義務・配慮規定など。この法律だけでは経済の量が動かない。
   - 判定不能：資料が読めず決められない。
3. 期限の延長のほかに、中身を変える規定があるか（ある／ない／読めない）。あるなら何か。

## 出力

次の JSON だけを、ファイル `{out}` に書き、同じ内容を最後の返答にも出してください。ほかのファイルは作らない。

```json
{
  "id": "{id}",
  "系統": "{line}",
  "何をする": "この法律がすること（60字以内）",
  "類型": "新規|実質改正|定型改正|組織手続|判定不能",
  "類型の理由": "理由（80字以内）",
  "経済に効くか": "経済に効く|制度のみ|判定不能",
  "経済の理由": "理由（80字以内）",
  "延長のほかの中身": "ある：〜|ない|読めない",
  "引用": ["資料の原文をそのまま20〜80字で抜いたもの（2つまで）"],
  "出典URL": ["実際に読めた URL"],
  "読めなかった資料": ["読めなかった資料と理由。無ければ空"],
  "確信": "高|中|低"
}
```

確信の目安：議案本文の理由と条文の両方を読めたら高、どちらか片方なら中、会議録の一部や題名だけなら低。
