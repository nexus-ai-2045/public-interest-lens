# 抜き取り検証で不合格のまま残った法律の読み直し（2026-11-19）

初回の抜き取り検証（2026-10-30、`docs/評価の独立検証.md`）で不合格になり、額を参考値に下げる自動の規則にも当たらず「不合格のまま」残っていた 11 本を、一次資料から読み直して1本ずつ決着させた記録。

## 前提

- 対象：抜き取り 118 本のうち、初回が不合格で、台帳の検証状態が「抜き取り検証で不合格」だった 11 本。どれも付加価値の額が無い（保留 6、測定できない 4、国の収支の別欄 1）。順位・議員配分には初めから入っていない。
- 初回の判定表（`sample-verdicts.csv`）と初回の記録（`verification-raw/`）は書き換えない。
- 初回の読み手への指示文はリポジトリに残っていない。今回の定義は `prompt-v1.md` に書いたもので、初回と一字一句同じとは限らない。
- 新しく抜き取り直してはいない。同じ 118 本を今の台帳に当て直した。

## 手順

1. 読み手：1本につき2系統（計 22 件）。サイトの値も初回の判定も見せず、題名と資料の場所だけを渡した。系統Aは議案本文を先に、系統Bは会議録を先に読む。モデルは Haiku。指示文は `prompt-v1.md`（版 v1）。結果は `lineA.json`・`lineB.json`（判定、理由、原文の引用、読めた URL、読めなかった資料、確信）。
2. 資料：衆議院の議案本文（理由と条文）と国会会議録検索システム。読む道具は `scripts/fetch_law_source.py`。読めなかった資料は各行の「読めなかった資料」に残した。
   取った原資料は、読み手に渡す前に `scripts/register_external_material.py` で `.local/external-materials/reverification-v1/` に登録する（観測時刻つき、内容は `unverified`。Git には入れない）。読み直しの時点ではこの登録が無かったので、2026-11-19 に読み直しで使った出典 URL 32件を取り直して登録した（観測時刻は取り直した時刻で、読み直しの時刻ではない）。
3. 裁定：2系統は 11 本とも類型・経済に効くかの両方で一致した。初回と結論が変わった項目（5 本）と、照合の読み方（3 本に関わる）は、Opus が一次資料を自分で読んで裁定した。結果は `rulings.json`。
4. 決着：`python3 scripts/resolve_sample_failures.py` が、台帳・2系統の判定・裁定から規則で決めて `../sample-resolutions.csv` を書く（AI は呼ばない）。規則はスクリプトの冒頭にある。照合の読み方の裁定は、裁定が名指しした法律にだけ使う。決着の行には、決着が前提にしたサイトの値（類型・分類・到達点・経済に効くか）を残し、台帳を作り直すときにサイトの値が変わっていれば決着を使わず不合格に戻す。
   - `sampling-time-ledger.csv` は、抜き取り時の台帳（#133 のマージ 275620d の `ledger.csv`）から対象 11 本の行だけを写したもの。抜き取り時と今で到達点が違う法律（閣法-180-38、閣法-180-72）は、決着が今の台帳に対するものだと理由に書く。
5. 反映：`python3 scripts/build_evaluation_ledger.py build`（台帳の検証状態と検証メモ）、`python3 scripts/report_verification.py`（レポート）。

## 結果

| 決着 | 本数 | 中身 |
|---|---|---|
| 合格に訂正 | 5 | サイトに誤りが無かった。3 本は照合の読み替え（振り分けの「評価対象外」を「制度のみ」と読んだ）、2 本は初回の独立判定の誤り |
| 参考に下げた | 6 | サイトの類型か分類が一次資料と合わない。サイトの値はまだ直っていない |
| 不合格のまま | 0 | |

抜き取り 118 本の今の内訳：合格 45、参考に下げた 73（規則で自動 67、読み直し 6）、不合格のまま 0。

## 裁定の要点

- 照合の読み方：台帳の「分類＝評価対象外」は、市場の産業の対応表に当たらないという振り分けの区分で、「制度だけ」という主張ではない。サイトが「経済に効く」と記録し、額を付けずに保留・測定できないに置いている法律は、分類の項目では独立判定と食い違わない（裁定が名指しした閣法-180-72、閣法-217-48、衆法-218-1 だけに使う）。閣法-180-72 は初回の抜き取りの時点では到達点が参考額だった。訂正は今の台帳に対する判定。同じ形の衆法-217-15 は名指しが無いので決めず、国の収支の別欄に置いた閣法-189-3 にはこの読み方を使わない（どちらも類型の誤りもあり、参考に下げた）。
- 閣法-213-35：附則で修学支援の対象に専攻科の学生を加えるので「経済に効く」。初回の裁定は理由の節だけを見ていた。
- 閣法-221-52：国以外の主宰者に保険契約などを義務付け、負担金・納付金を課すので「経済に効く」。
- 閣法-180-38：延長しなければ国庫補助と起債の特例が止まるので「経済に効く」。類型は定型改正。
- 閣法-213-45：大正11年の法律の全部改正なので「実質改正」。
- 衆法-217-15：期限の置換と、延長のたびに付く経過措置だけなので「定型改正」。

## 限界

- 読み手も裁定も AI で、誤りうる。条文の後半や附則を読めていない行がある（各行の「読めなかった資料」）。
- 参考に下げた 6 本は、サイトの値（類型・分類）が直っていない。直すには振り分けと類型のデータを作り直す必要があり、この記録の範囲の外。
- 抜き取っていない法律の中に同じ型の誤りがどれだけあるかは、この記録からは分からない。額の無い到達点（保留・測定できない・国の収支の別欄）は全体で 307 本、抜き取りは 18 本、うち初回の不合格 11 本、読み直し後もサイトの誤りが残ったのは 6 本。
- 別に直すべき点：照合（`scripts/compare_verification.py`）は台帳の「分類」ではなく「経済に効くか」の欄と比べるほうが正しい。今回は初回の判定表を変えないため直していない。
