# 誤りの型の全件検査（error-type-check-v1、2026-11-19）

抜き取り検証の読み直し（`../evaluation-ledger-v1/reverification-v1/`）で、サイトの類型・分類が一次資料と合わない法律が6本見つかった。同じ型の誤りが抜き取っていない法律にも残っている前提で、型ごとに機械で拾える検査を作り、成立した全法律で数えた。

- 作り方：`python3 scripts/check_error_types.py`（AI は呼ばない）。`--check` で出力が今の入力から作り直したものと同じか確かめる。`tests/test_error_types.py` も同じことを確かめる。
- 出力：`candidates.csv`（id・題名・型・根拠。1本が複数の型に当たれば複数行）、`counts.json`（型ごとの定義と本数）。
- 候補は**誤りの疑い**で、誤りと確定したものではない。確定は一次資料の読み直しで行う。
- 一次資料で直した法律（`../primary-source-corrections-v1/`）は、直した項目の型（類型→K、経済に効くか→C）には数えない。

## 結果（成立した全法律 3,415 本が分母）

| 型 | 定義 | 本数 | 6本のうち |
|---|---|---|---|
| K1 類型が空 | サイトの類型（all-laws-v1 の種類）が空 | 240 | 衆法-217-19 |
| K2 税法の年度改正を定型改正に置いた | 税法（所得税法・法人税法・地方税法・租税特別措置法・関税定率法・関税暫定措置法・消費税法）の一部改正で類型が定型改正。読み直しの指示文の定義では実質改正 | 88 | 閣法-189-3、閣法-221-4 |
| K3 時限法の改正で系統の類型が割れた | 時限法（定例の規則 RT8 と同じ語）の改正で、振り分けの各系統の類型が定型改正とそれ以外に割れる | 107 | 閣法-180-38、衆法-217-15、衆法-217-19 |
| C1 経済に効くと記録しつつ制度だけの扱い | 経済の区分が「経済に効く」なのに到達点が評価対象外か効果なし（定例） | 19 | （読み直しの6本には無い形。多くは題名の型「整備法」で対象外にした法律） |
| C2 制度と記録しつつ経済の扱い | 経済の区分が「制度」なのに到達点が測る側 | 2 | （閣法-213-45 は直す前、経済の区分が空だった） |
| C3 経済に効くかを AI が決められないまま測る側に置いた | 到達点が測る側で、経済の区分が判定不能 | 210 | 閣法-180-38 |
| R1 照合で読み替えが起きる形 | 台帳の分類が評価対象外なのに到達点が測る側（サイトの誤りではない。分類で照合すると誤って食い違いになる） | 638 | 閣法-180-72・閣法-217-48・衆法-218-1 で初回の照合が読み替えた |

- サイトの誤りの疑い（K1〜K3・C1〜C3）に1つ以上当たる法律：3,415 本中 582 本。到達点の内訳：参考額 335、評価対象外 85、効果なし（定例）59、保留 49、測定できない 41、国の収支の別欄 13。
- 順位・議員配分に使う個別の額（到達点「額（個別の因果の鎖）」、7本）は、候補に0本。参考額・国の収支の別欄は順位・配分に使わない。
- 機械で拾えない型：全部改正を「新規」と置いた誤り（閣法-213-45、大正11年の法律の全部改正）。題名だけでは分からず議案本文が要る。

## 候補の確定（2026-11-19）

候補 582 本は一次資料の読み直しで確定した（`../primary-source-corrections-v1/reread-v1/README.md`）。K2 は規則で実質改正に、そのほかは Haiku 2系統 → Sonnet → Opus で決め、直した値は `../primary-source-corrections-v1/corrections.csv`、サイトの値が正しかった項目は `confirmed.csv` に置いた（どちらも、その項目の型には数えない）。決められなかった 3 本と、制度と読んだが本法や附則を読めていなかった 4 本は、経済に効くかを判定不能として置く（定例の規則で効果なしに確定させない）。測る側に残るものが C3 の候補に残る（本数は `counts.json`）。
上の表の本数は #208 の時点のもの。今の本数は `counts.json`。
