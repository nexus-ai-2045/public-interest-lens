# 類型の照合（type-crosscheck-v1）

サイトの類型（振り分けに訂正表・当て直しを重ねた値）を、法律案の本文から決定論の規則で出した類型と突き合わせた結果。AI は使わない。

- 作り方：`python3 scripts/type_crosscheck.py fetch`（衆議院の議案本文と e-Gov 法令 API v2 の改正元を `.local/type-crosscheck-v1/` に取る。0.5秒間隔）→ `python3 scripts/type_crosscheck.py build`。
- `crosscheck.csv`：法律ごとの サイトの類型・規則の類型・照合（一致／食い違い／照合できない）・規則の根拠の数・本文URL・本文の sha256 の先頭16桁。
- `summary.json`：本数の集計。
- 使い方（案）：実質改正と判定された法律のうち、照合が「一致」のものだけを額・順位に使い、「食い違い」は参考に置く。**この PR ではまだつながない。**
- 新規どうしの一致は、規則もサイトも同じ情報（新規か改正か）で決めるので、確かさは上がらない。
- 定型改正・組織手続は規則が粗く、ほとんどが食い違う。額を付けない側なので、参考に落としても順位への影響は小さい。
- 根拠：標本（既存の裁定だけを正解）で、規則とサイトの値が一致した143本中139本が正しく、食い違いに既知の誤り27本中23本が入った。測定の記録は project の analysis 資料「確立理論で数え方の穴を洗い出す」6-4・6-5。
- 既知の限界：改正の指示は「改める・加える・削る・削除する」で数える。「改め、」と続けた置き換えは数に入らず、定型改正になるべき法律が実質改正に倒れることがある。直すときは規則の版を上げ、標本で測り直す。
