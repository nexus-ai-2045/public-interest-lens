# io-ripple-v1：産業連関による波及（川上）

損失額（loss-rule-v1）に足さず、別欄の「波及を含む上限」として出す。順位・議員の額には使わない。式（下）と実装は `scripts/io_ripple.py`。`app/src/method-spec.ts` への清書（節 `io-ripple`、定番の手法「産業連関分析」）は、公開データに載せるとき（method-spec-v2.3）に足す（ロードマップ R29）。

## 式
B = (I − (I − M̂)A)⁻¹、A_ij = Z_ij / X_j、M̂_i = 輸入計_i / 国内需要合計_i（競争輸入型）
r_S = Σ_{k∈S} w_k ·(1 / (v_k B_kk)) · Σ_{i∉S} v_i B_ik、w_k = VA_k / Σ_{k∈S} VA_k
波及の額 = Loss(0.5) · r_S、波及を含む上限 = Loss(0.5) · (1 + r_S · e^h)。v は付加価値率、h は下の半幅。
出典（定番）：Miller & Blair, Input-Output Analysis (2nd ed., 2009), ch. 2, 6。

出典（総務省ほか10府省庁「産業連関表」）：平成12-17-23年・平成17-23-27年接続産業連関表の統合中分類（105部門、2000・2005・2011・2015年。e-Stat）、接続産業連関表（平成23-27-令和2年）の基本分類の取引基本表（2011・2015名目・実質、2020名目。約380部門）、令和2年表 統合大分類の計算シート（検算用）。原本の URL と sha256 は `data/acquired/io-tables/manifest.csv`。

## 検算と検証（`backtest.json`）
- 同じ式を公式の大分類（37部門）に当てると、公式の逆行列係数表と最大絶対誤差 4.4e-16 で一致。
- 産出の予測：前の表の逆行列と次の年の最終需要から次の年の国内生産額を当てる。部門の上位3/4で、中央値の誤差は 2011→2015（実質）2.4%、2015→2020（名目）2.5%。直接効果だけだと 65%・72%、前期の値のままだと 6.1%・4.2%。誤差10%以内の部門は 97%・86%。
- 波及比率 r の5年間の動き：|対数比| の95%分位が 0.29（2011→2015）・0.22（2015→2020）、最大 0.355。2011→2020（9年）は 95%分位 0.46、最大 0.48。
- 区間の半幅 h：基本分類の表（2011・2015・2020）は、表との年の差が5年以内 0.40、10年以内 0.50。統合中分類の表（2000・2005）は5年以内 0.80（産業単位の5〜6年の動きの最大 0.42＋集計差の補正後の残り最大 0.38）。それを超える法律は保留。最大値を超える幅なので、保持した移行での被覆率は 100%（0.40 で 2011→2015 と 2015→2020、0.50 で 2011→2020）。移行は2回だけで、h は2回の最大値から決めたため、独立な検証ではない。古い表（1995・2000・2005）を足したら、まず予測だけで再検証する。

## 出す・出さない
- 出す：産業が ISIC の大分類（A〜S）に対応し、施行年が基本分類の表（2011・2015・2020）の前後10年以内、または中分類の表（2000・2005）の前後5年以内のもの（2,634本中1,331本）。
- 出さない：全産業（_T、1,303本）、対応のない産業、表から遠い法律。理由を `laws_ripple.csv` に書く。1995年の表（.xls）と各年の単独表は取得できる（探索済み）が未取り込み。理由を `laws_ripple.csv` に書く。

## 限界
需要側の固定係数モデル。価格・代替・供給制約が無く、供給を止める規制の川上への波及は過大になりうる。川下（その産業の製品を使う側）は入らない。産業の対応（ISIC → 基本分類）は判断によるもので、設計決定0007の2系統照合の前。
