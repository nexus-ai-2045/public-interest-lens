# io-ripple-v1：産業連関による波及（川上）

損失額（loss-rule-v1）に足さず、別欄に出す（波及を含む額の、絶対値が小さい側と大きい側）。順位・議員の額には使わない。式（下）と実装は `scripts/io_ripple.py`。`app/src/method-spec.ts` への清書（節 `io-ripple`、定番の手法「産業連関分析」）は、公開データに波及を載せるときに、そのときの版で足す（ロードマップ R40。v2.3 は covid-benefit-v1 に使われたので、次の版）。

## 式
B = (I − (I − M̂)A)⁻¹、A_ij = Z_ij / X_j、M̂_i = 輸入計_i / 国内需要合計_i（競争輸入型）
S の最終需要の減 f を B[S,S] f = w / v で解く（w_k = VA_k / Σ_{k∈S} VA_k。S 内の付加価値の減少がちょうど 1 になり、S 内部門どうしの波及も合わせる）
r_S = Σ_{i∉S} v_i (B[i,S] f)　（S が1部門のときは w=1 で r = (1 / (v_k B_kk)) · Σ_{i≠k} v_i B_ik）
波及の額 = Loss(0.5) · r_S、波及を含む額 = Loss(0.5) · (1 + r_S · e^{∓h})（−h が絶対値の小さい側、+h が大きい側。額は符号つき：正は損失、負は便益で、符号は変わらない）。v は付加価値率、h は下の半幅。
出典（定番）：Miller & Blair, Input-Output Analysis (2nd ed., 2009), ch. 2, 6。

出典（総務省ほか10府省庁「産業連関表」）：平成12-17-23年・平成17-23-27年接続産業連関表の統合中分類（105部門、2000・2005・2011・2015年。e-Stat）、接続産業連関表（平成23-27-令和2年）の基本分類の取引基本表（2011・2015名目・実質、2020名目。約380部門）、平成7-12-17年接続産業連関表の投入表（基本分類、1995・2000・2005年の名目と一部実質。符号体系が違うので4桁の185部門にまとめて使う。読み込みと検証は `scripts/io_ripple_old.py`、結果は `backtest_old.json`）、令和2年表 統合大分類の計算シート（検算用）。原本の URL と sha256 は `data/acquired/io-tables/manifest.csv`。

## 検算と検証（`backtest.json`）
- 同じ式を公式の大分類（37部門）に当てると、公式の逆行列係数表と最大絶対誤差 4.4e-16 で一致。
- 産出の予測：前の表の逆行列と次の年の最終需要から次の年の国内生産額を当てる。部門の上位3/4で、中央値の誤差は 2011→2015（実質）2.4%、2015→2020（名目）2.5%。直接効果だけだと 65%・72%、前期の値のままだと 6.1%・4.2%。誤差10%以内の部門は 97%・86%。
- 波及比率 r の5年間の動き：|対数比| の95%分位が 0.29（2011→2015）・0.22（2015→2020）、最大 0.355。2011→2020（9年）は 95%分位 0.46、最大 0.48。
- 古い表（1995・2000・2005年、`backtest_old.json`）：行（品目）と列（産業）の細かさが違うので、共通の先頭4桁の185部門にまとめる。行の収支（需要合計＋輸出−輸入＝国内生産額）と列の収支（中間投入＋粗付加価値＋分類不明＝国内生産額）は3年とも誤差0。粗付加価値の合計は2005年で506兆円（名目 GDP 約503兆円の規模）。
  - 産出の予測（部門の上位3/4）：中央値の誤差は 1995→2000（実質）4.4%、2000→2005（名目）4.8%。直接効果だけだと 78%・73%、前期の値のままだと 9.6%・10.7%。誤差10%以内の部門は 80%・70%。
  - 同じ符号の中の5年の動き：部門ごとの |対数比| の95%分位は 0.34（1995→2000）・0.38（2000→2005）、産業(ISIC)ごとの最大は 0.18・0.18。片方の移行の95%分位を半幅にして、もう片方に当てた被覆率は 95%・92%（部門ごと）。
  - 表の改訂をまたぐ差：古い表の2005年（6桁に換算）と基本分類の2011年の産業ごとの差は、最大 0.57（B 鉱業。M 専門・科学技術 0.48 は「研究」の範囲が変わった）、0.50 以内は18産業中17（94%）。
  - 4桁にまとめた表は6桁の表より波及比率が高く出る（内部の取引が部門に入るため）。2011・2015・2020年の基本分類を4桁にまとめて、差（対数）を産業ごとに測り、古い表の値から引く（0.02〜0.14）。3年のばらつきが大きい D（電力・ガス・熱供給：-0.69〜0.25）は補正が定まらないので古い表を使わず、2000・2005年は統合中分類で代える（1995年は保留）。
  - 産業の対応（ISIC → 古い表の符号）は、符号をそのまま流用せず部門名を読んで引き直した（`OLD_ISIC_TO_IO`）。2系統目の照合として、統合中分類（2011年以降の符号）の同じ年の産業ごとの粗付加価値の合計と比べた。全体の差 -1.8% を引いて、19産業中17産業は ±0.07 以内。差が大きい A（-0.25〜-0.29）は統合中分類の A が林業・漁業を含むため（古い表に 02・03 を足すと +0.05）、B（-0.13〜-0.21）は統合中分類の B が石炭・原油・天然ガスを含むため（07 を足すと -0.04）、I（-0.07〜-0.11）は飲食・宿泊の範囲の差。
- 区間の半幅 h：基本分類の表（2011・2015・2020）は、表との年の差が5年以内 0.40、10年以内 0.50。統合中分類の表（2000・2005）は5年以内 0.80（産業単位の5〜6年の動きの最大 0.42＋集計差の補正後の残り最大 0.38）。それを超える法律は保留。最大値を超える幅なので、保持した移行での被覆率は 100%（0.40 で 2011→2015 と 2015→2020、0.50 で 2011→2020）。移行は2回だけで、h は2回の最大値から決めたため、独立な検証ではない。古い表（1995・2000・2005）を足したら、まず予測だけで再検証する。

## 出す・出さない
- 出す：産業が ISIC の大分類（A〜S）に対応し、施行年が基本分類の表（2011・2015・2020）の前後10年以内、または古い表（1995・2000・2005）の前後5年以内のもの（額のある2,082本中1,289本。基本分類662、古い表596、統合中分類31）。古い表の導入前と出す本数は同じで、2000・2005年付近の596本が統合中分類（半幅 0.80）から古い基本分類（半幅 0.60）に代わり、r の変わりは対数で最大 0.28。
- 出さない：全産業（_T、628本）、対応のない産業（165本）、表から遠い法律。理由を `laws_ripple.csv` に書く。1995年の表はまだ使う法律が無い（額のある法律の施行日が1998年以降のため）。各年の単独表は取得できる（探索済み）が、同じ数字なので取り込まない。

## 限界
需要側の固定係数モデル。価格・代替・供給制約が無く、供給を止める規制の川上への波及は過大になりうる。川下（その産業の製品を使う側）は入らない。産業の対応（ISIC → 基本分類）は判断によるもので、古い表の分は統合中分類との合計の照合（上）で2系統目を済ませた。2011年以降の表の分は、同じ照合で A・B に統合中分類との定義の違い（林業・漁業、石炭・原油・天然ガス）が見つかっており、A を 01 だけにする割り切りと、M と N が重なる割り切りは、次の版で見直す。
