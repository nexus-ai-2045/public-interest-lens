# loss-v1（段階2以上の法律に反実仮想の損失額をかける）

`impact-v1` で影響段階が2以上になった法律に、判定ルール `loss-rule-v1`（`app/src/loss-rule.ts` の `estimateLoss`）をかけます。損失額の計算は `loss-rule.ts` だけが行い、この段階では系列を選んで入力を作り、結果を表にするだけです（ロジックを1か所に保つため）。`loss-rule.ts` は変更していません。

**この段階は法律だけを扱います。** 人物・採決・役職のデータ（`data/acquired/sangiin-votes/`・`office-holders/` など）は読まず、個人への配分（`allocateLoss`）も呼びません。

## 入力

| 入力 | 使う行 |
|---|---|
| `data/derived/impact-v1/impact.csv` | 判定が「段階2」「段階3」で、向き（貢献／悪影響）がある行（15本）。国際比較の段階は最大1なので対象にならない |
| `data/acquired/oecd-industry/industry_va.csv` | OECD 国民経済計算 表6の産業別総付加価値（B1G）。日本（JPN）と比較国の情報通信（J）・宿泊・飲食サービス（I）。実質は `LR`、名目は `V`（取得の報告は `docs/reports/oecd-industry.md`） |
| `data/acquired/domestic-stats/sna_gdp_by_industry_*base.csv` | 名目GDP（貸出残高の円換算）。分野の付加価値は OECD の値との照合だけに使う |
| `data/acquired/more-stats/worldbank_extra.csv` | 世界銀行 預金銀行の民間向け国内与信（GDP比%、FD.AST.PRVT.GD.ZS）。貸出残高（参考）だけに使う |

インターネットからは何も取っていません。

## 再実行

```sh
cd app && node scripts/run-loss-v1.mjs   # Node 22.18 以降
```

`app/src/loss-batch.ts` が指標ごとの入力の作り方（`LOSS_SOURCES`）を持ち、`app/scripts/run-loss-v1.mjs` が CSV の読み書きだけをします。テストは `app/src/loss-batch.test.ts`（人工データ）。

## 方法

### 1. loss-rule-v1 が求める入力

`estimateLoss` は「日本の分野の実質付加価値」を「比較国（3か国以上）の同じ定義の系列」の伸びと比べ、反実仮想との差を開始前最後の年の名目付加価値（円）で換算して、開始後1年目（施行年）から最大10年分足します。開始前から続く伸びの差は織り込み、規制の便益が未測定なら計算しても `publishable=false`（公開しない）にします。

### 2. 指標ごとの対応（`LOSS_SOURCES`）

| 指標 | 日本の系列 | 比較国の系列 | 扱い |
|---|---|---|---|
| 通信業の付加価値 | OECD 表6 JPN の情報通信（ISIC Rev.4 J）。実質 LR、名目 V | 同じ表・同じ産業・LR の12か国（ITA は条件付き、下の 2-2） | 下の 2-2 |
| 宿泊者数 | OECD 表6 JPN の宿泊・飲食サービス（I）（損失額は付加価値で測るため、宿泊者数ではなくこちら。飲食を含むので代理） | 同じ表・同じ産業・LR の11か国（KOR は系列が無い） | 下の 2-2 |
| 貸出残高 | 世界銀行 預金銀行の民間向け国内与信（GDP比%）の日本の値 | 同じ系列の12か国 | **参考**。下の 2-1 |

- 比較国の同じ定義の系列が無い指標に、国内の「経済全体」の系列や定義の違う国際の系列（世界銀行のサービス業のGDP比など）を代わりに入れることはしません。loss-rule-v1 は比較国の同じ定義の系列を前提にしているためです。
- 金融（K）と運輸（H）も取得済みですが、使っていません。`LOSS_SOURCES` に金融・運輸の付加価値で測る指標が無いためです（金融の法律は貸出残高で、比較国と同じ定義の世界銀行の与信で測る参考扱いのまま。合計に入れません）。

#### 2-1. 貸出残高（参考）

- 影響段階は日本銀行の国内銀行の総貸出で判定しましたが、比較国に同じ定義が要るため、損失額は世界銀行の与信のGDP比（日本と12か国）で測ります。
- 円への換算：開始前最後の年の与信残高＝与信のGDP比÷100×名目GDP（国民経済計算）。判定ルールはこれを「開始前最後の年の名目値」として使います。額は付加価値の損失ではなく、**与信残高の比較国との差を足した「残高の差の累積」**です。
- 比較国は、日本の窓の年をすべて持つ国だけです。最新の年は国によって公表が遅れるので、開始前の窓を持つ国の半数以上（かつ3か国以上）がそろう最後の年で開始後の窓を切ります。
- **系列の断絶：** 取得済みの値は2000年と2001年の間で多くの国が同時に段差を持ちます（日本179→104%、韓国68→100%、スウェーデン40→90%、カナダ74→121%。ドイツ・スペイン・フランス・イタリア・オランダの5か国は2001年から始まる）。定義の変わり目とみなし、損失額の窓が2001年をまたぐ法律は判定ルールを呼ばずに保留にします（系列接続禁止）。
- 参考にする理由：「貸出が多いほど良い」という向きは機械的な仮定で、1999〜2001年施行の6本はほぼ同じ窓の同じ系列（実質的に1つの観測）です。参考の行はどの合計にも入れません。

#### 2-2. 通信業・宿泊者数（OECD 表6）

決めたこと（既定値。変えるなら `LOSS_SOURCES` の `oecd`）：

1. **実質は `LR`（連鎖実質・全国2020年基準）、名目は `V`。** `L`（連鎖実質・自国の基準年）は基準年が国で違い（USA・CAN 2017、NOR 2015、NLD 2021 など）、GBR には無いので、国をまたいで使いません。判定ルールは各国の伸び（比）だけを使い、通貨はそろえません。
2. **産業の対応：** 通信の法律＝ISIC Rev.4 J（情報通信）、観光・宿泊の法律＝I（宿泊・飲食サービス）。
3. **KOR は I が無い**ので、宿泊者数の比較国から外します（別の出典で補わない）。
4. **ITA は2010年に系列の断絶フラグ**（原本の `OBS_STATUS=B`）があります。損失額の窓（開始年の5年前〜開始後10年目）が2010年をまたぐ法律（窓の最初の年 < 2010 ≦ 最後の年）では ITA を比較国から外します。
5. **AUS は年度（7〜6月）の可能性**が高いですが、そのまま使い、使った行の「計算式の要素」に注記します。
6. **比較国は、日本の窓の年をすべて持つ国だけ**です（CAN は2007年から、USA は1997年から）。最新の年は国で公表が遅れる（GBR の LR は2023年まで）ので、貸出残高と同じく、開始前の窓を持つ国の半数以上（かつ3か国以上）がそろう最後の年で開始後の窓を切ります。使える国が3か国に足りなければ、判定ルールが保留にします（そのまま）。
7. **日本も OECD 表6の JPN の行**を使い、比較国と定義をそろえます。換算に使う名目は JPN の `V`（百万円）です。これまで使っていた国民経済計算2020基準と照合すると、名目は開始前最後の年（2013〜2021年）のすべてで同じ値、実質は国民経済計算の指数（2020年=100、小数1桁）と JPN の LR を2020年=100にした値の差が最大0.12%（J の1996年。I は最大0.03%）で、指数の丸めの範囲です。各行の「計算式の要素」に国民経済計算の名目も並べています。

### 3. 独立でない観測（観測グループ）

同じ指標（同じ系列）で、損失額の窓（開始前5年〜開始後10年目）が重なる法律を1つの観測グループにします。グループの中の額は、同じ系列の同じ年を何度も数えています。**グループの中の額を足してはいけません。** 報告は法律ごと・グループごとに行い、合計は出しません。

### 4. 新型コロナ

損失額の開始後の窓（施行年〜開始後10年目）に2020〜2022年が入る行には、理由欄に注意を付けます。判定ルールは同時期の別の出来事を除かないので、額は変えていません。

## 出力 `loss.csv` の列

| 列 | 中身 |
|---|---|
| id, 題名, 分野, 指標 | impact.csv のまま |
| 段階, 向き | impact.csv の国内の判定（段階2／段階3、貢献／悪影響） |
| 損失または便益の額 | `損失：` または `便益：` のあとに `中央値=…;第1四分位=…;第3四分位=…`（円、整数）。正は失った額、負は得た額（loss-rule-v1 の符号のまま）。保留は空欄（0で埋めない） |
| 単位 | 円、開始後何年の累積か、換算に使った名目の年 |
| 計算式の要素 | 日本の系列と年、開始前最後の年の名目値（OECD の行は国民経済計算の名目との照合つき）、比較国（国コード）、外した国と理由（ITA の断絶・KOR の系列なし）、AUS の年度の注記、規制の便益（すべて未測定） |
| 参考フラグ | 指標が貸出残高なら「参考」 |
| 理由 | 判定ルールの理由文、保留の理由（比較国が3か国未満・向きの不一致・系列の断絶）、指標の注記、新型コロナの注意、独立でない旨 |
| 観測グループ | 上の 3（例：`通信業の付加価値-1`） |

## 限界

- 規制の便益はどの法律も未測定なので、額が出ても loss-rule-v1 により公開しません（`publishable=false`）。
- OECD の値には暫定値（`OBS_STATUS=P`）を含みます。`industry_va.csv` に状態の列が無いので、区別していません。
- 宿泊・飲食サービス業の付加価値は飲食を含むので、宿泊者数の代理です。
- 宿泊者数の3本と通信業の5本は、開始後の窓に新型コロナの2020〜2022年を含みます。判定ルールは同時期の別の出来事を除かないので、額は新型コロナの影響と分けられません。
- 貸出残高の額は残高の差の累積で、付加価値の損失とは比べられません。

## 追加：新分野（field-expansion-v1）の損失額の入力

`docs/提案/分野の拡張-v1.md` の新分野9つ（水道・廃棄物を除く）の指標14本（直接5本・代理9本）を `app/src/loss-batch.ts` の `EXPANSION_LOSS_SOURCES` に足しました。日本は国民経済計算の産業の実質付加価値（基準ごとの候補。教育・保健衛生・専門サービス・その他のサービスは2011基準以降だけ）、国際は OECD 表6の ISIC Rev.4 の節：農林水産 A、建設 F、住宅・不動産 L、教育 P、医療・福祉 Q、製造業 C、商業 G、専門サービス・研究開発 M+N、文化・娯楽・生活サービス R+S。

- **節が未取得なら保留**：`industry_va.csv` に必要な節が無い（現在は H・I・J・K・_T だけ）ときは、補わず、エラーにもせず、「保留（国際比較の系列が未取得）」と理由に書きます。節がそろえば、通信業・宿泊者数と同じ方法（2-2）で計算します。
- **合算**：M+N、R+S は節の値を足した系列です。連鎖実質（LR）は加法性がないので近似です。T（雇用主としての世帯）は日本の「その他のサービス」に含まれるか未確認のため足しません。
- **代理は参考**：「（代理）」付きの指標は参考フラグ付きで、額が出ても合計に入れず、公開せず、議員への配分に使いません。影響段階の向きが「上昇／低下」の行は、損失額の表でも「上昇／低下」と書きます。
- 経済全体の指標を固定していない（`impact-batch.ts`）ため、影響段階は段階1までで、額は段階1の参考として計算される見込みです。
