# impact-v1（評価対象の法律を一括で影響段階にかける）

`bill-triage-v1` で評価対象になり、施行日が確定している法律に、取得済みの統計から系列を当てて、判定ルール `impact-rule-v1`（`app/src/impact-rule.ts`）で影響段階を出します。判定の計算は `impact-rule.ts` だけが行い、この段階では系列を選んで窓を作るだけです（ロジックを1か所に保つため）。

## 入力

| 入力 | 使う行 |
|---|---|
| `data/derived/bill-triage-v1/triage.csv` | 結果＝評価対象（349本） |
| `data/acquired/enforcement-dates/enforcement.csv` | 施行日が空欄でない行。評価対象との重なりは140本 |
| `data/acquired/domestic-stats/*.csv` | 国民経済計算（経済活動別GDP）、消費者物価指数（品目別）、宿泊旅行統計、労働力調査（産業別就業者） |
| `data/acquired/intl-stats/intl-stats.csv` | 13か国の OECD 消費者物価・世界銀行 WDI |
| `data/acquired/more-stats/*.csv` | 日本銀行 貸出先別貸出金、総合エネルギー統計（年度）、世界銀行 WDI の追加分（不良債権比率・与信のGDP比・エネルギー集約度・発電比率）。雇用動向調査・労働力調査の転職・毎月勤労統計・金融庁の不良債権は読み込むが、判定には使わない（下の「比較群なし」） |

インターネットからは何も取っていません。取得済みの統計に合う系列がない指標は「系列なし」とし、値を作っていません。

## 再実行

```sh
cd app && node scripts/run-impact-v1.mjs   # Node 22.18 以降（型注釈は Node が取り除く）
```

`app/src/impact-batch.ts` が対応表（`INDICATOR_MAP`）と窓の作り方を持ち、`app/scripts/run-impact-v1.mjs` が CSV の読み書きだけをします。`indicator-map.csv` も同じ対応表から書き出すので、表とコードはずれません。

## 方法

### 1. 指標 → 系列（`indicator-map.csv`）

- 比較群は「その分野の値」対「経済全体の同じ種類の値」です（付加価値なら実質GDP、就業者なら就業者総数、物価なら総合指数、宿泊者数なら実質GDP）。分野の値が経済全体より開いたかどうかを、判定ルールの「対象−比較」の差で見ます。
- 対応の強さを「直接」「代理」「系列なし」で書きます。代理は、指標そのものではないが近い系列（例：旅客輸送の付加価値 → 貨物・郵便を含む運輸業の付加価値）。代理で出た判定には理由欄に「代理系列」と書きます。
- 経済全体の指標（段階2の条件）は、狙った指標とは別の系列を当てます（例：情報通信業の付加価値が狙いなら、情報通信業の就業者数対総数）。
- 分野の GDP 比（段階3の条件）は、開始前最後の年の名目の分野付加価値÷名目「合計」です。
- 国際比較は、国際統計に同じ定義の系列がある指標だけです（電力価格＝OECD CPI 04.5、ブロードバンド普及率＝インターネット利用者比率、労働生産性＝実質GDP÷労働力人口、不良債権比率＝世界銀行 FB.AST.NPER.ZS、貸出残高＝預金銀行の民間向け与信のGDP比、発電構成＝化石燃料の発電比率、エネルギー効率＝一次エネルギー集約度）。
- 追加した国内の組（more-stats）:
  - 貸出残高：日本銀行の総貸出（国内銀行、12月末残高）対 名目GDP（貸出の量が経済の規模より伸びたか）。どちらも暦年で、国民経済計算の基準ごとに候補を作り、基準はつながない。経済全体の指標は金融・保険業の実質付加価値対実質GDP、GDP比は金融・保険業。信用金庫・政府系金融機関の貸出を含まないため代理。貸出が多いほど良いとみなす（機械的な仮定）。
  - 発電構成：ゼロエミッション電源の発電量 対 総発電量（部分対全体、年度）。電源構成は2010年度からしかない。経済全体の指標は電気・ガス・水道業の実質付加価値対実質GDP。
- 国内に比較群がない指標:
  - 不良債権比率：対象の法律（預金保険法・金融再生法など）は全国の銀行に及ぶため、影響を受けない国内の比較群がありません。金融庁の全国銀行の系列（more-stats/npl_fsa_all_banks.csv）は取得しましたが国内の判定には使わず、判定ルールが比較群なしで扱える国際比較だけを行います（判定は「国内系列なし」、段階は最大1）。金融再生プログラム用の主要行対地域銀行の比較群（`app/src/case-evaluation.ts`）も、全銀行に及ぶ法律では比較群も同時に影響を受けるので流用しません。金融庁と世界銀行は定義が違うので、日本の値も世界銀行の系列を使います。世界銀行の日本の値は2010〜2022年だけです。
  - エネルギー効率：「最終エネルギー消費÷実質GDP」を国内で作るには、年度の総合エネルギー統計と暦年の国民経済計算を組にする必要があり、期間が3か月ずれるため作りません（取得済みの国民経済計算に年度の表はない）。国際比較（世界銀行の一次エネルギー集約度、2000〜2022年、日本の開始前最後の年=100）だけを行います。最終消費ではなく一次供給なので代理です。
  - 賃金・雇用の流動性：毎月勤労統計、雇用動向調査（入職率・離職率・転職入職率）、労働力調査（転職者比率）は取得しましたが、対象の法律（雇用保険法・労働基準法など）は全産業の労働者に及ぶため、分野対経済全体の比較群が作れません（労働生産性と同じ考え方）。国際の系列も未取得です。判定は「比較群なし」とし、判定ルールを呼びません。年齢・性別・就業形態・産業の区分で、法律ごとの対象の集団と全体を比べる方法はありえますが、法律ごとに対象を決める必要があり、指標ごとに1つの対応に固定するこの段階では行いません。
- 系列なしのまま：企業倒産件数（公式の司法統計を取得できず、民間の集計は使わない）、電子申請率（年度ごとのPDFだけで表形式の公式系列がない）、行政手続きの時間（公式系列がない）、ネット企業の時価総額（業種別の公式系列がない）、利用件数（輸送統計が未取得で、対象の交通機関も法律ごとに違う）。

### 2. 窓の作り方

- 年の値は暦年で、期末日を `YYYY-12-31` とします。判定ルールは期末日が施行日より前の年を開始前、以後を開始後とするので、施行年は開始後1年目（立ち上がりとして除外）、施行の翌年〜4年後が開始後2〜5年目になります。
- 年度の系列（総合エネルギー統計）は、期末日を翌年の `03-31` とし、4月始まりの年度で数えます（1〜3月の施行は前年度が開始後1年目）。年度の系列は年度の系列とだけ組にし、暦年の系列とは組にしません（`FISCAL_YEAR_FILES` とテストで確認）。経済全体の指標は別の組なので、暦年のまま使います。
- 日本銀行の貸出は12月末の残高をその年の値とします（足したり平均したりしていない）。
- 基準年・産業分類の違うファイルはつなぎません（`PROJECT_SSOT.md` の系列接続禁止）。候補のファイルのうち、判定に必要な10年（施行年の5年前〜4年後）で対象と比較の両方に値がある年が最も多いものを選び、同数なら新しい基準を選びます。
- 対象と比較は、開始前最後の共通年を100にそろえます（単位の違う系列を同じ物差しにするため）。比率（%）の国際系列はそろえません。
- 国際比較では、日本の開始前最後の年を全員100にそろえ、その年の値がない国は比較国から外します。
- 空欄の年は空欄のまま（0で埋めない）。同じ年に違う値があれば止めます。

### 3. 判定

- 国内の系列があれば `judgeImpact`、国際の系列があれば `judgeAcrossCountries` を呼びます。国際比較は経済全体の指標を渡さないので、段階は最大1です。
- 対応が「比較群なし」の指標は判定ルールを呼ばず、判定欄を「比較群なし」にします。
- 国際比較で日本に開始前の値が1つもない場合は、比率の系列でも比べず「保留」（理由「日本の開始前の値がない」）にします。
- 判定が出せないもの（開始前が3年未満、開始後2年目以降が2年未満）は「保留」で、理由欄に「期間が足りない」と書きます。
- 判定ルールは同時期の別の出来事（条件3）を扱いません。代わりに、開始後2〜5年目に2020〜2022年（新型コロナ）が入る法律には、理由欄に機械的に注意を付けます。判定は変えません。

## 出力 `impact.csv` の列

| 列 | 中身 |
|---|---|
| id, 題名, 分野, 指標, 施行日 | 入力のまま（題名は enforcement.csv） |
| 系列 | 使ったファイルと列、そろえた年、経済全体の指標、GDP比 |
| 判定 | 段階1〜3／保留／系列なし／比較群なし（系列は取得したが比較群がなく国際の系列もない）／国内系列なし（国際比較だけの指標） |
| 向き | 貢献／悪影響。保留でも、効果が計算できた場合は判定ルールが記録した向きを残す（段階が付いたという意味ではない） |
| 効果, ばらつき | 判定ルールの効果（開始後2〜5年目の差の平均−開始前の差の平均、指数ポイント）と、開始前の差の標本標準偏差 |
| 国際比較 | `judgeAcrossCountries` の段階・向きと、比較国数・条件を満たした国数。系列がなければ「系列なし」 |
| 理由 | 判定ルールの理由文、系列なしの理由、代理系列の注記、新型コロナの注意 |

`indicator-map.csv` には「取得済みだが判定に使わない系列」の列があり、比較群なし・国内では作らない指標で、取得したのに使わなかった系列を書いています。

## 限界

- 同じ系列を、施行時期の近い複数の法律が使います。窓が重なるので、判定は互いに独立ではありません。同じ年に施行された同じ指標の法律は、まったく同じ判定になります。段階は「その法律の効果」ではなく「施行の前後で系列の差が開いたか」です。
- 分野対経済全体の比較は、産業構造の長期的な変化（情報通信業の伸びなど）や景気の波も拾います。開始前の傾きの除去（段階3の条件）は開始前5点の直線だけです。
- 追加した貸出残高は、1998〜2003年の銀行危機・不良債権処理による貸出の縮小、2009年の名目GDPの落ち込み（分母）、2020年の新型コロナの緊急融資を、法律の前後の差として拾います。判定ルールは同時期の別の出来事を除きません。政府系金融機関の法律（日本政策投資銀行・商工中金・日本政策金融公庫・国際協力銀行）も、国内銀行の貸出で測っています。
- 発電構成の開始前の窓（2014〜2018年度）には、東日本大震災後の原子力発電所の停止と再稼働が入り、開始前のばらつきが大きくなります。
