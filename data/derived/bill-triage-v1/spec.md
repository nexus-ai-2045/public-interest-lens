# bill-triage-v1（法律の振り分け）

入力の各行（成立した法律1本）に、題名と付託委員会だけから次の4項目を付ける。推測で埋めず、迷ったら「保留」。

1. 種類（どれか1つ）
   - 新規：新しい法律を作る（題名が「〜の一部を改正する法律案」ではない、かつ廃止・整備法でない）
   - 実質改正：規制・制度・税率・対象範囲などの中身を変える改正
   - 定型改正：毎年の税法改正の定例部分、給与法（一般職・特別職・裁判官・検察官・防衛省職員などの給与）、期限の延長だけ、名称・字句の整理だけ
   - 組織手続：省庁の設置法、定員、組織の再編、手続き・事務の整理、整備法（関係法律の整備）
2. 分野（どれか1つ）：金融／交通・移動／宿泊・観光／通信・ネット／半導体・電子／エネルギー／労働市場／行政のデジタル化／対応表なし
   - 上の8分野のどれにもはっきり当たらなければ「対応表なし」（農業・医療・教育・防衛・司法・選挙・外交なども対応表なし）。
3. 指標（分野が8分野のときだけ、分野ごとに下から1つ。対応表なしなら空欄）
   - 金融：不良債権比率／貸出残高／企業倒産件数
   - 交通・移動：旅客輸送の付加価値／利用件数／就業者数
   - 宿泊・観光：宿泊者数／宿泊業の付加価値／客室数
   - 通信・ネット：通信業の付加価値／ブロードバンド普及率／ネット企業の時価総額
   - 半導体・電子：世界輸出シェア／生産額
   - エネルギー：電力価格／発電構成／エネルギー効率
   - 労働市場：労働生産性／賃金／雇用の流動性
   - 行政のデジタル化：電子申請率／行政手続きの時間
4. 判定：評価対象／評価対象外
   - 評価対象外：種類が定型改正か組織手続、または分野が対応表なし。
   - 評価対象：それ以外（新規か実質改正で、8分野のどれか）。
   - 理由：短く1文（例「給与法の定例改正」「農業分野で対応表なし」）。

出力 CSV の列（ヘッダー行を付ける、UTF-8）：id,種類,分野,指標,判定,理由
入力の全行を、入力の順で、1行ずつ出す。行を飛ばさない。
