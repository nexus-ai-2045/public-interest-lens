# 学習記録：全体指標の産業への結び直しと、定例除外の再判定（macro-sector-v2、2026-10-29）

目的：額なし・全産業（_T）で測っていた法律の質を上げる。ねく（2026-10-29）「全部を数字に」「精度は95%」。
出力（根拠は2つの表だけ。計算はここから読む）：
- `data/derived/macro-v1/sector-overrides.csv`（id・節・由来）：全産業で測っていた法律を産業の節で測り直す。`scripts/build_macro_amounts.py` の `apply_sector_overrides` が読む。振り分けで産業が決まった行は変えない。
- `data/derived/all-laws-v1/exclusion-overrides.csv`（id・理由）：定例・対象外と決めた法律のうち、実質的な制度変更を含むと再判定したもの。`scripts/build_all_laws_outcomes.py` の `apply_exclusion_overrides` が保留に戻し、macro-v1 が参考の額を付ける。規則 RT1〜RT8 の語は変えない。
木の定義：`scripts/workflows/macro-sector-tree.js`（Haiku 2系統→不一致だけ Sonnet→変更案だけ Opus）。

## 木の形と結果
- A（定例除外・対象外 375本）：Haiku 2系統が「定例のまま／実質変更」を判定。実質変更 57本→Opus 51本を採用（6本は定例のまま）。
- B（全産業 1,303本）：主な産業を選ばせた。非市場（公務・司法・防衛・選挙）741、経済全体 379、産業に結べる 184→Opus 104本を採用。
- エネルギー分野（振り分け・AI 2系統）は ISIC D（電気・ガス・蒸気・空調）で測る（D の外の石油・石炭・原子力規制も含めた代理）。
- 失敗：Haiku 1束で構造化出力が返らなかった（Sonnet が補った）。Opus の確認は変更案だけ。

## 誤りの型（次の巡で直す）
1. 非市場 741本は全産業のまま。公務（ISIC O）で測る案は「費用で測る非市場の付加価値で、高いほど良いと読めない」（docs/提案/分野の拡張-v1.md 3-1）ので採らない。
2. 議員歳費・秘書給与など公務内部の法律が実質変更と再判定された（A 系列）。全産業の参考の額が付くが、効果の経路は弱い。確かさは参考のまま。
3. OECD 表6は改定される。`industry_va.csv` を Git に入れて版を固定した（約5MB）。取り直すと数字が動くので、取り直しは PR で差分を見る。
