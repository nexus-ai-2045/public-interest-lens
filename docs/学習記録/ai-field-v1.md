# 学習記録：AI 2系統による分野の振り分け（ai-field-v1、2026-10-17）

対象：施行日があり、振り分け（all-laws-v1）で分野が「対応表なし」か空の法律1,071本。
出力：`data/derived/ai-field-v1/labels.csv`（id・分野・決め方・理由）。`scripts/build_macro_amounts.py` が産業の選択に使う。

## 木の形（1巡目）
1. Haiku：1個あたり6本。系統A（題名の対象の産業）と系統B（行動が変わる事業者の産業）を別々に判定。179束×2＝358個。
2. Sonnet：10束ごとに1個（18個）。2系統の食い違いだけを題名を読み直して決める。決め手が無ければ「経済全体」に倒す。
3. Opus：3個。Sonnet が決めた分を分野をまたいで見直し、誤りだけ直す。
4. スレッド本体：取り込み、全体指標の額を計算し直し、出典チェックとテストを通す。
5. 毎日の自動更新：出典チェックの食い違いは公開から外し、次の巡で見直す。

## 結果
- 1,072行（一致978・Sonnet が決定64・経済全体に倒した23・Opus が修正7）。一致率は約91%。
- 分野：経済全体899、医療・福祉29、農林水産23、建設23、交通・移動14 ほか。

## 見つかった誤りの型（次の巡の入力）
| 型 | 例 | 次の巡の規則 |
|---|---|---|
| 同じ題名の法律が回ごとに別の分野になる | 温暖化対策法（208-25 と 211-12）、都市緑地法（193-24 と 213-18）、入管法 | 最初の法律の題名が同じなら同じ分野に揃える（多数決、同数なら経済全体） |
| 独立行政法人・機構の法律で「経済全体」と「主業務の産業」が割れる | 緑資源機構、地域経済活性化支援機構 | 機構の主業務の産業を採る（設置法の目的の条文を見る） |
| 健康被害の救済・給付で「経済全体」と「医療・福祉」が割れる | 石綿救済法、B型肝炎給付 | 医療・福祉に揃える |
| 出入国管理・防災・DV など産業横断の制度 | 入管法、地震防災 | 経済全体に揃える |

## 注意
- AI の振り分けは産業の選択だけに使う。額は OECD 表6 の公的統計から機械的に計算し、確かさは「参考（全体指標）」のまま。
- 議員への配分には使わない。

## 規則の変更（2巡目、2026-10-17）
- 誤りの型1（同じ題名で分野が割れる）を `scripts/build_macro_amounts.py` の `align_by_title` に入れた。元の題名（「の一部を改正する法律」などを除く）が同じ本は、産業の分野が付いた本の最多の分野にそろえる。同数ならそのまま、振り分けで決まった本は変えない。
- 当てはまったのは78本（由来「同じ題名にそろえた」）。題名の割れは67組248本あり、残りは同数か、すでに同じ産業だった。
- 公開本数は変わらない（額つき2,848本・理由つき567本）。出典チェックの不一致は遡及の4本のまま。
- 試験：`tests/test_macro_amounts.py` の AlignByTitleTest。

## 3巡目（2026-10-17 夜）
- 公布日の推定で全体指標の対象に増えた671本に分野を付けた（一致593・Sonnet が決定58・経済全体に倒した15・Opus が修正5）。
- 誤りの型：ワークフローの出力の形に日本語のキー（種類・分野・誤りの型）を使うと、Opus の段で受け付けられず落ちた。木のスキーマのキーは ASCII（kind・field・reason・how）にし、表に書くときに日本語の列名へ直す（scripts/workflows/triage-tiebreak-tree.js）。
