## 誤りの型（Opus が返したもの）
| 型 | 例 | 次の規則 |
|---|---|---|
| 同じ法律の改正なのに種類や分野が違う | 市町村合併特例法、国立国会図書館法、港湾法、原子力損害賠償法 | **2回目**（ai-field-v1 の型1と同じ）。規則にはしない（1回目の評価ループで残りを測った結果、下の「毎日の評価ループ 1回目」を参照）。Opus の確認で直す |

## 2系統の食い違いの決着（R2、2026-10-18）
振り分け v2 で系統1と系統2が食い違って保留だった141本を、Haiku 2系統、Sonnet の突き合わせ、Opus の確認の順で「どちらの系統を採るか」だけ決めた（規則 TB2）。結果は `data/derived/bill-triage-v2/tiebreak-lines.csv`、木は `scripts/workflows/triage-lines-tree.js`。

- 採るのは Haiku 2系統が独立に同じ系統を選んだ決定（決め方＝一致）だけ。Sonnet・Opus が単独で決めた行は、ADR 0007 の「2系統の AI が一致したものだけ採用」に当たらないので保留のまま（Codex の指摘、PR #119）。
- 判定者には v2 の基準（bill-triage-v2/spec.md、系統2の criteria.md・criteria-v2-fields.md）を渡す。1回目は旧 v1 の spec を渡したため、新分野（農林水産など）を「対応表なし」とする誤った理由で選んだ行があり、全件を判定し直した（Codex の指摘、PR #119）。
- 2回目は main の法律の概要の拡張（PR #110）の後で、141本のうち121本に提案理由の要約があった。
- 141本：系統1を採った52本・系統2を採った52本（いずれも一致）が採用。Sonnet・Opus の単独の決定12本と保留25本は保留のまま。
- 2系統の採用は2,609本から2,713本、保留は141本から37本になった。保留の行は翌朝のループの「系統の決着」に毎回入り、要約が増えれば再判定される。

| 型 | 例 | 次の規則 |
|---|---|---|
| 旧基準を渡して新分野を対応表なしとする | 1回目の「農林水産は対応表なし」 | v2 の基準を渡す（済） |
| 要約が無い行で推測して実質改正にする | 独立行政法人法・協会法の改正 | Opus の確認で保留に戻す（現行どおり） |
| 非公務員型への移行の種類が割れる | 閣法-164-7・164-35・166-17 | 単独の決定なので保留。同じ型が続けば規則を検討する |
