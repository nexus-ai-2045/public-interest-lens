# 学習記録：経済への直接効果の判定（econ-relevance-v1、2026-10-30）

対象：全法律の結果で、市場の産業の対応表が無く「代理指標を題名の語で当てただけ（MA 規則）」か「代理指標なし」だった 1,599 本。
出力：`data/derived/econ-relevance-v1/labels.csv`（id・区分・分野・決め方・理由）。`scripts/build_all_laws_outcomes.py` が読む。

## 区分
- 制度：国・自治体の組織・手続・選挙・司法・人事・名称変更などで、民間の売上・費用・給付・税・規制の負担を直接は変えない → 結果「評価対象外」、経路「経済への直接効果なし」（692 本）。経済に絞る方針（ねく 2026-10-29）の外。全体指標の参考の額も付けない。
- 経済に効く：民間のお金の流れを直接変える（670 本）。結果は変えない（保留のまま、全体指標の参考の額を付ける）。分野は参考情報。
- 判定不能：材料が足りない・単独の決着・金銭の義務や請負規制に触れる（236 本）。結果は変えない。

## 木の形
1. Haiku 2系統（観点A＝対象が民間の産業か国の内部か、観点B＝「成立しなかったら民間の誰かのお金の流れは変わっていたか」）。8本×200束×2。
2. 一致したものだけ採用。割れたもの・判定不能は Sonnet が1束ずつ決着（254 本）。
3. Opus が制度と判定された 165 本（一致の8本に1本＋Sonnet 決着の制度60本）を抜き取り検査：誤り 4 本（2.4%）。誤りは「経済に効く」に直した。
3b. 自動レビューの指摘（Codex P1）：理由に「材料なし・不明・読み取れない」とある制度判定13本は「判定不能」に降格した（影響が不明なことは影響が無い根拠にならない）。
3c. 自動レビューの指摘（Codex P1 2回目）：賠償・損害・補償・債務・担保・供託・支払に触れる制度判定14本も「判定不能」に降格した（司法分野でも民間の支払義務を変える法律がある）。
3d. 自動レビューの指摘（Codex P1 3回目）：Sonnet 1系統だけで決着した制度判定116本は、ADR 0007（独立した2系統が一致したものだけ採用）に合わないので「判定不能」に降格した。制度として採用するのは2系統が一致した分だけ。
4. 抜き取り外の制度判定にも同程度（約2〜3%）の誤りが残りうる。公開時に「AI 判定」と明記し、訂正は Issue の窓口で受ける。

## 結果
全法律の結果：評価対象外 28→718、保留 1,925→1,366、測定できない 920→789。額ありは変わらない（219）。
