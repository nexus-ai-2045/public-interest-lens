# 提案：分野の拡張 field-expansion-v1（対応表なしの実質法を、産業別の付加価値で同じ方法に載せる）

日付：2026-10-17。状態：提案（未承認）。設計決定0007 §5 の「事前に固定するルール」に当たるので、採用には人の承認が要ります。この段階では、既存のコード（`app/src/`）、派生データ（`data/derived/` の既存ディレクトリ）、`bill-triage-v1/spec.md`、`bill-triage-v2/spec.md` を変えていません。足したのは、この文書、見積りの `scripts/estimate_field_expansion.py`、そのテスト、見積りの出力 `data/derived/field-expansion-estimate/estimate.csv` だけです。

## 1. 問題

- 成立した法律3,415本のうち、種類が新規・実質改正の法律は2,284本（新規682・実質改正1,602）です（`bill-triage-v1/triage.csv`）。
- 評価の対象は8分野（金融／交通・移動／宿泊・観光／通信・ネット／半導体・電子／エネルギー／労働市場／行政のデジタル化）だけです。実質法のうち**1,662本**（評価対象外の1,662本。ほかに2系統が食い違った保留2本）は、分野が「対応表なし」であるためだけに評価の外にあります（農業・環境・医療・教育・司法・選挙・防衛・年金・防災・住宅・建設など）。
- 評価は、分野の指標を「国内の対象と比較群の差（`impact-v1`）」と「日本と比較国の同じ産業の付加価値の差から出す損失額（`loss-v1`）」で測ります。この2つが必要とする系列は、産業別の付加価値です。国民経済計算（以下 SNA）は**全産業**の実質・名目付加価値を持っています。足りないのは、OECD の産業別付加価値のうち ISIC の節 H・I・J・K・_T だけを取得している点です（損失額用）。

## 2. 方針（同じ方法のまま、分野と指標だけを足す）

- **指標は1分野につき1本**で、その産業の実質付加価値（既存の「通信業の付加価値」「宿泊業の付加価値」「旅客輸送の付加価値」と同じ型）にします。向きは「高いほど良い」です。
- **国内（`impact-v1`）**：日本の SNA の産業の実質付加価値（連鎖方式）対「合計」の指数（開始前最後の年=100）。基準（2020・2015・2011・2005・2000）ごとに候補を作り、基準どうしはつなぎません（既存の `snaVsGdp` と同じ）。経済全体の指標（`share`）には名目の産業÷「合計」を使います。
- **国際（`loss-v1`）**：日本と比較国の同じ産業の付加価値を OECD 表6（`OECD.SDD.NAD,DSD_NAMAIN10@DF_TABLE6,2.0`）で比べます。ISIC Rev.4 の節で対応づけます。
- **事実は一次資料と公的統計だけ**です（設計決定0007 §1）。使うのは内閣府の国民経済計算、OECD の国民経済計算、題名（法律の公布文）だけで、報道・評判・所属は使いません。
- **分野の決め方**は `bill-triage-v2` の D1・D2 のままです。題名に含まれる語のうち、題名で最も前に出る語の分野に決めます（D1）。「及び〜設置法」「及び〜整備法」は除いて最初の法律で決めます（D2）。同じ位置で別の分野の語が重なれば保留です（D5）。追加で次の2点を決めます。
  - **既存優先**：既存8分野の語（`scripts/triage_v2_line2.py` の `FIELD_WORDS`）が題名に1つでもあれば、現行の規則のまま既存分野にします。新分野の語は、既存の規則で対応表なしになる題名にだけ当てます。これで、既に評価した法律の分野は変わりません（確認：`bill-triage-v2/labels-line2.csv` の349本のうち既存分野が決まっている324本は、語を足しても0本が変わる）。
  - **語の包含**：同じ位置の語が別の語の一部のとき（例：「土地」と「土地改良」）は長い語を採ります。

**取得の手順（採用後。この提案では実行しません）**

1. `scripts/fetch_oecd_industry.py` の `ACTIVITIES` に上の14個を日本語の名前つきで足す（`parse_table` は `ACTIVITIES` に無い産業を捨てるので、足さないと表に出ない）。既存のテスト `tests/test_fetch_oecd_industry.py` は URL の産業部分を `_T+J+I+K+H` に固定しているので、同時に直す。

**未確認で、結果に響く点**

- **合算の問題**：M と N、D と E、R と S（と T）は、SNA では1つの行ですが、OECD では別々の節の可能性があります。連鎖実質（`L`・`LR`）は加法性がないため、節を足して集約を作ると近似になります。OECD が集約コード（例：M_N）を返すなら、それを使う。返さなければ、名目 `V`（足してよい）で比較国の産業の大きさを示し、実質は近似として注記するか、その分野の国際比較を保留にします。
- **国による欠け**：既存の取得でも H は他の産業より行が少なく（1,370行、他は1,394行）、国と年の欠けがあります。新しい節でも同様です。欠けた年は補間せず、比較国から外します（既存の規則）。
- **年度と暦年**：AUS は年度の可能性があり、ITA は2010年に系列の断絶があります。既存の `loss-batch.ts` の `excludeIfCrossing` と注記の仕組みをそのまま使います。

**コード側の追加（採用後）**：`app/src/loss-batch.ts` の `LOSS_SOURCES` に10行（指標・SNA の候補・`oecd: { industry: 'A' }` など）、`app/src/impact-batch.ts` の `SNA_NAMES` に10キーと `indicator-map` の10行を足します。これらは現状のまま変えていません。

## 8. 限界（正直な書き方）

- **評価できるのは約4割＋α**：新分野に入るのは1,662本のうち648本（39%）です。残りは意図して対応表なしにするか（777本）、既存の語表の問題で既存分野に入ります（237本）。「ほとんどの法律を評価に載せる」ことはこの提案ではできません。
- **代理が多い**：648本のうち426本が代理です。教育・医療・福祉は、SNA の実質付加価値が**提供量（人員・時間）で測られる**側面があり、付加価値が上がっても質や成果が良くなったとは限りません（学級編制の改善で教員が増えれば付加価値は増えるが、成果の測定ではない）。不動産業の付加価値の大半は持ち家の帰属家賃で、法律の効果にほぼ反応しません。文化・娯楽は産業の括りが広く、法律の対象と産業が重なる割合が小さいです。
- **向きが機械的**：「高いほど良い」は仮定です。漁業資源の保護、廃棄物の規制、医療費の抑制、建築規制の強化などは、付加価値を下げることが目的の場合があり、その場合に貢献と読むと逆になります。そのため B4 の「参考」扱いを推奨します。
- **比較群が弱い**：国内の比較は「産業対合計」で、合計に産業自身が入ります。農林水産のように、法律と無関係に長く縮む産業では、開始前の趨勢を引いても差が残ります。影響段階（`impact-rule-v1`）の保留条件で多くは落ちる見込みですが、落ちない場合の因果の主張は既存の8分野より弱いです。
- **国際比較は産業の定義の一致に依存**：OECD の節と日本の SNA の行が1対1に対応する見込みなのは A、C、F、G、L、P、Q です（コードの実在は未確認）。M と N、D と E、R と S は合算の問題があり、5-2 のとおり確認が要ります。
- **題名だけの判断**：語が主題を表さない例（「人権教育」「私立学校教職員共済法」）が残ります。D2 は設置法・整備法の部分だけを除きます。複数の法律を改正する題名の2つ目以降の主題は見ません。
- **データの範囲**：教育・医療・専門サービス・その他のサービスは2011基準以降だけで、基準を超える長さの系列はつなぎません。2011基準は2018年で終わるため、それ以降の効果は2015・2020基準の候補で見ます。
- **既存の語表の問題は残る**：237本が既存分野に入る問題（災害44・再生43・保険41・手続18）は、この提案では直しません（B8）。
- **この見積りは何も証明しない**：学習内の当てはめであり、新しいデータでの検証ではありません。独立の別セッション・別モデルによる確認は未完了です（`bill-triage-v2/spec.md` の独立性の限界と同じ）。
