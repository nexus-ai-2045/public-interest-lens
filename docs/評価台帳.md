# 評価台帳（全法律の評価の到達点・方法・検証状態）

このファイルは `python3 scripts/build_evaluation_ledger.py build` が作ります。手で直さないでください。
1本ごとの表は `data/derived/evaluation-ledger-v1/ledger.csv`（3,426本）。

**分類の2系統照合は『分類』だけを確かめたもの。向き・類型・額まで確かめたのは抜き取り検証だけ。抜き取りで不合格だった法律のうち、額を順位・議員配分に使わない（参考値）ものは『参考に下げた』（額と根拠は参考値として出し続ける）、額の無いものは自動では下げず『抜き取り検証で不合格』のまま数える。不合格のまま残った法律は、一次資料を読み直して1本ずつ決着させる（`sample-resolutions.csv`、記録は `reverification-v1/`）：サイトに誤りが無かったものは『抜き取り検証で合格』に訂正し、サイトの値がまだ直っていないものは『参考に下げた』にして、サイトの値と読み直しの値を並べて出し続ける。**
