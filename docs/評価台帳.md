# 評価台帳（全法律の評価の到達点・方法・検証状態）

このファイルは `python3 scripts/build_evaluation_ledger.py build` が作ります。手で直さないでください。
1本ごとの表は `data/derived/evaluation-ledger-v1/ledger.csv`（3,415本）。

**分類の2系統照合は『分類』だけを確かめたもの。向き・類型・額まで確かめたのは抜き取り検証だけ。抜き取りで不合格だった法律のうち、額を順位・議員配分に使わない（参考値）ものは『参考に下げた』（額と根拠は参考値として出し続ける）、分類を決め直す必要があるものは『抜き取り検証で不合格』のまま数える。**
