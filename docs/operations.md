# 公益レンズの検証・運用・残務

正本: [`PROJECT_SSOT.md`](../PROJECT_SSOT.md)。今回の保証はローカル算定と限定取得の再現性まで。常時稼働、実在評価の正しさ、全量取得、公開運用は未保証。

## 起動と検証

リポジトリ直下から実行する。`Node.js` 22以上、`Python` 3.12以上を使用する。

```powershell
python -m unittest discover -s tests -v
cd app
npm ci
npm test
npm run build
npm audit --audit-level=moderate
npx playwright install chromium
npm run test:e2e
npm run dev
```

`test:e2e` は専用ポート4179でヘッドレスブラウザを起動し、テスト終了時に自身のサーバーを閉じる。使用中ポートは奪わずエラーにする。通常閲覧は5173。スクリーンショットは`Git`対象外の `app/test-results/` に出力する。既存`Chrome`やログイン済みブラウザの状態は操作しない。

`CI`の `.github/workflows/verify.yml` は`Python`、算定、型・`build`、依存監査、`E2E`を同じ`PR`で実行する。公式`API`へのライブリクエストは`CI`に含めない。実行前の設定だけで`CI`成功としない。

## 取得と障害時の復旧

`docs/diet-data-coverage.md` の既存コマンドと `data-sources/diet-official-sources.yaml` を使用する。同じ取得器を増やさない。最初は `--max-pages 1` と専用の `.local/` 出力先を必須にする。

成功の判断は終了コードだけでなく`manifest`の `status`、`complete`、`corpus_complete`、保存件数と`API`報告件数で行う。`capped` は上限到達、`query_exhausted` は指定検索の終端であり、国会データ全件の網羅ではない。

| 検出 | 担当と修復 |
|---|---|
| `timeout`・`HTTP`・総数変化・不正ページ | 収集担当が`failed` `manifest`を確認。連打せず原因を解消し、同一条件で再開 |
| `hash`・`checkpoint`範囲不一致 | 収集担当が原本を保全。別出力先で再取得し差分を比較。削除してごまかさない |
| 算定参照不備・重複・係数範囲外 | 評価データ担当が失敗テストと該当入力を照合。値を黙って補完しない |
| 順位の異議・反証追加 | 評価責任者が政策検証記録を改版し、同じ入力版の全人物を再計算 |
| `CI`未開始・課金制限 | 開発担当がローカル結果と区別し、`CI`実行を完了条件に残す |

長時間取得前に空き容量、対象会期、ページ上限、担当、停止条件を記録する。重複実行や資源の点検は既存 `runtime-process-guard` に戻す。スケジューラ・通知・権限設定は本`PR`で変更しない。

## 残務の所有と再開条件

| 項目 | 担当 | 次の手順・完了条件 |
|---|---|---|
| 今回のコード・`CI`・`PR`回収 | 本タスクの開発担当 | 同一`HEAD`の`CI`・未解決レビュー・`mergeability`を回収 |
| 実在データ契約 | 本タスクの開発・評価担当 | 原資料`URL/hash`/観測時刻/レビュー担当、人物同定・役職期間を必須化した別データ版を実装。架空版の`flag`を外すだけで実在化しない |
| 最初の実政策分野・係数の妥当性 | ねくと評価担当 | 調査範囲、比較対象、結果指標、反証、帰属ルールをレビュー |
| 40〜50年間の`coverage` | 収集担当 | 公式ソースごとに取得・正規化・照合を完了し、既知欠落を記録 |
| 常時同期・容量・監視 | 運用担当 | 有限ページの反復、容量と失敗検知のリハーサル後に長期取得を開始 |
| 人間目視・`merge`・公開 | ねく | `human-review-checklist.md` と正確な`PR`差分を確認。`merge`・公開は実行していない |
| 旧タスク・タブの回収 | 本タスク | `docs/context-absorption.md` に回収範囲と未確認を記録。旧タスクの無関係残務は消さない |

最小の改善ループは「入力範囲を固定 → 取得/算定 → テストと`manifest` → 不一致を担当へ戻す → 同じ検査」。自動点検から実在人物の評価判断や公開承認を推定しない。
