# ChatGPT 画像生成プロンプト（国賊ランキング デモ用）

2026-10-11 作成。色・文言はデモ（PR #21 の `site/src/styles.css` と `App.tsx`）から取った。

## 正本と流れ（SSOT）

- このファイルが正本。ChatGPT 側のプロジェクト、カスタム指示、メモリには何も置かない。
- 流れは一方向：このファイルからコピーして貼る → 生成 → 採用した画像をリポジトリに戻す。
- ChatGPT 上で手直ししたプロンプトは正本ではない。直すときはこのファイルを直してから作り直す。
- 配色や文言をサイト側で変えたら、このファイルの色コードと文言も合わせて直す。

## 使い方（先に読む）

1. ChatGPT の新しいチャットに、まず「共通ルール」を貼る。
2. 続けて、作りたい画像のプロンプトを 1 つだけ貼る。1 回に 1 枚が安定する。
3. 日本語の文字は崩れやすい。**文字なしで背景だけ作り、タイトルは後で重ねる（推奨）**。文字入りで試す場合は各プロンプト末尾の「文字入り版」を足す。
4. 採用した画像はリポジトリ（例：`site/public/`）に戻し、そちらを正本にする。

> 認知の罠：画像生成は「それっぽい1枚」が出るまで回し続けやすい。各画像 3 回まで、ダメなら文字なし背景で妥協して先へ進む、と決めておくと止まれる。

## 共通ルール（最初に 1 回貼る）

```
これから Web サービス「国賊ランキング」の告知用画像を何枚か作ってもらいます。以下のルールを全画像に適用してください。

【サービスの概要】
政治家の公開された行動と政策の結果から、日本経済への影響をたどって並べるサイト。悪影響側を「国賊」、貢献側を「国士」と呼び、切り替えられる。今は架空データ版のデモ。

【絶対に守ること】
- 実在の人物、政治家、政党、党のロゴやシンボルカラー、国会議事堂など特定できる建物、国旗・日の丸、家紋、実在のニュース画面を描かない。
- 人の顔を描かない。人物を出す場合も、顔の見えない抽象的なシルエットか、形だけの記号にする。
- 暴力、血、武器、炎上、差別的な表現、特定の集団を攻撃する表現を入れない。
- 写真風ではなく、抽象的でグラフィカルなデジタルアートにする。
- 指定がない限り、文字・ロゴ・透かしを入れない。

【デザインの方向性】
- 線の流れ（細い光の筋が流れる 2D のフローフィールド）がモチーフ。3D の立体物は使わない。
- 余白を広く取り、中央に大きくタイトルを重ねられる構図にする。
- 国賊モード：ほぼ黒の背景 #08080a、くすんだ赤 #d33a43 の細い線が雨のように下へ垂れる。暗く、しょぼくれた、力なくうなだれた雰囲気。周辺は暗く沈むビネット。
- 国士モード：温かいオフホワイトの背景 #fbf7ee、明るい金色 #f0a500 とオレンジの細い線が放射状に弾け、ところどころ水色 #4fd1c5 の小さな光が混じる。明るく、祝福して褒める雰囲気。紙吹雪のような軽さ。
```

## 1. OGP 画像（リンク共有時のサムネ）1200×630

```
横長 1200×630 の OGP 画像を作ってください。共通ルールに従います。
画面の左半分を国賊モード、右半分を国士モードにして、中央で滑らかに切り替わる構図。左は黒地に赤い線が下へ垂れ、右はオフホワイト地に金色の線が上へ弾ける。中央の縦帯は、線の流れが向きを変える境目として描く。
中央から上寄りに、大きな横書きタイトルを後から重ねる余白を空けておく。文字は入れない。
```

文字入り版（足す場合）：

```
中央に太いゴシック体で「国賊ランキング」と横書き。「国賊」の 2 文字だけ赤 #d33a43、「ランキング」は左側が白・右側が黒になるよう背景に合わせる。下に小さく「架空データ版デモ」。文字は正確に、余計な文字を足さないこと。
```

## 2. キービジュアル：国賊モード 1920×1080

```
横長 1920×1080 の背景画像を作ってください。共通ルールの国賊モードです。
ほぼ黒 #08080a の背景に、くすんだ赤 #d33a43 の髪の毛ほど細い線が無数に、上から下へ力なく垂れ落ちる。線はところどころ途切れ、下に行くほど暗く沈む。画面の四隅は深い黒のビネット。
全体に重く、停滞し、うなだれた空気。ただし怖さや暴力性は出さず、静かな寂しさにとどめる。
中央に大きなタイトルを重ねる余白を残す。文字は入れない。
```

文字入り版：

```
中央に太いゴシック体で「国賊ランキング」。「国賊」は赤 #d33a43 で少し右に傾いてうなだれ、「ランキング」は白 #e9e7ec。その下に小さく灰色で「日本の伸びを、誰が止めたか。」。
```

## 3. キービジュアル：国士モード 1920×1080

```
横長 1920×1080 の背景画像を作ってください。共通ルールの国士モードです。
温かいオフホワイト #fbf7ee の背景に、金色 #f0a500 とオレンジの細い線が、中央から外へ放射状に軽やかに弾ける。ところどころ水色 #4fd1c5 の小さな光の粒が舞う。紙吹雪や祝砲のような、明るく誇らしい空気。
線は細く上品に、ごちゃごちゃさせない。中央に大きなタイトルを重ねる余白を残す。文字は入れない。
```

文字入り版：

```
中央に太いゴシック体で「国士ランキング」。「国士」は金色からオレンジのグラデーション、「ランキング」は濃い黒 #1d1a14。その下に小さく茶灰色で「日本の伸びを、誰が押し上げたか。」。
```

```

対角線で 2 分割し、左上を国賊モード（黒地に赤い線が垂れる）、右下を国士モード（オフホワイト地に金色の線が弾ける）にする。境目は線の流れが反転する斜めの帯として描く。
上部と下部に告知文を重ねる余白を空けておく。文字は入れない。

```

