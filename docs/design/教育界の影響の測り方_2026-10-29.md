# 教育界の影響の測り方（education-ledger-v1、R32）

日付：2026-10-29。状態：測り方と帳簿の第1版。経済に絞る（ねく 2026-10-29）。上位の方針は [評価方法設計書](../評価方法設計書.md)（3.0 比べる相手は OECD 中央値、3.2 機構と根拠値、4章 台帳、5章 精度）に従う。
このファイルは教育界（大学・学会・文科行政）の分だけを決める。額は台帳に教育領域の採用値が入るまで出さない（根拠が先、計算は後）。

## 1. 何を測るか（収束：1行で）

**教育界の行動（法律・制度）が、教育・研究の量を OECD の同じ水準の国より動かしたか。動いた分が経済（産業の付加価値）にいくらつながるか。** 前半は実測で今回出した。後半は台帳の根拠値待ち。

## 2. 因果の鎖（議員までつなぐ形）

行動（法律）→ 指標（研究費・研究者数など）→ 機構（効き方）→ 経済（額）。議員は「法律」の先でつなぐ（既存の配分と同じ）。

| 機構 | 中身 | 台帳に要る量（採用されたら額を出す） | 今回の指標 |
|---|---|---|---|
| 研究への公的投入 | 大学・公的研究への資金が生産性を上げる | R&D の収益率・波及（メタ分析） | 研究開発費（大学等・政府部門、対GDP比） |
| 研究人材 | 研究者の数・博士人材が技術進歩を支える | 研究者数と生産性の弾性値、博士の賃金プレミアム | 研究者数（千人の就業者当たり）、研究者に占める大学等の割合 |
| 大学の存在と自律 | 大学の数・制度が地域・国の成長を高める | 大学の経済効果の推計、日本の法人化の差の差 | 同上 |
| 産学連携 | 大学の研究が企業に移る | R&D 波及（メタ分析） | 研究開発費（全体、対GDP比） |
| 人的資本の量 | 就学年数・進学率が賃金・成長を上げる | 就学1年当たり収益率（ミンサー式のメタ分析）、成長回帰 | 高等教育の総就学率（取得済み・日本は2013年以降のみで窓が組めない） |
| 人的資本の質 | 認知スキルが成長を上げる | 認知スキルと成長・賃金（PISA・PIAAC） | **未取得**（PISA・PIAAC。日本は上位で、損失の根拠は弱いと見込む） |
| フロンティア近傍の高等教育 | 先頭に近い国ほど高等教育・研究が効く | 距離別の効果（Vandenbussche ら） | 補正に使う（台帳待ち） |

## 3. 測り方

### 3.1 指標の差の差（今回実装。`scripts/build_education_ledger.py`）

- 比べる相手：OECD 加盟国の中央値。2000年の就業者1人当たり GDP が日本の8割未満の国とアイルランドを除く（22か国採用。理由つきの全表は `comparators.csv`）。年ごとに比較国が3か国未満なら比べない。
- 差 $d_t$ = 日本の値 − 比較国の中央値。施行年 $t_0$ の前3年・後2年の平均を引いた値を「差の差」とする（窓は設計決定0015と同じ固定）。開始前5年の趨勢を後へ延ばして引いた値を並べる（追い上げ・趨勢を効果にしない）。
- 後2年が最新年を超える法律は「暫定」。施行日がない・前の年が足りない法律は「測定不能」。指標を取得していない行動は「指標なし」。
- 1つの観測を複数の法律が共有する（同じ年・同じ指標）。本数を `同じ観測を共有する本数` に出し、足し合わせない。

### 3.2 経済への換算（台帳待ち。式だけ決める）

M2（設計書 3.1）：額 $=\sum_m S_m\cdot\beta_m$。$S_m$ は指標の差（対GDP比のポイント）に名目GDPを掛けた規模、$\beta_m$ は台帳の根拠値（区間）。台帳に値がない機構の額は「未測定」とし、数字を直書きしない。
補正（設計書 3.3）は教育領域では次を入れる：時間の遅れ（研究投資は効くまでに年数がかかる。台帳の期間別の値）、波及（私的収益率と社会的収益率の差）、出版バイアス補正後の値を中心にする、追加性（公的資金が民間資金を置き換える分）。

## 4. 最初の実測（indicator-gaps.csv・chains.csv）

日本は研究費の総額（対GDP比）も研究者数も、OECD の中央値より高い水準にある。ただし**大学部門の研究費は日本が横ばいで、比較国が伸びた**。

| 指標 | 日本 2003 → 2020 | 比較国中央値 2003 → 2020 | 差（日本−中央値）2003 → 2020 |
|---|---|---|---|
| 大学等の研究開発費（対GDP比、%） | 0.409 → 0.382 | 0.413 → 0.592 | −0.004 → −0.210 |
| 研究者数（千人の就業者当たり） | 10.1 → 10.1 | 7.4 → 11.1 | +2.7 → −1.0 |
| 研究開発費の全体（対GDP比、%） | 2.99 → 3.27 | 2.05 → 2.91 | +0.94 → +0.36 |

- 差の −0.21 ポイントは、名目GDPが約600兆円なら年1.2兆円ほどの規模に当たる（**額ではない**。額は台帳の収益率を掛けて出す）。
- 国立大学の法人化（2004年）の前後で、大学等の研究費の差は動いていない（差の差 −0.01 ポイント、趨勢除去後 +0.02）。差が開いたのは主に2005年以降で、法人化そのものより「その後に日本が横ばい、他国が伸びた」形に近い。1つの法律には帰属させず、議員への配分は配分の規則（行動と向き）に任せる。
- 法人化の効果は分野と大学で割れる（Kikuchi 2021 ほか）。量の指標は質（論文の被引用など）を測らない。

## 5. 限界と認知の罠（隠さない）

- **結果論の罠**：日本の差が開いたことは、特定の法律の効果の証明ではない。同時期の景気・予算・他国の政策・追い上げを取り除けていない（趨勢除去は一部）。
- **量と質の取り違え**：研究費・人数は投入で、論文の質・産業への移転ではない。質（Top10%論文など）は NISTEP の表が要る（未取得）。
- **帰属の罠**：教育界の行動のうち、予算（運営費交付金の配分・効率化係数）は法律でなく予算編成で決まる。今回の台帳は法律の行動だけ。予算の一次資料（文科省・財務省）を取得して足すのが次の版。
- **初中等教育**：日本の認知スキルは国際的に高い。人的資本の質の機構で損失を出す根拠は弱いと見込み、PISA・PIAAC を取得するまで「指標なし」とする。
- 議員の関与：対象の77法律は配分の入力（allocation-v1）に未登録。関与の取得（国会会議録の読み取り）を済ませると、同じ形（法律ID→人物ID）で議員へつながる。人数は未取得のまま0人とは書かない。
