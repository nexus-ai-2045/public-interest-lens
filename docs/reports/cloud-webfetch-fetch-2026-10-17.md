# クラウドからの追加取得（施行日・古い回次の一覧・便益データ、2026-10-17）

ロードマップ（実データ公開まで）の C1・C3・D1 のうち、クラウドから届いた分の取得結果です。
この日は Mac に届かず、クラウドから衆議院・省庁へは直接（curl）届かないため、WebFetch（要約モデル経由）で読みました。
**原本のバイトと sha256 はありません。全部「暫定値」です。** 抽出した文は JSON に残し、Mac から原本を取り直せたら置き換えます。

暫定値でも推測は入れていません。採るのは次の検算が通ったものだけです。

- 2系統（別々のエージェントが別の道筋で開く）で同じ文・同じ値が取れた。
- 文の中に日付と対象の法律（題名か法令番号）が両方ある。
- 衆議院のページは、URL や本文冒頭に書かれた回次・法律番号・公布日が、こちらの表と一致する。

## 2. 施行日が空欄の法律（C1）

`data/acquired/enforcement-dates/enforcement.csv` の施行日あり **170 → 197 本**（+27）。作成は `scripts/apply_enforcement_webfetch.py`、抽出文は `shugiin-fusoku-extract.json`。

| 補い方 | 本数 | 取得方法の列 |
|---|---|---|
| 衆議院 制定法律の附則の明示の日・公布の日 | 13 | 衆議院 制定法律の附則（2系統一致、WebFetch 経由の暫定値） |
| 同じ附則の「公布の日から起算して◯を経過した日」を計算 | 5 | 計算（衆議院 制定法律の附則：…） |
| 施行期日政令の内容を書いた省庁の発表（金融庁・国土交通省・厚生労働省・農林水産省） | 9 | 施行期日政令の省庁発表（2回取得で一致、…） |

- 附則で埋まったのは、e-Gov で「取得不可」（改正対象が廃止・改称）だった行が中心。e-Gov に無くても衆議院には公布時の本文がある。
- 省庁の発表は、2回の取得で日付が一致し、附則の「公布の日から起算して◯を超えない範囲内」に収まるものだけを採った。go.jp 以外（法令出版社の記事）の1本（閣法-183-16）は候補に留めた。
- 「政令で定める日」のまま原文が空だった行は、衆議院の附則の原文だけを入れた（施行日は空欄）。
- 残り 152 本の大半は「政令で定める日」。施行期日政令は e-Gov に無く、省庁の発表も古い年ほど見つからない。官報（国立国会図書館の官報検索）か日本法令索引の政令の記載を Mac から当たる必要がある。
