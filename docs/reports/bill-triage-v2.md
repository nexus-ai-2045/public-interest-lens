## 再現と版の保存

```sh
python3 scripts/triage_v2_line2.py
node app/scripts/run-triage-v2-line1.mjs
node app/scripts/run-impact-v1.mjs --triage v2
node app/scripts/run-loss-v1.mjs --triage v2
node app/scripts/run-benefit-v1.mjs --triage v2
```

全runnerが同じ版選択を受け取り、v1は従来の `impact-v1/`・`loss-v1/`・`benefit-v1/`・`publish-v1/`、v2は各名前に `-triage-v2` を付けた別の保存先を使います。既定はv2。途中で別版のrunnerを実行しても、他版の入力や出力を読み替えません。表示側が従来パスを読む場合はv1を表示し続けます。表示へのv2採用、Web公開、人物評価への採用は今回の計算とは別です。

`tests/test_triage_version_pipeline.py` は隔離コピーで実runnerをv1→v2→v1と実行し、各段階で他版のCSVのSHA-256が不変なこと、欠落・保留が非公開のまま残ることを検査します。`tests/test_triage_v2.py` は題名位置の期待値、全170件の実装間照合、保存された一致表を検査します。これらは実装の回帰検査で、規則の一般化の保証ではありません。
