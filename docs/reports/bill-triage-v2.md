# bill-triage-v2：指標の選び方を固定して付け直した結果（前後の比較）

日付：2026-10-17。提案 `docs/提案/指標の選び方-v1.md` の推奨の既定（A1〜A8）を、そのまま新しい版 `bill-triage-v2` として実装し、2系統を付け直して、`impact-v1` → `loss-v1` → `benefit-v1`（公開の判定）を再実行しました。`bill-triage-v1/` の出力は変えていません。

## 先に断っておく点

1. **このルールは、同じ170本を見たあとで作りました（学習内、in-sample）。** 2系統の食い違い28本と一致142本を見て語の表を決め、一致していた142本が壊れないように語も足しました（`bill-triage-v2/spec.md`）。下の「170/170 一致」は新しいデータでの検証ではなく、ルールを作ったデータでの当てはめです。本当に効くかは、別の年・別の法律に同じルールを当てて確かめるまで分かりません。
2. **指標の選び方は決定的な関数なので、2系統の指標の一致は自明です。** 系統1は TypeScript の `app/src/indicator-pick.ts`、系統2は Python の `scripts/triage_v2_line2.py`（提案の文書から別に書き起こした実装）で、コード経路は分けましたが、規則の中身は同じです。`tests/test_triage_v2.py` が全題名で両実装の出力が同じことを確かめるので、実装の写し間違いは拾えますが、規則そのものの正しさは確かめません。**独立に確かめられるのは、各系統の AI が付けた種類・分野の判断（分野の割り当て）だけ**です。その一致は、規則を当てる前に分野が同じ165/170、種類が同じ168/170で、違う5本・2本は評価対象かどうかの食い違い6本の中にあります。D1〜D5 はこの6本を解消するために書いたので、規則を当てたあとの一致は、その6本の分は構成上そうなります。
3. 系統1・系統2とも同じ系列のモデルが付けています（`docs/reports/adr0007-line2.md` の限界は変わらず）。

### 評価対象から外れた5本の内訳

食い違い28本のうち、評価対象かどうかの食い違い6本は、D1〜D5 で次のように決まりました。

| id | 規則 | 結果 |
|---|---|---|
| 閣法-189-27 | D3（新設法人の根拠法は新規）。題名に「通信」「放送」「郵便」 | 評価対象・通信・ネット（系統1と同じ） |
| 閣法-197-1 | D2（最初の法律＝入管法）→ D1（語なし） | 評価対象外（系統2と同じ） |
| 衆法-200-7、閣法-211-23 | D1（題名に8分野の語なし） | 評価対象外（系統2と同じ） |
| 閣法-217-18、閣法-217-28 | D1 | 評価対象外（系統2と同じ） |

指標の選び方の食い違い22本は、すべて表で1つに定まりました（系統1の指標に寄ったもの、系統2の指標に寄ったもの、どちらとも違うもの0）。両系統の指標が入力どおりから変わった数は、系統1で19本（うち5本は評価対象外化で指標が空に）、系統2で8本です。

### 新たに加わった数値（loss-v1 への参入）

- **閣法-189-27**（通信業の付加価値）：影響段階3・向きは貢献。`loss.csv` の便益の中央値は -61.56兆円（四分位 -70.86〜-52.00）、開始後10年の累積（名目は開始前最後の年2014年の水準）。規制の便益が未測定のため公開しない。`publish.csv` では判定表の行 R4（便益を差し引けない）、**公開不可**。
- 参考：閣法-155-62（金融機関等の組織再編成の促進に関する特別措置法案）は指標が不良債権比率から貸出残高に変わり、保留から段階1・悪影響になった。段階2未満なので loss-v1 には入らない。
- その他の法律の影響の判定は、指標が変わったものは「保留（2系統の振り分けが一致しない）」から実際の判定（系列なし・比較群なし・国内系列なし・保留など）に戻った。**金額が付いたのは閣法-189-27 の1本だけ**で、公開可の本数は0本のままです。

### 数が増えた分の読み方

- 保留が28本消えたのは、規則で2系統が同じ指標に寄ったからで、新しいデータが入ったからではありません。指標が決まっても、多くは「系列なし」「比較群なし」で止まっています（上の表のとおり、系列なし35・比較群なし41）。
- 閣法-189-27 の10年累積の金額は、通信業の付加価値の比較国との差です。海外で得た所得は国内の付加価値に入らず、`docs/提案/便益ルール-v1.md` の扱いで、公開は引き続き保留です。
