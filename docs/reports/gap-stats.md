# 判定できなかった指標の不足系列の取得（gap-stats）

impact-v1（`data/derived/impact-v1/impact.csv`）で「系列なし」「国内系列なし」「比較群なし」となった指標のうち、公的機関の統計で補えるものを取得した。
取得は `scripts/fetch_gap_stats.py`、整えた表は `data/acquired/gap-stats/`、原本は `.local/gap-stats/raw/`（Git に入れない）、URL と sha256 は `data/acquired/gap-stats/manifest.csv`、取得できなかったものは `data/acquired/gap-stats/status.csv` に理由つきで書いた。
表の列は他の取得物と同じ「系列,国,区分,年,値,単位,出典URL,備考」。欠けた値は書かず、補間も 0 埋めもしていない。

比較国は industry_va.csv と同じ13か国（JPN, USA, GBR, FRA, DEU, ITA, CAN, KOR, NLD, NOR, SWE, ESP, AUS）。

この取得は系列を増やしただけで、判定そのものは作り直していない。「解消できる判定」の欄は、系列が足りるかどうかの見立てであり、判定ルール上の条件（開始前の年数など）の確認は impact の再実行で行う。

## 1. 雇用の流動性（国際比較）

- ファイル: `oecd_tenure.csv`（4,080行）。OECD の DSD_TENURE@DF_TENURE_FREQ。区分は「勤続1年未満／勤続10年以上」×「就業者全体／雇用者（被用者）」×「男女計／男性／女性」、年齢計。値は各区分の就業者に占める割合（%）。
- 勤続1年未満の割合（男女計）の範囲:
  - 日本: 就業者全体で 2013〜2025年（13年）のみ。
  - 米国: 雇用者で 1996〜2024年（15年。年が飛ぶ）。韓国: 雇用者で 2004〜2025年。豪州: 2001〜2025年。
  - 加・独・西・仏・英・伊・蘭: 1990または1992〜2025年（蘭は28年）。ノルウェー・スウェーデン: 1995〜2025年。
- 欠け: 日本の2012年以前（OECD の表に無い）。OECD の労働移動率（labour turnover）の表は公開データフロー一覧に見当たらず取得できず。
- 解消できる判定: 雇用の流動性（比較群なし・35件）。ただし日本の開始前の値が要るため、施行日が2015年以降の15件が対象になりうる。2014年以前の20件は日本の値が足りず、解消しない。

## 2. 賃金（国際比較）

- ファイル: `oecd_wages.csv`（1,402行）。OECD の DSD_EARNINGS@AV_AN_WAGE（平均年間賃金）。
- 区分: 実質（2025年価格）の米ドル（購買力平価）と自国通貨、名目の自国通貨。13か国すべて 1990〜2025年（36年。ドイツの自国通貨のみ1991年から）。
- 欠けなし（13か国、1990〜2025年）。
- 解消できる判定: 賃金（比較群なし・6件）の国際比較。日本・比較国とも施行前の年が十分ある。

## 3. 電子申請率（行政手続のオンライン利用率）

- ファイル: `egov_online_rate.csv`（16行）。総務省の報道資料（平成20・22・24・25・26年度分）と情報通信白書（平成29年版が引く平成27年度）から、国の行政機関が扱う申請・届出等手続のオンライン利用率を取り出した。
- 区分と範囲（年は年度の開始年）:
  - 全申請・届出等手続: 2007・2008年度（平成19・20年度。集計方法が統一される前後で、2つは比較できない）
  - 全申請・届出等手続（オンライン利用可能分）: 2009〜2015年度（31.5, 31.8, 38.5, 41.2, 44.1, 45.4, 47.3 %）。平成21・23年度は翌年度の資料が記す前年度の値
  - 重点手続（71手続）: 2009〜2013年度。改善促進手続: 2014・2015年度（定義が変わった）
- 取得できず: 平成28年度以降（集計表の形が変わり、同じ定義で続く値が資料に無い）。平成19年度より前の資料は所在を確かめていない。国連 EGDI は動的画面で固定のファイルを確認できず、OECD のデジタルガバメント指数は機械可読の表を確かめていないため取得していない。
- 解消できる判定: 電子申請率（系列なし・6件）。施行日が2005年（閣法-161-9）は前の値が無く、2016年以降の4件は開始後の値が無いため、実質ほぼ解消しない。系列は2007〜2015年度の参考値として使える。

## 4. ブロードバンド普及率

- ファイル: `broadband.csv`（994行）。
  - OECD（DF_BB_TEL_DATABASE、年次）: 固定ブロードバンド契約数（人口100人当たり・契約数）、モバイルブロードバンド契約数（人口100人当たり）。13か国とも 2009〜2025年。
  - 世界銀行 IT.NET.BBND.P2（固定ブロードバンド契約数、100人当たり）: 13か国。日本は 1998〜2023年。OECD より前の年を補う。
- 欠け: 総務省の国内契約数の時系列表は確認できず取得できず（日本の値は OECD・世界銀行で代える）。世界銀行の系列は国により終わりの年が違う。
- 解消できる判定: ブロードバンド普及率（国内系列なし・2件。うち1件は「保留」）。2001年施行の法律は世界銀行の系列で開始前（1998〜2000年）の日本の値がある。

## 5. 企業倒産件数

- 新規取得なし。最高裁の司法統計の破産新受件数（法人・その他）は benefit-data に 2005〜2025年（2014年を除く）が既にある（`data/acquired/benefit-data/courts_bankruptcy.csv`）。
- 欠け: 2000〜2004年と2014年は PDF から数を一意に読めず、1999年以前は司法統計検索システムに表が無い。商工リサーチ・帝国データバンクは民間のため使わない。
- 解消できる判定: 企業倒産件数（系列なし・3件）。3件の施行日は2011・2012・2025年。2011・2012年は開始前の年が benefit-data にあるが、司法統計は破産の件数で倒産件数そのものではないため、系列に固定するかは別途決める。

## 6. 利用件数（交通）

- `airport_passengers.csv`（14,916行）: 国土交通省 空港管理状況調書の暦年・年度別の乗降客数（国際線・国内線・合計）。空港別 137区分（中部国際、成田国際、関西国際など、全空港計を含む）、2007〜2025年。平成28年（2016年）の重なりで2つのファイルの値は一致（744件）。
- `rail_transport.csv`（624行）: 鉄道統計年報 令和5年度「運輸成績の推移」。年度、民鉄・大手民鉄・公営・JR（国鉄）の旅客（千人）・人キロ・貨物。1960〜2023年度（52年。表は昭和35・40・45・50年度以降は毎年）。「民鉄＋JR（国鉄）／旅客（合計）」は本スクリプトで足した値で、公表値ではない（備考に明記）。
- 欠け: 空港別は2006年以前（公開ファイルが平成19年分から）。港湾・道路・自動車の利用件数は対象外で取得していない。鉄道の駅別・路線別は e-Stat の画面が動的で取得できず。
- 解消できる判定: 利用件数（系列なし・12件）のうち、中部国際空港（閣法-142-11、1998年施行）は開始前の値が無いため解消しない。航空法（2005年）も同様に2006年以前が無い。交通政策基本法（2013年）と鉄道軌道整備法（2018年）は鉄道の年度合計で比べられるが、どの系列に固定するかは決めていない。

## 7. 不良債権比率

- ファイル: `npl_wb_gfdd.csv`（294行）。世界銀行 GFDD.SI.02（銀行の不良債権比率、総貸出に対する%）。13か国。日本は 1998〜2020年（23年）。既存の FB.AST.NPER.ZS（more-stats）の日本は2010年以降のため、1998〜2009年を補う。
- 欠け: 日本の1997年以前は取得できず。金融監督庁の資料（平成10年7月）にある平成9年3月期の従来基準公表不良債権（27.9兆円）は金額で、同じ基準の総貸出が無く比率にできない。大蔵省時代の比率の資料は所在を確かめていない。
- 解消できる判定: 不良債権比率（保留・10件）。2001・2003年施行の6件は開始前の値が1998年以降にあり解消しうる。1998年施行の3件は開始前の値が無いままで解消しない。2020年施行の1件は GFDD が2020年までで、開始後の値を既存の FB.AST.NPER.ZS（2022年まで）で補う形になる。

## 取得できなかったもの（一覧は `status.csv`）

OECD 労働移動率、日本の勤続年数の2012年以前、平成28年度以降のオンライン利用率、国連 EGDI・OECD デジタルガバメント指数、総務省の国内ブロードバンド契約数、倒産件数の新規系列、空港別乗降客数の2006年以前、鉄道の駅別年次表、日本の不良債権比率の1997年以前。

## 再現

```
python3 -m venv <リポジトリ外の場所>   # xlrd・openpyxl・pdfplumber を入れる
<venv>/bin/python scripts/fetch_gap_stats.py            # 取得して表を作る（1.1秒以上あけて取得）
<venv>/bin/python scripts/fetch_gap_stats.py --rebuild  # 原本から表だけ作り直す
python3 -m unittest discover -s tests
```
