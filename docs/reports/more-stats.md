# 不足していた公的統計の取得（more-stats）

影響評価（impact-v1）で、取得済みの系列に合う指標がなく判定できなかった法律109件のために、公式の統計を追加で取得した。民間・有料のデータは使っていない。
欠けた値は書かず、0や推定で埋めていない。原本は `.local/more-stats/raw/`（Git管理外）に保存し、URL・sha256・取得時刻を `data/acquired/more-stats/manifest.csv` に残した。

整えた表は `data/acquired/more-stats/` にある。列は「系列, 区分, 年, 値, 単位, 出典URL, 備考」。備考に表名・シート名・系列コードを書いた。
取得と整形は `scripts/fetch_more_stats.py`（`fetch` と `build`）。xls/xlsx を読むため xlrd と openpyxl が要る。テストは `tests/test_fetch_more_stats.py`。

### 各表の中身と使うときの注意

- 雇用動向調査（`employment_turnover.csv`）: 系列は入職率・離職率・未就業入職率・転職入職率（%）。区分は、就業形態×性（第1表）、産業（第2表。製造業の消費関連・素材関連・機械関連を含む）、性×年齢階級（第4-2表）。産業分類の改定で産業名と区分が時期によって違う（鉱業と「鉱業，採石業，砂利採取業」、「運輸・通信業」と「運輸業，郵便業」など）。どの分類の値かは備考のシート名で分かる。つないでいない。調査産業計は全期間（1991〜2025年）ある。
- 労働力調査（`job_changers_lfs.csv`）: 転職者数（万人）と転職者比率（%）。男女計・男・女×年齢階級。転職者は「就業者のうち前職のある者で、過去1年間に離職を経験した者」、比率は転職者数÷就業者数。2002年より前は長期時系列表にない。ベンチマーク人口の切替えによる時系列接続用の数値が入っている（原本の注による）。
- 日本銀行（`bank_loans_by_sector_boj.csv`）: 国内銀行（銀行勘定・信託勘定・海外店勘定の合計）の貸出先別貸出金の残高（億円）を110区分（総貸出、製造業、情報通信業、不動産業、中小企業の総貸出と製造業など）。原本は四半期末残高で、年の値には12月末を使った（足したり平均したりしていない）。「更新停止」の旧区分（運輸・通信業など）も含み、区分名に残してある。
- 金融庁（`npl_fsa_all_banks.csv`）: 全国銀行の総与信、金融再生法開示債権（破産更生等債権・危険債権・要管理債権の内訳）、正常債権（億円）、不良債権比率（%）。年は期末の年、区分に3月期か9月期を付けた。四つの公表回（2006年8月、2012年8月、2016年8月、2026年2月）の表1をつなぎ、重なる期は新しい公表の値を採った。2016年3月期の比率は原本のセルが丸められていない値（1.471…）のまま。1999年3月期より前のリスク管理債権は取得していない。
- 毎月勤労統計（`wages_monthly_labour_survey.csv`）: 現金給与総額・きまって支給する給与・所定内給与・所定外給与・特別給与（円）、総実労働時間・所定内労働時間・所定外労働時間（時間）、出勤日数（日）の年平均の実数。区分は産業（調査産業計と大分類、主な中分類）×就業形態（計・一般・パート）×事業所規模（5人以上・30人以上）。標本の入れ替えや産業分類改定による段差は補正していない。賃金構造基本統計調査は今回取得していない。
- 資源エネルギー庁（`energy_total_energy_statistics.csv`）: 一次エネルギー国内供給、最終消費（エネルギー源別・部門別）、電源構成（発電量・投入量）、CO2排出量、エネルギー自給率。単位は系列ごと（PJ、原油換算万kl、億kWh など）。年は年度。構成比と前年度比の表は読んでいない。電源構成は原本が2010年度からしか載せていない（2009年度以前は電力調査統計の自家発電にバイオマスの別掲がないため）。実質GDP当たりの最終エネルギー消費という系列は時系列表にないので作っていない。最終消費（部門別・PJ）と、取得済みの国民経済計算（`data/acquired/domestic-stats/`）の実質値から比を作る必要がある。
- 世界銀行（`worldbank_extra.csv`）: 13か国（日本・米・英・仏・独・伊・加・韓・蘭・ノルウェー・スウェーデン・西・豪）。銀行の不良債権比率（FB.AST.NPER.ZS。日本は2005〜2025年）、預金銀行の民間向け国内与信のGDP比（FD.AST.PRVT.GD.ZS、1960〜2025年）、金融部門の民間向け国内与信のGDP比（FS.AST.PRVT.GD.ZS、1960〜2025年）、一次エネルギー集約度（EG.EGY.PRIM.PP.KD、2000〜2022年）、発電比率（原子力・水力・再生可能・化石燃料・石炭・天然ガス・石油。1990〜2025年、EG.ELC.*）。国・年によって欠けている。

## 取得できなかったもの（公式系列なし、または今回は着手できず）

- 企業倒産件数（3）: 中小企業白書などの倒産件数は東京商工リサーチの集計で、民間データなので使わない。公式の候補は裁判所の司法統計（破産事件の新受件数）だが、司法統計の検索画面はスクリプトで描画され機械的に取れず、年報の概要版PDFは5年分ずつの図表に数値が散らばっていて列の対応を確実に読めなかった。推測で埋めないため取得していない。年報（民事・行政編）の表を年ごとに取る作業が残っている。
- 電子申請率・行政手続きの時間（6・4）: 国の行政手続のオンライン利用率は総務省・デジタル庁が年度ごとのPDF資料で公表しているが、年度をまたぐ表形式の系列は見つからなかった。行政手続きの所要時間は公式の系列がない。着手していない。
- 利用件数（12）: 旅客数・利用件数は国土交通省の鉄道輸送統計・自動車輸送統計・航空輸送統計にあるが、e-Stat では年度ごとのファイルで、法律ごとに対象の交通機関が違うため、どの系列に固定するか決めずに取得はしていない。
- ネット企業の時価総額（3）: 業種別の株式時価総額を載せた公式の時系列表を見つけられなかったので取得していない。
- OECDの国際比較（銀行貸出、労働移動）: 使えるデータセットを特定できず、取得していない。世界銀行の与信・不良債権比率で代えた。

## 再現

```
python3 scripts/fetch_more_stats.py fetch
python3 scripts/fetch_more_stats.py build
```

資源エネルギー庁のサイトは、研究用の名乗りのUAでは404を返すため、そのファイルだけ一般的なブラウザのUAと参照元を付けて取得している。取得の間隔は1.2秒以上あける。
