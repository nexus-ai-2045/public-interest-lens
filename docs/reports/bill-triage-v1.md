# 成立法の振り分け（bill-triage-v1、2026-10-17）

第142〜222回国会で成立した法律 3,415 本（`data/acquired/bill-census-full/enacted.csv`）を、2系統の AI が独立に振り分けました。規則は [`spec.md`](spec.md) です。系統 A は Sonnet、系統 B は Opus が担当し、互いの結果は見ていません。材料は題名と衆議院の付託委員会だけです。

## 採用の決まり（設計決定0007 §4）

- 2系統で「種類・分野・判定」がすべて一致したものだけを採用します。
- 評価対象では、指標も一致したものだけを採用します。
- 一致しなかったものは「保留」です。人が判断で埋めることはしません。

## 結果

| 結果 | 本数 |
|---|---|
| 評価対象外 | 2,469 |
| 保留（2系統が不一致） | 486 |
| 評価対象 | 349 |
| 保留（指標が不一致） | 102 |
| 保留 | 9 |

- 評価対象外の内訳：定型改正・組織手続が 807 本、8分野の対応表に当たらないものが 1,662 本。
- 2系統の一致率：種類 91.5%、分野 94.8%、判定 94.0%。

## 列

- `結果`：評価対象／評価対象外／保留（2系統が不一致）／保留（指標が不一致）／保留（両系統が「保留」を付けたもの）。
- `種類`・`分野`・`指標`：2系統が一致したときだけ値が入ります。
- `A_*`・`B_*`：各系統の元の判断と理由です。

## まだやっていないこと

- 開始日（施行日）は付けていません。条文の附則から取る必要があり、e-Gov の法令データで別に取ります。施行から2年未満の除外も、その後に行います。
- 第141回以前（1976〜1997年）は一覧がまだないので、入っていません。

## 認知の罠

- 評価対象 349本は「問題のある法律」の数ではありません。比較群を作って測れそうな法律の数です。段階が付くのは、このうち実測で差が出たものだけです。
- 題名だけで振り分けているので、題名が抽象的な法律（「〜の整備に関する法律」など）は対象外に寄りやすくなります。保留と対象外の一覧も公開して、選び方を検証できるようにします。
