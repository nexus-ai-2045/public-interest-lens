## 表の説明

- 引用は、取得した原本のテキストに完全一致することを機械で確かめたものだけを入れた（一致しない行は作っていない）。
- 閣僚名簿（首相官邸「歴代内閣」）は表形式で、役職と氏名が別の行にあるため、引用欄は氏名のセル文字列、役職欄は名簿の職名。名簿は公布日時点で在任した改造内閣の区分から取った。
- 国会会議録の行は、API の発言本文にある文字列を引用した。「審議した会議」は法案名と「議題」を含む発言のある会議（本会議・委員会）で、公布日欄にはその会議の日付を入れた。
- 国会会議録の URL は会議録の発言ごとの URL。sha256 はその行を取った API 応答（JSON）のもの。
- 公布日・施行日が空の行は、その資料に日付が無いことを示す。政令委任の施行日は別の行（省庁ページ等）に入れた。
- e-Gov の「題名」は現行の法令名。法令本文・改正履歴は e-Gov 法令API v2（`/api/2/laws`, `/law_revisions`, `/law_data`）。
