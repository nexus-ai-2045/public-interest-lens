# 参議院本会議の個人別賛否（取得報告、2026-10-17）

参議院「本会議投票結果」（押しボタン投票）を、第142回国会（1998年）から第221回国会（2026年7月）まで取りました。原本の HTML は Git に入れていません。URL・sha256・HTTP の結果・取得時刻は `data/acquired/sangiin-votes/manifest.csv`（5,376件）に残しています。

## 手順

1. `scripts/crawl_sangiin_votes_full.py`：回次一覧から、各回次の一覧を経て、議案ごとの個人別投票ページまで取ります。同じサイトへのアクセスは1.1秒以上あけています。
2. `scripts/parse_sangiin_votes_full.py`：ページを、議員1人1行の表と、投票ごとの集計表に分けます。
3. `scripts/normalize_sangiin_votes.py`：Git に入る大きさに正規化します（302MB が 26MB になります）。

## 表

| ファイル | 中身 |
|---|---|
| `votes_index.csv` | 投票1件1行、5,290件。投票ID・回次・投票日・議案名・公表の票数・集計した票数・照合結果・出典URL・採決方法（押しボタンか起立採決か） |
| `members.csv` | 回次ごとの議員と会派、14,485件。議員ID は回次と議員名と会派の組で振っています。同じ人でも回次や会派が変われば別の ID です |
| `ballots/ballots_NNN.csv` | 回次ごとの個人別賛否、合計1,125,199行。賛否は Y=賛成、N=反対、A=投票なし |

## 照合

- 4,609件は、ページに公表された賛成数・反対数と、個人別の行を数えた数が一致しました（照合 OK）。
- 残る681件は起立採決です（ページに「起立採決により可決されました」などとあり、個人別の記録はありません）。照合は「個人別なし」とし、議案名と結果の文を `採決方法` 列に入れました。第201〜213回（2020〜2024年）に多いのは、感染症対策で押しボタンを使わない採決が増えたためと見られます（推測です）。
- 投票のない回次（参議院の個人別ページがない回次）は空のファイルになるため、出力していません。

## 注意

- 押しボタン投票の分だけで、起立採決や異議なし採決の個人別賛否は記録自体がありません。
- 議員名は原本の表記のまま（空白を除いたもの）です。同姓同名は区別していません。
