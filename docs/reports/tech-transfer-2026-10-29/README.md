# 他国の政策と技術移転の事例（2026-10-29）

ねくさんの問い：「伸びている国の政策は何か」「中国は日本の技術をほとんど取ったのか」。一次資料だけで事例を積んだ。調べ直しを避けるため、既存の `他国の産業政策と日本_2026-10-24.md` と調査メモは読み込み済みの前提。

## 結論（先に）
1. **「ほとんど取った」は、この調査では測れない。** 拾えたのは訴訟・起訴・契約開示された少数の事例で、訴訟にならなかった流出や、合法の取引の総量は分からない。
2. **合法の移転経路が確認できた**（比率・総量は不明）：新幹線の技術供与（川崎重工、2004年前後）、家電・液晶の売却や出資（東芝家電→Midea 2016、シャープ←鴻海 2016）、中国側の合弁・出資比率の条件（2017年版目録で完成車は中国側50%以上）。日本の企業判断か、相手国の公開法令による取引で、違法とは確認されていない。TDKによるATL買収（2005）は日本企業が中国系企業を買った話で、日本の技術が出た例ではないため、結論から外した（逆方向の参考事例。Dに記載）。
3. **営業秘密をめぐる争いで、和解または刑事手続まで確認できたもの**：新日鉄対POSCO（2015、POSCOが300億円を支払い和解）、東芝対SKハイニックス（2014、2億7800万米ドルで和解）。いずれも韓国企業が相手で、**和解は侵害の認定ではなく、POSCO・SKハイニックスが侵害を認めたかは不明**。B・Dの「違法D」は「和解・判決まで進んだ営業秘密事案」の意味で、各社の違法性を確認したものではない。中国関連は元従業員の持出しの刑事事件（積水化学は有罪・二次、旭化成は2026年起訴で判決前）。
4. **日本側が「許した」のは何か**：法律の穴を示す証拠は出ていない。2011-04-28 の国会で議員が「法的規制がないということですよね」と質問した（議員の見解で、政府が認めたわけではない）。国交省は知財管理の強化と答弁（C）。外為法の審査が個別取引で働いたかは記録が取れず不明（D）。日本政府が条件を付けた例は、東芝メモリ売却（議決権上限）と2023年の半導体装置の輸出管理。
5. 伸びている国（ベトナム）：実質GDPは2000→2023で4.05倍（日本1.17倍）。対内直接投資がGDP比4〜5%（日本0.1〜0.5%）。ただしタイは外資誘致が長くても2.08倍で、政策と成長は一対一ではない（E）。
