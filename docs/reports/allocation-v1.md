# 議員への配分 allocation-v1（集計のみ）

作成: 2026-10-17。対象は振り分け v2 で損失額・便益額が出た6本（便益ルール v1.2 適用後の公開可否）。
この文書は**人物名を含まない集計だけ**を載せる。個人ごとの配分は非公開の作業フォルダにだけ置き、リポジトリにもサイトにも出さない。**未公開・試算**。

## 方法

- 按分は `app/src/loss-rule.ts` の `allocateLoss`（設計 M2 §2-4）をそのまま使う。行動の重み 決定5・修正4・委員長3・質疑2・採決1、立場の重み 首相3・大臣2・副大臣/政務官/委員長1.5・その他1。1人1法律で最大の組を1回だけ数え、証拠URLの無い行動は数えない。
- 帰属率は 0.3／0.5／0.7（基準0.5）。感度として 行動重視（立場の重みを1）と 立場重視（行動の重みを1）も計算する。
- 数えるのは法案を前に進めた行動だけ：提出・決定、修正案、採決を主宰した委員長、2系統とも「支持」の質疑（ADR 0007）、参議院本会議の賛成。参議院本会議で反対した人は数えない。
- 衆議院は個人別の賛否記録が無いので、採決の関与は参議院だけ。党籍から推定しない。立場（役職）は `data/acquired/office-holders/cabinet.csv` を日付で引き、行動を補正するだけに使う。
- 手順：`scripts/allocation_involvements.py`（関与の一覧）→ `app/scripts/run-allocation-v1.mjs`（按分・合計・順位）。計算の中身は `app/src/allocation-batch.ts`。

## 人数の集計

- 配分を受けた人：310 人（損失の側だけ 72、便益の側だけ 61、両方 177）。
- 公開不可の法律だけに依存：89 人、一部依存：208 人、依存なし：13 人。
- 同じ観測グループの法律を2本以上合計した人（額が重なる）：258 人。
- 重みの変種で順位が5以上動いた人：268 人。参議院の賛成票だけの人は同額で多数並ぶため、順位の動きは大きく出やすい。

## 注意

- 衆議院の個人別賛否が無いため、参議院議員に配分が積み上がりやすい（院による構造的な偏り）。
- 党内の決定（部会・総務会など）、閣法の提出名義（内閣）、会議録に氏名の無い共同提案者は個人に配分していない。
- 同じ観測グループの法律（宿泊者数-1 の4本、通信業の付加価値-1 の2本）は額が重なるので、法律をまたいで足した額は過大になりうる。
- 閣法-196-4 は質疑の立場判定（2系統）が無いため、質疑を1件も数えていない。
- 6本だけの in-sample の試算で、公開可は1本（衆法-186-35、下限の扱い）。重みは運営の仮定。公開には人間のレビューと反論の経路が要る。
