## 0. 結論（3行）

1. **「人手ゼロ」と「精度の保証」は、AI の判断が残る限り両立しない**（文献：Dawid–Skene 系の正解なし推定は誤りの独立を前提にする。同じ題名を見る同系統の AI は独立でない。標本2でも2系統一致の12%が誤り）。両立させる道は、**AI の判断そのものを公的データの機械的な引き当てに置き換え、判断の残る部分を順位に使わない**こと。
2. 調整役の見立て「CAP の日本データを正解に使う」は**採れない**。日本の CAP は一覧に無く、日本の法律約3,400本に札を付けた人手コード済みデータは見つからなかった（文献・未確認の混在。下の2章）。
3. 代わりに、**e-Gov 法令 API v2 が、改正法ごとに「改正元の法律」と公式の法令分類（50区分）を返す**ことをクラウドから確認した（確認：電気事業法 → category「工業」、改正法の law_id・施行日つき）。題名だけで札を付けていた根本原因を、判断なしで潰せる最大の穴埋め。⭐案A。

## 3. 人手なしで保証できる範囲（ここが一番大事）

- **できる**：決定論の手続き（公的 API の突合、規則による類型、対応表、統計手続き、投票力指数）の正しさ。性質テストと2源の突合で、人手なしに検証できる。
- **できない**：AI の判断が残る札の精度。正解なしの推定（Dawid–Skene 1979、MACE、Snorkel、cleanlab）はどれも「判定役の誤りが互いに独立」を前提にし、同じ題名を見る同系統のモデルでは崩れる（文献）。少数の人手正解と大量の AI 判定から有効な区間を出す確立手法（Prediction-Powered Inference、Angelopoulos ほか 2023 Science）は、**無作為な人手標本が前提**。
- **だから**：「人手ゼロ」を守るなら、AI の判断が残った法律は順位・配分に使わず参考に置く。これは進め方の既存ルール（直せないものは参考に下げる）と同じ線。
