# 点数の付け方：設計確定 v2.1（推奨の最適設定）

2026-11-08。v2 骨組みの後継。ねくの「推奨最適設定で完成させたい。つまみは多くて3個」に従う。
状態：設計の決定。コードは未変更。実装は 7 章の順に進める。

## 0. 先に結論（ねくの問いへの答え）

「計算方法とか設計は決まってるんだよね？」への答えは、**今日の測定でほぼ決まった**です。決め手は次の1つの測定です。

- 産業別の額が付いた法律 1,982 本のうち、「同じ産業の他の法律が前後5年以内に無い」＝単独で効果を識別できる法律は **2 本だけ**（macro-v1 の産業・施行日で数えた。リポ main 5a13f3c 時点）。
- よって、**法律ごとに因果効果を差の差で下から積む案（v2 L1）は、日本1国の産業統計だけでは成立しない**。法律単位の額は、外部の証拠（他国の実測、メタ分析、官庁の見込み）が取れた場合だけ出せる。
- 識別できる単位は「産業×期間の群」まで。ここは確定する。

## 1. 確定する設計（変更点を太字）

| 層 | 確定内容 |
|---|---|
| 主張の3種 | 事実／推定（幅つき）／取り決め。混ぜない（v2 §0 のまま） |
| **L1 識別の単位** | **産業×期間の群**。群の差（OECD 同産業中央値との差）は記述として出す。「政策で説明できる割合」は出さない |
| **L1 法律単位の額** | **外部証拠のはしご（他国の実測→官庁の見込み→業界統計→弾力性×規模）が取れた法律だけ**。取れなければ「測定できない」（試験20本では 0/20 が到達。範囲は狭いと見込む）。群の差を法律へ配らない |
| L2 阻止・遅れ | 中立な定義（反対・阻止・遅延）。見込みの偏りは、成立した法案の「見込みと実測のずれ」で補正。判定者に会派を伏せる。事前登録とプラセボ |
| **L3 帰属** | **党への帰属を基本、個人は役割ごとの固定比率（取り決めと明記）。党と個人を重複して合算しない（性質テスト）。責任度は比較用の別欄に出すだけ。Shapley は撤回** |
| L4 順位 | 同時信頼集合の階層。幅と条件を満たさない人は「測定不能」。**法律単位の額を持つ法律が寄与法律数の下限に満たない人は、点を出さず、関与した群と本数だけを出す** |
| L6 MacroTax | 消費税は乗数の幅つき別欄、法人税・金融規制は測定できない、特例公債法は許可型（v1 §10.4 のまま） |
| 実名公開 | 事実（賛否・役職）は全員公開。推定の額は条件を満たす人だけ |

## 2. つまみの整理（4個 → 固定3個＋残す1個）

| 元のつまみ | 決定 | 値 | 理由 |
|---|---|---|---|
| 的中率の基準（80%） | **固定**。つまみにしない | 80% | つまみにすると、通りやすい値に合わせて調整してしまう。公開の合格基準として固定し、最終評価用の標本で1回だけ測る |
| 寄与法律数の下限 | **固定** | 5 | 首相のくじ引き（法律3〜10本）を防ぐ最小限。5未満は点を出さない |
| 上位3本の占有率の上限 | **固定** | 50% | 同じ目的。1本の法律で決まる人を除く |
| 確かさの下限 | **固定** | 中以上 | 低・参考は順位と配分に使わない（既存の決定を維持） |
| **残すつまみ① 個人の固定比率** | **残す**（取り決めの部分） | 初期値：発議0.4・賛成0.2・反対0.2（逆向き）・閣議決定0.2。党と個人の重複なし | 真に取り決めで、正解がない。値を変えたとき順位がどう動くかを必ず並べて見せる |
| **残すつまみ② 順位の信頼水準** | **残す**（任意） | 90%（既定） | 95% にすると「判定不能」の階層が増える。統計の幅の取り方に過ぎない |

固定した3個と的中率の値は、実装上は定数（`method-spec` の版に含める）とし、設定画面には出さない。変更するときは版を上げる。

### ばらつかせたときの順位の変動幅
- 実測は未算出。**この変動幅は、実装の最初の成果物として出す**（つまみ①を5通りに振り、順位相関と、上位10人・下位10人の入れ替わり数を表にする）。
- 理由：個人の固定比率で動く部分は、`allocation-v1` の involvements と、法律単位の額が揃って初めて計算できる。法律単位の額が揃う本数が今は少ない（上の0章）ため、先に額の本数を数える。
- 見込み：法律単位の額が出る法律が少ないので、ほとんどの人は「測定不能」になる。順位が出る人は少数になる。この点は、ねくの了解が要る（次章）。

## 3. ねくに確認したい1点（一語でよい）

**「点を出せる人が少数になる」ことを受け入れるか。**
- おすすめ：受け入れる。出せない人は、関与した産業群と本数だけを出す。
- 理由：今の「全員に点」は、首相3人のマイナスや符号の的中が19本中10本という実測で、誤りが確認されている。少数でも正しい方が、全員の誤った点より説明がつく。
- 受け入れない場合：群の差を法律へ配る旧方式に戻る。誤りが再発するため、おすすめしない。

## 4. v1・v2 からの訂正

- v1 段2（群の差から政策分の割合を出して配る）：**廃止**。
- v1 Shapley 配分：**廃止**（取り決めの固定比率に置換）。
- v2 L1 の「段階的導入の差の差で法律ごとに積む」：**日本のデータでは識別できないため、群単位の記述に格下げ**。他国の同種規制での差の差は、外部証拠として使える。

## 5. 検証（3つに分ける。Codex 突き合わせ穴3への対応）

1. 計算の再現：同じ入力から同じ出力が出ること（性質テスト）。
2. 観測値の予測校正：成立済み法律の事前見込みと事後実測のずれ。
3. 因果の識別：外部の自然実験や対照がある法律に限る。**符号の的中率は、この3の代用にしない**。

## 6. 性質テスト（追加分）
- 法律単位の額が無い法律は、人の点に入らない。
- 党と個人に二重に配らない。
- 群の差を法律へ配る経路が存在しない（型で作れない）。
- 固定した定数は、設定ファイルから変更できない。

## 7. 実装順（小さく、順に）
1. 型：`GroupDiff`（群の記述）、`LawEffect`（外部証拠つきの法律単位の額、無ければ作れない）、`Scored`、`Reference`。
2. 性質テスト（上の6章）。現行コードが落ちることを確認する。
3. 実装バグ3件：noAmount の無視（`members-reference.ts`）、向きを産業の差の符号で決める箇所、閣法を首相1人に付ける箇所。
4. 群単位の表示（産業群の差と、関与した法律の本数・役割）。これで「まず産業群の差と関与法律だけ出す」提案を実現する。
5. 外部証拠のはしごを、影響が大きい法律から順に当てる（凍結標本で到達率を測る）。
6. つまみ①の変動幅の表を出す。
