## 手順（リポジトリのルートで）

```
python3 scripts/primary_triage.py targets --extra 抜き取り2回目_2系統目待ち_2026-11-19.csv   # 2,561 本
python3 scripts/primary_triage.py fetch --set all          # 議案本文＋会議録 → .local/primary-triage-v1/sources/{id}.txt（直列で約 1.6 時間）
python3 scripts/primary_triage.py prompts --set all        # 版 v2。1本×2系統の指示文 → .local/primary-triage-v1/prompts/line{A,B}/{id}.md
#   読み手：各指示文を Haiku（effort medium）に1件ずつ渡す。出力 JSON を集めて data/derived/primary-triage-v1/all/lineA.json・lineB.json（配列）にする
python3 scripts/primary_triage.py queue --set all          # 裁定に回す項目 → all/queue.json
#   裁定：queue の各件を prompt-adjudicate-v1.md で Sonnet に渡す。{id: 裁定 JSON} を all/rulings.json にする
python3 scripts/primary_triage.py apply --set all          # labels.csv に書く（判定者・指示文の版・記録の場所つき）
python3 scripts/primary_triage.py compare --set all --ids 抜き取り2回目_2系統目待ち_2026-11-19.csv   # 23 本を標本の判定と並べる
python3 scripts/rebuild_public.py && python3 scripts/build_evaluation_ledger.py && python3 scripts/check_error_types.py
```

- 閣法-211-46 は `DEEP_READ`：本文の全体（65,080 字）を取り、経済に効くかは必ず Sonnet が裁定する。
- 読み手には、サイトの値や前の判定を見せない（題名と資料ファイルだけ）。裁定者には、両方を見せる。
- 指示文の出力先（`{out}`）は `.local/primary-triage-v1/all/line{A,B}/{id}.json`。集めて配列にする部分はスクリプトに無い（外の実行環境に合わせて書く）。
