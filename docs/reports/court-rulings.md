# 規制をめぐる判決・行政訴訟（court-rulings）

日本で事業や技術を制限した規制（法律・省令・告示・処分・刑事規定の運用）が、裁判で違法・違憲とされた例と、争われて規制が維持された例を集めた。スレッド「新技術を止めた法律の特定」で、規制ごとに「裁判で退けられたか」を引くための表である。

- 表: `data/acquired/court-rulings/rulings.csv`（2系統が一致した24件）
- 保留: `data/acquired/court-rulings/disputed.csv`（食い違い・未確認・片系統のみの24件。理由と各系統の値つき）
- 各系統が読んだ値: `data/acquired/court-rulings/lines/<分野>.<系統>.json` と、そのときの指示（`収集の指示.md`、`系統C_指示1.md`、`系統C_指示2.md`）
- 作り直し: `python3 scripts/build_court_rulings.py --in data/acquired/court-rulings/lines --out data/acquired/court-rulings`

## 集め方と確かさ

- 系統A・Bが別々に、裁判所の判例ページ（courts.go.jp）や判決PDFを WebFetch で開いて読んだ。A・Bが別の判決を選んだものや未確認を残したものは、系統Cが同じ判例ページを読み直した（設計決定0007 §4 の2系統一致）。
- **判決日・事件番号・規制への判断（規制を退けたか、維持したか）の3つがどれか2系統でそろったものだけ**を `rulings.csv` に入れた。食い違いは推測で直していない。
- WebFetch は小さなモデルがページを要約して返すので、値は「判例ページの表示を読んだもの」で、原本の保存（sha256）はまだ無い。公開前の念押しは、自動の出典チェックで判例ページを取り直して照合する。
- 「その後の変化」（判決後の法改正・告示改正）は、一次資料で確かめられたのが一部だけ。多くは `未確認` のまま。
- 所管は判例ページに書かれていないことが多く、法律の所管から書いたもの（推定と明記）を含む。

## 保留（disputed.csv）の主なもの

- 判例ページが開けなかった（courts.go.jp が途中から HTTP 429 で読み取りを断った）: 薬局の距離制限違憲判決（1975）、病院開設中止勧告の最高裁判決（2005）、要指導医薬品の上告審、公衆浴場の平成元年の判決、NOON 事件の控訴審・上告審、自炊代行・選撮見録の控訴審。
- 一次資料が見つからない: ヤマト運輸の路線免許をめぐる不作為の違法確認訴訟（判決が出たかどうかも未確認）、ワンセグと受信契約。
- 系統で値が食い違う: NOON 事件の第一審（判例ページは 2014-04-25、全文PDFの言渡し日は 2014-05-02 と読んだ系統がある）、ロクラクII の最高裁判決の扱い、ファイルローグ。
- 貸金業の 2006-01-13 判決は、判例ページ 52404 を別の判決（2006-01-24）として読んだ系統があり、URL を取り直す必要がある（rulings.csv の備考にも記載）。

## 今回の範囲に入れていないもの

- 規制が裁判で退けられた例は、医薬・交通・著作権・刑事規定の外ではまだ少ない。独占禁止法（JASRAC 2015年、NTT東日本 2010年）、自治体の営業規制条例（宝塚市パチンコ条例 2002年）、景品表示法の措置命令などは候補として残した（判例ページを読めていないので表に入れていない）。
