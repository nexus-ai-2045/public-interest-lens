# 規制をめぐる判決・行政訴訟（court-rulings）

日本で事業や技術を制限した規制（法律・省令・告示・処分・刑事規定の運用）が、裁判で違法・違憲とされた例と、争われて規制が維持された例を集めた。スレッド「新技術を止めた法律の特定」で、規制ごとに「裁判で退けられたか」を引くための表である。

- 表: `data/acquired/court-rulings/rulings.csv`（2系統が一致した40件）
- 保留: `data/acquired/court-rulings/disputed.csv`（照合列が未確認の8件。理由と各系統の値つき）
- 各系統が読んだ値: `data/acquired/court-rulings/lines/<分野>.<系統>.json` と、そのときの指示（`収集の指示.md`、`系統C_指示1.md`、`系統C_指示2.md`）
- 作り直し: `python3 scripts/build_court_rulings.py --in data/acquired/court-rulings/lines --out data/acquired/court-rulings --lines ABCDEF`

## 集め方と確かさ

- 系統A・Bが別々に、裁判所の判例ページ（courts.go.jp）や判決PDFを WebFetch で開いて読んだ。A・Bが別の判決を選んだものや未確認を残したものは、系統Cが同じ判例ページを読み直した（設計決定0007 §4 の2系統一致）。その後の系統D・E・Fも、同じ照合列で足している。
- **判決日・事件番号・規制への判断（規制を退けたか、維持したか）の3つがどれか2系統でそろったものだけ**を `rulings.csv` に入れた。食い違いは推測で直していない。
- 大分類は `scripts/build_court_rulings.py` の `ruling_kind` で数える。収集メニューの「合憲・適法（規制維持）」は大分類ではない。公開セルは、その中の正本の種類 `規制維持` だけを書く。自然文に「合憲」や「適法」だけがあるときも、その語は公開セルに残さない。大分類が規制維持であることだけから、裁判所が合憲と言ったことにはしない。
- 文頭が `その他`、`規制維持`、`規制否定` のときは、その種類を採り、続く説明や引用は大分類に使わない。種類が文頭に無い「違憲であるとは認められない」は、これまでの語の照合のまま規制否定である。否定の例外辞書は足していない。
- 公開表は系統JSONから生成する。CSVだけの手修正は、次の生成で戻る。新しい原本判断は `lane_acceptance` が2系統の一致を返すまで表へ入れない。この関数は歴史の系統JSONを書かない。
- 初期の報告が書いた24件と24件は、いまのCSVと一致しない。現行は一致40件、保留8件である。
- 表に sha256 列は無い。2026-10-22に保存した全文PDF 39件は、A/B照合が記録した sha256 と一致した。tech-06 は再取得せず、既存の保存PDFが同じ sha256 だった。公式HTMLは、表の判例URLと同じPDF番号を指している。この確認は、表の採否を変えていない。
- 全文PDFを取得していない3件（tech-01、tech-02、med-06）は、系統一致の行のまま残し、本文確認へ上げていない。
- URLが1本に決まっていない6件（add-07b、adm-04c、biz-03、med-05、tech-07b、tech-07c）は保留のままである。
- 「その後の変化」（判決後の法改正・告示改正）は、一次資料で確かめられたのが一部だけ。多くは `未確認` のまま。
- 所管は判例ページに書かれていないことが多く、法律の所管から書いたもの（推定と明記）を含む。

公開セルは、収集ラベル「合憲・適法（規制維持）」を「規制維持」に分けて出す。裁判所自身の文言へ替える候補は、新しい2系統が揃うまで採らない。tech-03 は侵害認定のまま、adm-02 はその他のままである。この2行を入れ替えて内訳の数を合わせてはいない。adm-04b の「その他」と biz-01a の「違法・無効」も、採否を変えていない。

## 保留（disputed.csv の8件）

現行の保留は、判決日・事件番号・規制への判断が未確認の8件である。id は add-07、add-07b、adm-04c、biz-03、med-05、tech-04c、tech-07b、tech-07c。

- add-07 と tech-04c は全文PDFを読んだ。公開列は埋めていない。
- 旧報告にあった HTTP 429 の一覧は、現行の保留ではない。薬局の距離制限、要指導医薬品の上告審、公衆浴場の平成元年の判決、自炊代行の控訴審は表に入っている。
- 貸金業の 2006-01-13 判決の判例URLは 52404（平成16(受)1518）である。2006-01-24 の別件は adm-04c として保留のままである。URLの取り直しは、この切り分けで閉じている。
- tech-07 は表に残り、判決日は 2014-04-25 のままである。全文PDFの署名日は 2014-05-02 と読め、言渡日としては採用していない。

## 今回の範囲に入れていないもの

- 規制が裁判で退けられた例は、医薬・交通・著作権・刑事規定の外ではまだ少ない。独占禁止法（JASRAC 2015年、NTT東日本 2010年）、自治体の営業規制条例（宝塚市パチンコ条例 2002年）、景品表示法の措置命令などは候補として残した（判例ページを読めていないので表に入れていない）。
