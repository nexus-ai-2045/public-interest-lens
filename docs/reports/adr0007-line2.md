# 設計決定0007の2系統目：目的の分類と振り分けの一致と、公開の候補への影響

日付：2026-10-17。

設計決定0007は「独立した2つの AI セッションが別々に判断し、一致したものだけを採用し、食い違えば保留にする（人へ回さない）」と決めています。これまでの AI の判断の段階は、どちらも同じセッションが書いたもの（便益の目的の分類の系統A・系統B、振り分けの A・B）で、独立していませんでした（`docs/reports/benefit-v1.md`）。この報告は、別のセッションが系統1を見ずに付けた**系統2**を加え、2系統の一致を判定の流れに組み込んだ結果です。

## 1. 系統2の作り方

| 段階 | 基準（先に固定） | ラベル | 件数 | 入力 |
|---|---|---|---|---|
| 便益の目的の分類（benefit-v1） | `data/derived/benefit-v1-line2/criteria.md` | `data/derived/benefit-v1-line2/labels.csv` | 19本（loss-v1 の全行） | 第1条の原文（`purposes.csv`）と題名 |
| 法律の振り分け（bill-triage-v1） | `data/derived/bill-triage-v1-line2/criteria.md` | `data/derived/bill-triage-v1-line2/labels.csv` | 170本（施行日を原文で確定できた全行） | 題名と付託委員会（`bill-census-full/enacted.csv`） |

- 基準を書いてから、全件を基準どおりに付けました。ラベルは系統1の結果（`classification.csv`、`triage.csv` の結果・分野・指標・A_*・B_* の列、報告書の分類の表）を開く前に、別のコミットで固定しています。
- **独立性の限界**：系統1と同じ系列のモデルが、別のセッションで付けています（別のモデルではない）。`benefit-v1/spec.md` の本文に系統1の一致の数と不一致3本の名前が書かれており、語彙を読む過程で目にしました。振り分けの170本は、系統1が「評価対象」とした法律から選ばれた集合で、系統1が評価対象外とした約3,200本には系統2を付けていません（評価対象外を評価対象へ戻す向きの食い違いは、この範囲では見つかりません）。

## 2. 一致の判定（`app/src/line-agreement.ts`）

| 段階 | 一致の条件 | 不一致・系統2なしのとき |
|---|---|---|
| 目的の分類 | 系統1（系統A・Bが一致したときの種類の集合）と系統2の種類の集合が同じ、かつ向きの矛盾が同じ。目的の記述なし（空）どうしも一致 | 種類を「保留」に替え、便益は「目的の分類：未測定（保留）」。系統1が保留（A・B不一致、原文なし）のものは、系統2があっても保留のまま |
| 振り分け | 判定・分野・指標がすべて同じ | impact-v1 の判定を「保留（2系統の振り分けが一致しない）」にし、向きを空にする。系統1の分野・指標で計算した段階は理由欄に参考として残す。保留の行は loss-v1 以降に進まない |

系統2で系統1を上書きすることはしません。どちらかが無ければ保留です。

## 3. 結果

### 3-1. 便益の目的の分類（`data/derived/benefit-v1/agreement.csv`）

| 系統1の状態 | 本数 | 系統2との比較 |
|---|---|---|
| 系統1が種類を採用（A・B一致） | 12 | **12本すべて一致**（種類の集合も向きの矛盾も同じ。うち閣法-204-2 は双方とも「目的の記述なし」） |
| 系統1が保留：A・Bが不一致 | 3 | 衆法-147-33 は系統2が A と同じ（預金者の保護を消費者保護に数える）。衆法-147-34 は種類が A と同じ（第1条は禁止規定で目的なし）。閣法-196-4 は系統2が B と同じ（「理解の増進・国際交流」は「…に鑑み」の背景の句で数えない） |
| 系統1が保留：原文なし | 4 | 系統2も「原文なし」 |

- 一致率：系統1が採用した12本のうち12本（100%）。第1条の原文がある15本で見ると、系統1の最終の採否（採用12・保留3）と系統2が同じ判断になったのは12本（80%）。系統1の A・B の不一致3本では、系統2は2対1で A 側（147-33・147-34）と B 側（196-4）に分かれ、どちらの読みにも偏っていません。
- 閣法-189-27 は分類では一致しましたが、下の振り分けで保留になったため、benefit-v1 の対象（loss-v1）から外れました。`agreement.csv` は loss-v1 の18本です。

### 3-2. 振り分け（`data/derived/bill-triage-v1/agreement.csv`）

| 比較 | 一致 |
|---|---|
| 判定・分野・指標のすべて | **142 / 170（83.5%）** |
| 判定だけ | 164 / 170（96.5%） |
| 判定と分野 | 164 / 170 |

不一致28本の内訳：

| 型 | 本数 | 例 |
|---|---|---|
| 指標の選び方（労働市場） | 8 | 系統1は「雇用管理・待遇・労働組合」を賃金、「労働安全衛生・過労死」を労働生産性。系統2の基準は題名に賃金・労働時間・労働基準の語が無ければ雇用の流動性 |
| 指標の選び方（交通・移動） | 6 | 系統1は貨物自動車運送事業を就業者数、空港・新幹線・海上運送を旅客輸送の付加価値。系統2は「事業」の規制だけを付加価値、施設の整備を利用件数 |
| 判定（評価対象か） | 6 | 系統2が評価対象外：株式会社海外通信・放送・郵便事業支援機構法案（機構の設立だけを述べる題名を組織手続）、出入国管理及び難民認定法及び法務省設置法の改正（設置法・対応表なし）、特定地域づくり事業・特定受託事業者の取引の適正化（労働市場と読まず対応表なし）、地域経済活性化支援機構法の改正、脱炭素成長型経済構造の移行推進法等の改正（環境として対応表なし） |
| 指標の選び方（行政のデジタル化） | 3 | 系統1は行政手続きの時間、系統2は既定の電子申請率 |
| 指標の選び方（金融） | 3 | 中小企業信用保険（系統2は企業倒産件数、系統1は貸出残高）、金融機関の組織再編成（系統1は不良債権比率） |
| 指標の選び方（通信・ネット、エネルギー） | 2 | 5G の導入促進法（ブロードバンド普及率か通信業の付加価値か）、水素の供給促進法（発電構成か電力価格か） |

不一致の大半（22本）は、分野の中で指標を1つ選ぶ段階です。`bill-triage-v1/spec.md` は分野ごとの指標の候補を並べるだけで、どれを選ぶかの条件を固定していないため、2系統が別々の条件を立てて食い違いました。

## 4. 判定の流れへの影響（再実行の結果）

再実行：`cd app && node scripts/run-impact-v1.mjs && node scripts/run-loss-v1.mjs && node scripts/run-benefit-v1.mjs`（Node 22.22）。一致した法律の行は、再実行の前後で1文字も変わっていません。

| 出力 | 前 | 後 |
|---|---|---|
| impact-v1：段階1／段階2／段階3 | 17 / 5 / 14 | 14 / 5 / 13 |
| impact-v1：保留（2系統の振り分けが一致しない） | — | 28（前の判定は段階1が3本、段階3が1本、残り24本は保留・系列なし・比較群なし） |
| loss-v1（段階2以上） | 19本 | 18本（閣法-189-27 が外れる） |
| benefit-v1：目的の分類を採用 | 12本（系統1の A・B 一致。うち種類あり11） | 11本（2系統一致。うち種類あり10。減った1本は閣法-189-27 が対象外になった分だけ） |
| publish-v1：公開可 | **0本** | **0本** |
| publish-v1：判定表の行 | R1 13・R3 4・R4 2 | R1 13・R3 4・R4 1 |

- **公開可の本数は0本のまま変わりません。** 目的の分類は、系統1が採用したものすべてで系統2と一致したため、分類による新しい保留は生じませんでした。
- 変わったのは振り分けの側で、閣法-189-27（R4 で公開不可だった）が「振り分けの2系統が不一致」で影響段階の判定から保留になり、損失額・公開の判定に進まなくなりました。もともと公開不可だったので、公開可の本数には影響しません。
- 影響段階が付いていた4本（閣法-156-16 段階1、閣法-189-17 段階1、衆法-211-17 段階1、閣法-189-27 段階3）が保留に回りました。`docs/reports/impact-v1.md` の本数は、この報告の前の数です。

## 5. 限界と次の手

- 系統2も同じ系列のモデルです。設計決定0007の「独立」をより強く満たすには、別のモデルで第3の系統を作るか、系統2をそれに置き換える必要があります。系統2のラベルは基準とともにファイルで外に出してあるので、差し替えられます。
- 振り分けの不一致の多くは「分野の中の指標の選び方」です。この選び方の条件を `bill-triage-v1` の基準として事前に固定（人が承認するルール、設計決定0007の5）すれば、両系統が同じ条件で選べるようになり、保留が減る見込みです。条件を固定したら、版を上げて両系統とも付け直します（旧版の結果は上書きしない）。
- 振り分けの系統2は、施行日を確定できた170本だけです。施行日が新たに確定した法律は系統2が無いため、自動で保留になります（付け足すまで影響段階の判定に進まない）。
