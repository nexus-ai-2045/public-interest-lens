# 設計決定0023：条約と承認案件を評価の対象に入れる

日付：2026-10-30。状態：採用（取り込みと分類まで実装。額と向きは後段、R58）。ねく 2026-10-30「条約締結とか忘れてた」を、評価の対象が法律案（閣法・衆法・参法）だけになっている漏れと読んだ。

## 確かめたこと
- 取り込みは `scripts/fetch_shugiin_bill_census.py` の `KINDS = 衆法・参法・閣法` だけ。衆議院の議案一覧（kaiji ページ）には、ほかに予算・**条約**・**承認**・承諾・決算その他・決議の表がある。条約と承認は未取得だった。
- 題名に「条約」を含む法律は12本あるが、どれも条約の実施法で、条約そのものの承認ではない。
- 第142回国会（1998年）以降で、条約・承認の議案は541件（条約451・承認90、うち両院承認は506件）。条約は国会が修正できず、承認か否かの1票になる。

## 決めたこと
1. **取り込む範囲：条約と承認案件。** 承認案件には、NHK収支予算・出先機関の設置のような組織の手続のほか、外為法に基づく北朝鮮への輸出入禁止措置の事後承認のような**経済の措置**が混ざる。題名の語で分けるので、承認も取る。承諾（予備費の使用）・決算・予算は財政の帳簿の範囲なので、このスレッドでは取らない。決議は法的効果が無いので取らない。
2. **評価の順序：まず全件に結果を付け、額と向きは根拠のある類型だけ後で付ける。** 法律の台帳（all-laws-v1）と同じ5つの語のうち、`保留`（経済への経路がある類型）・`測定できない`（経済に関わるが代理指標を決められない）・`評価対象外`（経済に絞る方針の外、または組織の手続）を使う。額が出ないものは理由つきで全件載せる。
3. **経済への経路がある類型（保留）：** 経済連携・貿易、租税条約、投資協定、社会保障協定、航空協定、在日米軍の経費負担、貿易制限措置の承認。額と向きは R58 で、外国の事後評価の研究から効果の大きさを取れる類型（貿易額への効果、二重課税の回避、航空の自由化）だけに付ける。証拠が無い類型には額を作らない（バックテストの結論と同じ。ADR 0020・0021）。
4. **議員との接続：** 条約の賛否は衆院が会派別、参院は押しボタンなら個人別で、法律と同じ形で /votes に出す（種別は「条約」「承認」）。議員の鎖・配分（allocation-v1）には、額が付くまで入れない。賛否だけでは損失の鎖にならない（ADR 0014）。
5. **規則は題名の語だけ。** 1本ごとの人の判断を入れない。`scripts/build_treaty_outcomes.py` の RULES が正本。上から当て、最初に当たった規則で決める。どれにも当たらない題名は `TR99`（測定できない）として残し、全体の5%を超えたら語を足す（テストで見張る）。

## 限界
- 第141回以前（1997年まで）の条約は、衆議院のサイトに一覧が無く未取得。
- 類型は題名の語で決めている。たとえば「協力に関する」協定は一括して対象外にしたので、経済の中身を持つ協定を取りこぼすことがある。取りこぼしは R58 で類型ごとに再点検する。
- 条約は2国間の交渉の結果で、国会の1票が内容を変える余地は小さい。この表は「国会が承認した」記録であって、「議員が条約の中身を決めた」ことは意味しない。議員への帰属は、額が付いた後に、法律と同じ鎖の規則で別に決める。

## 認知の罠
- 「条約も法律と同じ重さで議員に帰属させる」：国会は修正できず承認か否かだけ。内閣の交渉の結果と国会の1票を混ぜない。
- 「経済連携協定なら効果は大きい、と先に決める」：向きと額は外国の事後評価の研究で測ってから決める。

## 追記（2026-10-30）R58 の結果

経済連携・租税・投資・航空の4類型を、外国の事後評価（メタ分析・査読）から独立2系統で集め、出典の実在を確かめて突き合わせた（`data/evidence/treaties/r58.json`）。どの類型も向きが割れ（mixed）、円の額を作れる類型は無かった。経済連携・航空は向きだけ参考にできる（貿易増・旅客増の方向だが幅が大きい）。租税・投資は使えない。上の3の方針（証拠が無い類型には額を作らない）どおり、184件は「測定できない」とし、議員の鎖には入れない。
