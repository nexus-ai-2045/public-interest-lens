# 設計決定0025：衆議院の責任を議員個人まで届ける（案・実装は次の「検証→配分」PR）

日付：2026-10-31。状態：**設計案（採否つき）。実装しない。** 次の「検証→配分」PR に合流させる。ねく 2026-10-31「衆議院の方が大事まである」。

## 1. 問題

- 衆議院の本会議・委員会は起立採決か異議なし採決で、個人の賛否が会議録に残らない。いまは衆院の分（φ_veto）を会派に置き、個人に配っていない（`docs/計算式.md`、会派の帳簿）。
- 参議院は押しボタンで個人別の賛否が残るので、参院の賛成・反対だけが個人に届く。**成立にはどちらの院も要るのに、個人の点は参院の行動に偏っている。**
- 守る決まり：点は行動と結果だけ（属性に付けない）／一次資料だけ（報道の造反情報は点に使わない）／基準を下げない／経済（付加価値）に絞る／額＝「この人が失わせた額」を一次資料つきの鎖で。

## 3. 案の採否

線引き：**役職・当選回数・派閥は属性。その人が実際にした行動が一次資料に残っているときだけ点になる。** 役職は「資格」で、点になるのは役職で行った行動（採決の宣告、閣議決定の署名、趣旨説明）の記録。

| 案 | 採否 | 点の扱い | 根拠・条件 |
|---|---|---|---|
| A 衆院本会議の記名投票 | **採用（あれば最優先）** | 点に入れる。個人の賛否そのもの | 氏名の原本が見つかった回だけ。約20回で全体への効果は小さい。原本の入手を先に確かめる |
| B 委員会の起立総員 → 出席委員の個人 | **採用** | 点に入れる（確かさ「中」） | 採決の宣告（全員起立）と、その会議の出席委員欄の2つが一次資料。出席欄は退席を拾えないので上限。全員一致の法律は42%あり、衆院の個人に届く最大の経路 |
| C 提出者・発議者（衆法）、修正案の提出者、質疑者 | **採用（既存）** | 点に入れる | すでに実装。修正案は2系統確認の決まりを維持 |
| D 討論者（賛成・反対の討論） | **採用（要取得）** | 点に入れる。向きは討論の賛否 | 記録された本人の行動。ただし討論者は党が指名するので、賛成側は書く人が少なく、反対側に偏る。偏りを画面に明記し、対称にならない前提で重みを抑える |
| E 閣法の閣議決定の全閣僚 | **採用（役職の帳簿から点へ、つまみ付き）** | 点に入れる（現状は首相1人。全閣僚の等分に広げる案） | 閣議決定は全員一致で署名する行動。提出日に在職の国務大臣を `cabinet.csv` の日付で結ぶ。副大臣・政務官は閣議に出ないので入れない。所管大臣は趣旨説明（既存）で別に出る |

## 4. 重みの置き方（案、実装時に版上げ）

- いまの φ_veto（衆院を拒否権者1つ）を、**行動が個人に届いたぶんだけ**個人に移す。届かなかった残りは会派に置いたまま（合計は A_i のまま、検査は「人＋党＋名前不明＝A_i」）。
- 本会議と委員会の分け方（衆院の φ を何割ずつ置くか）は、Shapley の2院＋委員会のゲームを組み直して決める。決めるまでは感度のつまみ（既存の見え方のつまみに追加）で幅を出す。どの値でも合計は1。
- F の等分は、別欄の参考にだけ配る（`reference-*` と同じ扱い）。

## 5. 認知の罠

- 「個人まで届く」ことと「その人の責任が大きい」ことは別。起立総員で届く個人は全員一致の法律の全員で、薄く広く当たる。
- 討論者が増えるほど反対側の議員の点が増える仕組みにならないよう、D は重みを抑え、向きと偏りを表示する。
- 会派が分かる法律（2014年以降）に偏って個人が見えると、新しい議員ほど点が付く。年代の偏りを画面に出す。

## 6. 収束の道（次にやること）

1. 先に確かめる（1スレッド）：A の氏名原本の入手可否、B の採決日の出席委員の取り方、E の全閣僚等分と既存テストの整合。
2. 取得（Haiku で並行、スクリプト化）：D の討論者、会派の日付単位の履歴。
3. 実装は「検証→配分」PR に合流。B・C・E を先に、D は偏りの表示と一緒に、F は別欄で。
4. 検証：配分の合計検査（人＋党＋名前不明＝A_i）、ロジック保証のテストに「個人に届いた割合」を足す。
