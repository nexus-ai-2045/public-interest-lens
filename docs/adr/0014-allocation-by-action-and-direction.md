# 設計決定0014：責任の配り方を「行動 × 向き × 結果」にし、コロナ期の額を配らない（allocation-v1）

日付：2026-10-24。状態：オーナー（ねく）が見直し案の推奨17項目すべてを採用（2026-10-24、プロジェクトのスレッド「損失額の責任の配り方を見直す」）。この記録はそのうち、今回の PR で実装した部分と、後の PR に回した部分を分けて書く。見直し案の全文はプロジェクトの共有フォルダ `analysis/責任の配り方_見直し案_2026-10-24.md`。

## きっかけ

議員ページ（causal-shapley-v1）は、成立させた側（提出者・衆議院の賛成会派・参議院の賛成票）だけに額を配っていた。損失の上位10人は全員、提出者の役割だけで額が乗っていた。1位は閣法1本（国際観光旅客税法案）の担当の大臣としての分だけで5.43兆円で、その額は2020〜2022年の入国制限による観光の落ち込みをそのまま含んでいた。反対票と質疑での反対は0円だった。

オーナーの指摘（2026-10-23〜24）：担当の責任者は、本人が望んでいなかったこともある。賛成・反対した向きでプラス・マイナスを付けるべき。コロナのマイナスにお金を出した法律は、むしろプラスである。

## 決定（今回の PR で実装）

1. **点数は行動の帳簿だけ**。閣法の提出者（閣議決定に関わった担当の大臣）の分は「役職の帳簿」に置き、点数（純額・順位）に入れない。議員ページに別に見せ、つまみ「担当の大臣の分も点数に入れる」（URL `office=1`）で入れられる。衆法の発議者は本人が選んだ行動なので行動の帳簿のまま。配った額の合計（役職の帳簿を含む）は今までどおり法律の額に一致する。
2. **反対した側にも向きを逆にして配る**。参議院本会議で反対した議員（参議院の個人別の投票、`scripts/build_opposing_votes.py`）に、賛成1票と同じ割合（Shapley 値の賛成1票分）を配る。損失の法律に反対＝国士側、便益の法律に反対＝国賊側。反対票の分は法律の額の配分（合計1）とは別に数える。同姓同名で人物を決められない票は算入しない（person_ids と同じ決まり）。
3. **コロナ期と分離できない法律（判定表の R3）は配らない**。元の窓の額はコロナ期の落ち込みをそのまま含み、その法律の効果ではない。公開ランキングでは確かさを「参考」にし、印「コロナ期と分離できない（元の窓の額。議員への配分に使わない）」を付ける。全議員の表（参考の額）も、印が「コロナ期と」で始まる法律を配らない。
4. **コロナ対応の法律は額を付けず理由にする**。2020年以降に施行した法律385本を Haiku 2系統→Sonnet 突き合わせ→Opus 点検で振り分け（`data/derived/covid-response-v1/labels.csv`）、コロナ対応のものは全体指標の参考の額を付けない。産業別の額が出ている法律でも、コロナ対応なら決定3と同じ扱い（参考・印つき・配らない）にする（例：予防接種法及び検疫法の改正の、2020〜2024年の保健衛生の付加価値の伸び）。比べるべきは「コロナはあったが、その法律が無かった場合」で、定説（財政乗数・雇用維持の効果）では落ち込みを和らげる向き（便益）。支出の規模の一次資料が未取得なので額は出さない。

5. **関与の一覧が無い法律にも機械的に配る**。会議録から関与を集めた法律は17本だけで、1〜4 の後は議員に配る法律が便益側の5本になり、国賊側が「便益の法律に反対した議員」だけになった。`scripts/build_auto_involvements.py` が、議案の提出者の欄（衆法・参法は提出者一覧、閣法は提出時の内閣総理大臣）と参議院の個人別の賛否から関与を作る（59本）。質疑・委員長・修正案は会議録を読む必要があるので入れない。提出者が決まらない法律（名前の分からない「外N名」・委員会提出）は足さない。
6. **確かさ「低」も印つきで議員に配る**。損失側の法律は確かさ「低」しか無く、高・中だけでは損失側が1本も配れない。参考は今までどおり配らない（オーナー確認 2026-10-24「入れていい」）。
7. **衆議院の会派別の賛否を会派の帳簿に置く**。議案の経過に載った賛成会派・反対会派で、賛成会派は衆議院の分を会派の数で等分、反対会派には賛成会派1つと同じ額を向きを逆に置く。議員の点数には足さない。会派別の賛否が載るのは第186回国会ごろからで、いまは4本だけ。

8. **政党ランキングを出す（2026-10-24 追加、オーナーの依頼）**。議員の行動の額（役職の帳簿は入れない）を、その法律を参議院で採決した時の会派（採決ごとの投票の議員IDから引いた `data/derived/allocation-v1/vote-parties.csv`。回次の途中で会派が変わった議員がいるため、回次ではなく採決ごと）の系統ごとに足す。新しい額ではなく、会派の分と会派が分からなかった分の合計は全議員の純額の合計に一致する。並べ方は1人あたり（既定）・1本あたり・1票あたり（1人が1本に示した賛否1つあたり）で、総額は参考。与党は人数も賛成する本数も多く、総額は規模で大きくなるため。会派の系統は会派名の一部で寄せる（`blocOf`、合流・改称が多い）。期間は議員に配っている法律の参議院の採決の範囲（いまは1998〜2016年）。

9. **省庁の帳簿（霞が関、2026-10-24 追加、オーナーの依頼）**。閣法の提出者の組の分（決定1の役職の帳簿と同じ額）を、所管の省庁に置いて見せる。所管は、提案理由を説明した人の会議録の肩書（国会会議録 API の発言者の肩書）から決める（`scripts/build_ministry_bills.py`、閣法2,720本のうち2,701本で決まった）。会議録の応答は外部資料として登録してから使う。財務大臣と金融担当の兼務の肩書のときだけ、題名で金融庁の法律（金融・保険業・銀行法・資金決済など）と財務省の法律（税・関税・国際機関への加盟・政府系の銀行など）を分ける。それ以外の兼務は先頭の役職を取る。肩書が「国務大臣」だけのときは内閣の名簿のその日の役職を使い、決まらない法律は理由を書いて置かない。2001年の再編の前の省庁は今の名前に寄せる。新しい額ではなく、議員の点数にも足さない。限界：説明した大臣の省庁が原案を書いた省庁と違うことがある（例：中央省庁等改革の関連法は総務庁長官が説明）。抵抗の件数・実額の帳簿は後の PR（案は共有フォルダの `analysis/霞が関の力関係_案_2026-10-24.md`）。
10. **税の帳簿（金融政策・税の1本目、2026-10-24 追加）**。消費税率を変えた法律（閣法-180-72 の引上げ、閣法-189-3・閣法-192-3 の延期）の額を、内閣府 経済社会総合研究所の短期マクロモデル（ESRI Research Note No.41 表2-5：税率1%ポイントで実質GDP が1〜3年目に−0.28%・−0.19%・−0.20%）で出す（`scripts/build_tax_ledger.py`）。物差しは実質GDP（2020年基準）。延期は、延期した期間に避けた減少を便益とする。確かさは「低」、印は「定説（政府モデル）」「需要の短期効果だけ」。法律の額とは物差しが違うので、議員の点数にも法律の額にも足さない。所得税・法人税の改正は財務省の増減収見込額が取れてから、金融政策は日本銀行への通信が届いてから（案は共有フォルダの `analysis/税の帳簿_案_2026-10-24.md`）。
11. **省庁の抵抗の件数と団体の帳簿（2026-10-24 追加）**。止めた側の記録のうち原本照合済み（機械の照合と AI 2系統が一致）の行だけを数える（`scripts/build_org_ledger.py`）。省庁は、規制改革ホットラインの「対応不可」、WG のヒアリングでの反対・慎重、フォローアップでの反対・慎重・未措置を所管省庁ごとに数える（共管は各省庁に1件）。団体は、審議会・検討会で名前のある団体が示した立場を数える。学者・委員・肩書の無い発言者・官僚は名指しせず区分でまとめる。額は付けない（額のある法律に結び付けるのは後の PR）。集めた記録は止めた側の事例なので、対応不可の割合は省庁全体の割合ではない。

版の名前は `allocation-v1`（members.json の rules の先頭）。causal-shapley-v1 は成立への寄与の計算として中で使い続ける（v0 として残す。仕様の版の決まりは設計決定0013）。

## 扱わないもの（決まりとして固定）

出自・国籍・民族・家族関係（「在日」「二世」など）は点数にも記録にも入れない。行動ではなく属性で、事実でない属性を実名で載せると名誉毀損になる。記事・番組の論調と私人の言論には点を付けない。不成立の法案に「国益」の価値判断で点を付けない。

## 認知の罠（記録）

役職と行動の混同（担当＝推した人ではない）。時期が重なる＝原因ではない（コロナ期）。結果論の非対称（推した側だけ数えると、止めた人が0点で安全になる）。配る法律が便益側だけになると、国賊側は「便益の法律に反対した人」だけになり、特定の会派に偏って見える（決定5・6の前はそうなっていた。決定5・6の後は、国賊側の上位が与党の参議院議員に寄る。損失の法律の多くが閣法で、成立させた賛成票が国賊側に乗るため）。
