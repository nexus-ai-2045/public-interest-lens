# 設計決定0025：同じ額を共有する法律は「共有額の参考値」にする（1本ごとの額は出さない）

日付：2026-10-31。状態：採用（機械処理の分。配分は次の PR）。ねく 2026-10-31（暫定でも出す・降格と同じく根拠を残す・調査 B-4 を理解して採用）。調査：`analysis/精度向上の調査_2026-10-31.md` の B-4・E 章。

## 起きたこと
全体指標（macro-v1）の額は、産業ごと・期間ごとの「産業の付加価値の差」で、法律ごとに分けていない。同じ産業・同じ期間の法律は同じ額を共有する（約1,860本、304群）。これまでは同じ額が2本以上あると額を出さず「額は出さない」にしていたので、計算済みの額が画面に何も出なかった。

## 決めたこと
1. **1本ごとの額は出さない。** 画面は「この業界・期間の合計 X の一部（0〜X）」。X は共有された額（産業の付加価値の差、幅つき）。同じ額を共有する本数を添える。確かさ「低」。足し合わせない。この法律だけの効果ではない。
2. **順位・合計・議員配分に入れない。** 法律は `ranking.json` の `others` に残し（`laws` には入れない）、`sharedReference` に出典・施行日と群（総枠 `medianYen`・本数 `size`）を持つ。議員の額（`build_public_members.mjs`・`members-reference.ts`）、配布データの検証（`public-distribution.ts`）が、この群を `laws` と重ならない・本数が合う、で検査する。
3. **降格（検証で不合格）とは別の印。** 降格は「検証で不合格だが法律ごとの額を残す」（`refReason`・`refBasis`）。共有額は「そもそも法律ごとの額が無い」（`shared`）。文言も分ける。
4. **配分はしない。** 総枠を法律へ分ける重み（法文の強さ・対象範囲・施行時期）が観測できていないので、重みを仮定しない（仮定の追加は情報の追加ではない。調査 B-4）。「重みが観測できる法律だけ総枠を配分し、合計 ≤ 総枠を検査する」は次の PR。枠の材料（群の総枠と本数）はこの PR で `sharedReference.groups` に載せた。
5. **経済全体（産業コード _T）の約490本は、一覧で既定で畳む。** 規模が大きいので、日本の付加価値（窓の開始前最後の年）の10%以上のときは「1年分の○%」を添える。
6. **根拠カード。** 各法律に「使った前提（共有額・産業・期間・出典）」を `sharedBasis` として持たせる。機械処理（同額の検出）の根拠だけで、モデルの判定はまだ無い。
7. **出典チェック。** 共有額の法律も出典URL・題名・施行日・共有額の再計算（OECD 表6）を一次資料と突き合わせる（`scripts/source_check.py`）。

## 限界
- 共有された額 X は、産業全体の差そのもの。法律の効果の上限でも下限でもない（0〜X は「一部」という読み方の枠で、確率ではない）。
- 窓の開始前最後の年の日本の付加価値との比は、規模の見当を付けるためだけ。
