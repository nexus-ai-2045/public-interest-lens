# 設計決定0006：公式原本収集と評価・公開の境界

状態：既存収集器を再利用したローカル候補への統合。取得実績・実評価成立・公開承認を意味しません。

## 既存契約との関係

設計決定0001の公式取得元の連携を具体化します。設計決定0002の製品目的、0003の独立検証と配信境界、0004の表示先、0005の評価期間・政策調査は変更しません。旧収集枝の原本保存契約は、番号が重複するためここへ意味を統合し、旧番号の文書を追加しません。

## 収集契約

- `official_raw.py` は既存の外部資料登録処理へ受信バイトを登録します。公開ヘッダーだけを保持し、本文・ハッシュ・容量・取得元・観測時刻を再読して照合します。取得成功でも内容は `unverified` のままです。
- `HTTPS`の公式ホストを許可一覧で限定し、転送を自動追跡しません。同じホストの取得はプロセス間ロックで直列化し、応答終了後3秒以上の間隔、最大3試行、待機指定、20 `MiB`の応答上限と5 `GiB`の空き容量予備を守ります。過大応答を切り詰めた原本として保存しません。
- `collect_official_raw.py` は非公開領域の固定`URL`計画を有限バッチで実行します。保存済みの取得規則を再開にも適用し、禁止・取得不能・`HTTP`失敗を成功へ読み替えません。本文から列挙した参照先は未取得のまま区別します。
- `collect_diet_corpus.py` と `fetch_diet_minutes.py` は会期・院・日付・索引件数・必要な索引識別子を固定します。国会図書館`API`の受信バイトと、辞書を再出力した旧派生物を区別します。日付付き可読本文、一覧レコード、保存応答ページ、確認済み行動証拠を別計数にします。
- `collect_sangiin_materials.py` は固定した開始資料と取得規則から、参議院の本文・添付候補を有限件数で辿ります。動画・外部参照・対象外・装飾素材を区別し、循環を除き、保存原本を検証して再利用します。禁止・制限・サーバー失敗のチェックポイントは保全して停止します。
- `fetch_law_inventory.py` は対象日時付きの法令`ID`一覧だけを取得します。件数変動、重複、ページ循環、再開時の日時・取得元不一致を拒否します。`ID`一覧の完了は法令本文・履歴本文・資料全体の完了ではありません。
- 投票取得器は候補側の既存実装を保持します。公式合計と会派別の全掲載行を照合し、診断行と未確認を残し、登録済み原本のオフライン再利用・ハッシュ検査を弱めません。

## 保管と停止線

原本、チェックポイント、実名入り派生データ、物理パスと実行ログは非公開 `.local` へ残します。既存原本の移動や複製をこの統合の条件にせず、収集済み資料は`Git`対象へ追加しません。新しい依存関係、取得規則の回避、人物同定、分析承認、採点、公開・送信・配信は本契約に含めません。

## 受入確認

ネットワークを置換した隔離試験で、元バイト一致、`GET`と`HEAD`の分離、ホスト間隔、有限再試行、失敗応答保全、原本改変停止、取得規則の再開適用、固定索引との一致、法令`ID`と本文の完了分離を検査します。旧会議録試験と現在の投票試験も継続します。試験成功は実データの取得完了や実評価の成立の証拠ではありません。
