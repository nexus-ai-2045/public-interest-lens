# 設計決定0021：バックテストの本命を「外国の研究から日本の向きを当てる」に広げる（backtest-v2）

日付：2026-10-29。状態：採用（調整役を通した、ねくの「全部おすすめで進める」。ねくが違うと言えば止める）。設計決定0020の追記（v1.1）で、日本の研究だけでは本命が10件に届かないと分かった（R50：候補45件、採用0件）。そこで、暫定評価（設計決定0015・0016）が実際にやること、つまり他国の実績から日本の向きを推すことの当たり具合を測る。計算式（method-spec-v2.3）は変えない。v1・v1.1 の結果と「緩めた参考」の表示はそのまま残し、v2 は別の段として並べる。

## 何を測るか
**問い**：外国の同種の政策の研究だけを見て、日本で実際に起きた向き（経済に良い／悪い）を当てられるか。

日本の研究（答えの分かっている事例集のうち、日本の研究で向きが定まるもの）を「正解の候補」、外国の研究を「予測の材料」とする。現行の計算は使わない。測るのは、暫定評価の考え方そのものの当たり具合である。

## 決めたこと（結果を見る前に固定する）
1. **正解**：日本の事例（事例集の49件のうち、研究の国が日本で、2系統が一致した便益の向きが +1／−1 のもの）。向きの付け方は v1 と同じ（価格・手数料・スプレッドは下がれば +1、雇用・生産は増えれば +1）。向きが 0（有意でない・定まらない）の事例は、本命から外し、別に「効果なしの予測」として表示する。
2. **予測の材料（外国の研究プール）**：事例集の外国の研究27件に、日本の政策の領域ごとに外国の同種政策の研究を足す。足す研究は、Haiku の調査員が領域の説明だけを見て探す（日本の結果は見せない）。条件は、因果の識別がある（差の差・操作変数・回帰不連続・合成対照・RCT・対照のある事象研究、メタ分析なら最良）、効果の数値と向きを原文のとおり写せる、**効果が正でも負でも零でも入れる**（成功例だけを選ばない）。プールは測定の前に固定し、入力のハッシュで残す。
3. **外国の研究の向き**：結果指標と効果から、便益の向き（+1／−1／0）を2系統が独立に付け、一致したものだけ使う。割れたものはプールから外し、数を公開する。
4. **対応づけ（どの外国の研究をどの日本の事例に当てるか）**：次の5条件がすべて合うときだけ「同種」とする。(a)目的、(b)対象の産業、(c)手段（規制緩和・民営化・参入自由化・最低賃金の引き上げ、など）、(d)開始時期の水準（制度の成熟度が大きく違う時代・国は合わせない）、(e)結果指標の種類（生産・雇用・賃金・価格のどれか）が同じ。判定する側には政策の説明と結果指標の種類だけを見せ、**日本の結果の向きも外国の効果の数値も見せない**。2系統が独立に判定し、一致して「同種」としたものだけを使う。割れたものは保留で、数を公開する。
5. **予測**：一致して同種とされた外国の研究の向きが全部同じなら、その向き。割れていれば「向きが定まらない」とし、**外れには数えず、予測が出せなかった件として別に数える**（出せた割合＝カバー率を必ず併記する）。複数の外国の研究が同じ国・同じデータに由来するときは、1つとして数える。
6. **精度の定義（本命 T0）**：予測が出せた日本の事例のうち、予測の向きが正解の向きと同じだった割合。
7. **合格**：一致率 **95%以上**、かつ、予測が出せた日本の事例が **10件以上、政策のグループが5つ以上**（同じ政策の複数の研究は同じ向きが重なりやすく、件数だけでは独立でないため）。満たさなければ「判定不能」と書き、95%に届いたとも届かないとも言わない。一致率には Wilson の95%区間と、**基準**（毎回その正解の最頻の向きを答えたときの一致率）を並べる。基準を上回れなければ、一致率が高くても「見立てに技術がある」とは言わない。
8. **届かない種類は暫定値を出さない**：結果指標の種類（生産・雇用・賃金・価格）ごとに T0 を出す。一致率が95%に届かない、または判定不能の種類では、暫定評価で他国の実績から向きや額を出さず、理由を書く。ここで出る「暫定の向き」は、外国の研究の向きの多数であり、額ではない（外国の効果の大きさを日本の規模に直す額の移植は、このバックテストでは測れない）。
9. **緩めた参考は残す**：v1.1 の L0〜L2・M0〜M2 は消さない。v2 の件数が足りないときに備え、T1＝同種の条件(d)を外した場合、T2＝条件(e)を外した場合、を並べる（良く見える方だけを出さない）。
10. **固定と再測定**：v1・v1.1 と同じく `data/evidence/backtest/<名前>.json` に入力のハッシュつきで固定する。外国の研究プール・向きのラベル・対応づけは `data/evidence/backtest_foreign_*.json` に出典つきで置く。CI は今のデータで測り直し、入力が同じなら固定結果と一致することを検査する。

## 限界（結果と一緒に出す）
- 日本の結果を知っている者が外国の研究を探している。偏りを減らすため、調査員には日本の結果を見せず、効果の正負を問わない条件にし、ラベルと対応づけは日本の結果を見せない2系統の独立判定にした。それでも、プールに入れた領域の選び方には、私たちの事前の知識が入りうる。
- 日本の事例は数が少なく、同じ政策の複数の研究は独立でない。そのため政策のグループ数の条件を足した。件数が足りなければ、判定不能と書く。
- 向きが合う・合わないは、政策効果の移植の良し悪しだけでなく、外国と日本で測っている集団や指標が違うことも含む。結果指標の種類をそろえる条件(e)で減らすが、なくせない。
- 外国の効果の大きさ（額）を日本に移す精度は測らない。

## 認知の罠（この測定の）
- 後付けの絞り込み：5条件と件数の条件を、結果を見る前にここで固定した。緩めた参考は並べる。
- 基準との比較：向きは2択に近く、世の中の多くが「規制緩和は良い」なら、毎回「良い」と答えるだけで当たる。基準を併記する。
- 件数の罠：10件未満の100%・0%は判定に使わない。
- 「当てられた」を「移植できる」と読まない：向きの一致は、額の移植や個別の法律の評価の根拠にはならない。
