# 設計記録0015：他国の同種政策を用いた暫定評価の提案

日付：2026-10-26。状態：検討案。現行の計算仕様は `app/src/method-spec.ts` の `method-spec-v2.2` であり、この記録で上書きしない。v2.1は既存の別の変更に使われているため、本案の版番号には使わない。

旧稿は、2026-10-26のスレッド「最近の動きと政党の賛否を見られるようにする」でオーナーが「はい」と回答したと記録していた。その記録を、以下の数値化条件・計算式まで承認された証拠にはしない。既存の承認範囲は元の会話で照合する。このPRは賛否の記録表示を修復するもので、外国実績による得点・暫定ランキングを実装・採用しない。

## 目的

日本の直近の法律では政策結果を観測する期間が足りない。他国で先に実施された同種政策について、成功・失敗の双方を比較し、選挙の判断材料にしたいという方向性を残す。政策の記録と、他国から日本への効果の推定を区別する。

## 今回扱う範囲

`/votes` は既存の賛否の記録だけを表示する。既定の4年は、データ最新日を基準に4年前の同日を除き、最新日を含む期間とする。日付は公布日を優先し、なければ衆院、次に参院の採決日を使う。現在日からの4年でも、各議員の在任期間でもない。

会派比較の一致率は双方の賛否が一意な法律だけを分母にする。記載なし・会派内の割れは比較から除き、反対とはみなさない。議員個人の賛否を党籍から推定しない。議員の賛成・反対・欠席の総数と初期表示順は全期間の集計であり、選択期間の反対法数とは分ける。

## 後続の評価方法案（未採用）

- 国内の観測結果、外国実績による推定、未測定を別の状態で表示する。外国実績による推定を、観測済みの国内効果と混ぜない。
- 観測窓が満ちても自動的に確定しない。統計の実測値が揃った時点で、現行仕様の観測数・比較対象・事前傾向・符号の整合などの条件を再検証し、条件を満たさなければ保留を続ける。
- 同種政策の候補条件は、目的・対象産業・手段・開始時期の水準とする。この4条件だけで日本への因果効果を保証しない。適用可能性、比較期間、効果の単位と日本の規模への対応は、出典と反証を含めて設計する。
- 成功例だけを選ばず、失敗例・効果が見られなかった例も調べる。旧稿の「成功例と同数以上」の固定条件は提案として残し、件数不足時の扱いも含めてレビューする。
- 効果幅は未決定。「下限0〜上限＝外国の効果」では、外国の効果が負のとき上下限が逆転する。負の効果・効果なし・複数国の相違・各推計の不確実性を保持する区間の定義が必要。外国の最小値〜最大値だけで統計的な信頼区間とは呼ばない。
- 根拠のない移植係数は加えない。ただし外国の推計を日本へ当てはめること自体が新しい推定であり、「式を足さない」という理由で現行仕様の承認済み計算とは扱わない。
- 比較の対象は政策であり、国や人物の好悪に点を付けない。暫定値を出す場合も現行の本順位とは別にし、対象・不確実性・根拠を明示する。
- 公約達成率は今回の得点に含めない。別表示と演出は本案の範囲外とする。

## 採用に必要な確認

新方式の適用条件、符号・区間・尺度、欠測と保留、表示と順位への利用範囲を具体化し、既存承認と突き合わせて人間レビューする。採用する場合は設計決定0013に従い、計算仕様の正本を更新し、新しい版・変更理由・データベース比較・説明文を揃える。個別の出典・反証・人物への帰属は設計決定0007の2系統による独立照合を維持する。

追い上げ成長、同時期の別政策、後付けの窓選び、制度差、統計品質、産業データの欠測を検証上の制約として残す。データが取れたことと、政策効果を識別できたことは区別する。
