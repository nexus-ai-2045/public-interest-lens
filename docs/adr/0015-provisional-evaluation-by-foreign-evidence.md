# 設計決定0015：直近の法律を、他国で先に結果が出た同種政策の実績で暫定評価する（method-spec v2.1）

日付：2026-10-26。状態：オーナー（ねく）が「はい」と回答（2026-10-26、プロジェクトのスレッド「最近の動きと政党の賛否を見られるようにする」）。この記録は決定だけで、実装は後の PR。

## きっかけ

結果（付加価値の差）が出ていない直近の法律は、窓（開始前3年・開始後2年）が満ちず、いまの式では評価できない。一方、他国には同種の政策を先に実施し、結果が出ているものがある（米国に限らず、中国・ベトナムなど伸びている国も、伸びなかった国も）。オーナーの意図：日本の直近4年を選挙の材料にしたい。

## 決定

1. **状態を3つにする**：確定（窓が満ちた）／暫定（他国の実績を当てた）／未測定。窓は版で固定。窓が満ちた翌年の統計公表で自動的に確定し、後から窓を縮めない。
2. **暫定は幅で出す**：下限0（効かなかった）〜上限＝他国の同種政策の効果（差の差。複数なら最小〜最大）。日本向けの「移植係数」は入れない（根拠のない数字を増やさない）。式は足さない（差の差と「差×規模」）。確かさは「低」固定。
3. **同種の判定は4条件がすべて合うときだけ**：目的・対象産業・手段（補助／規制緩和／税）・開始時期の水準。合わなければ当てない。
4. **失敗した国も必ず比較に入れる**：成功例と同じ数以上の、同種で伸びなかった例を並べる。伸びた国だけを拾わない（生存者バイアス）。
5. **他国の政策に点を付ける。国・人物には付けない**。政策カード（行動→結果→日本に当てはまる条件）。
6. **暫定ランキングは別枠**：「国賊ランキング」と「暫定国賊ランキング」を切り替える。暫定は確定の順位に混ぜない。対象の既定は直近4年。党別・議員別・関連法案別、何に賛成・反対したかを見られる（/votes が土台）。
7. **公約の達成率は点数に入れない**。「点数は行動と結果だけ」の方針を守る。やるなら別の表示（案は analysis/公約の達成率_案_2026-10-26.md）で、オーナーの確認後。
8. 演出（派手な見せ方・音）は別スレッドで扱う。

## 限界と認知の罠

追い上げ（低い水準からの伸びは政策がなくても速い）、同時多発の政策、後付けの窓選び、制度の違い、中国統計の質、区間の上限だけが目立つ見せ方。中国・ベトナムは OECD STAN に産業別の付加価値が無く、世界銀行で補う。外国政府の原文は届かないものが多く、他国の政策の数字は確度「中」以下。
