# 設計決定0019：根拠値の台帳を正本にし、評価方法を設計書で固定する（eval-design-v1）

日付：2026-10-29。状態：採用（ねく 2026-10-29「根拠をしっかりまず最初に作るべき」「メタ分析はかなり使った方がいい」「精度は95%」「独立も増やすもあり」「計算を急いで」）。

## 決定

1. 暫定評価・額・産業連関で使う根拠値（乗数・弾性値・収益率・単価）は、`data/evidence/ledger.json` の台帳だけを正本とする。計算コードに数字を直書きしない。
2. 評価は独立な5系統（M1 実測、M2 理論値、M3 他国実績、M4 産業連関、M5 マクロの期待成長）。暫定は M2 と M3 の共通区間。M4 は額に足さず別欄の上限。前方波及は採らない。
3. 精度は、実測済みの法律を時間で分けたバックテストで、95%区間の的中率≥95%かつ幅が上限以内の種類だけ暫定を出す。届かない種類は出さず理由を書く。
4. 台帳の値は、収集・照合1・照合2の3者が一致したものだけを採用（`verified`）。割れたものは `held`。
5. 手法の本数の上限（6本）は外す。追加の条件は、出典つきの定番・バックテスト通過・版上げ。
6. 内容は [評価方法設計書](../評価方法設計書.md)。最小版を先にマージし、台帳の値と機構の対応表は続く PR で足す（版を上げる）。

## 影響

計算・額・順位は変わらない（この決定は設計と台帳の置き場だけ）。`method-spec` の版上げ（手法の追加）は、M2・M4 の計算を入れる PR で行う。
