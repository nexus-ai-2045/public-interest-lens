# 設計決定0008：全件を確かさの印つきで公開し、議員は実名で因果の鎖から額を出す

日付：2026-10-17。状態：採用（ユーザーの指示 2026-10-17 を記録する。マージで正本とする）。

## 背景

設計決定0003 と 0007 は、実在の評価の公開を「対象を名指しした一括承認」の後に限り、議員の実名は別承認としていた。2026-10-17 時点で公開候補は1本だけで、漏斗が細すぎてランキングとして成り立たなかった。同じ日にユーザーが次の4点を指示した。

1. 法律は全部出す（「全部なんだよ」、承認カードで「参考も全部」）。
2. 議員は公人なので実名も全部出す。
3. 議員の額は見せ方ではなくロジックで、「この人が失わせた額」を出す。
4. 対象は全法律（3,415本すべてを計算に通す）。

## 決定

1. **法律は全件・常時承認で公開する。** 計算できた法律から順に、額に確かさの印（高・中・低・参考）と読み方の注意（コロナ期と重なる、便益側の一部が未測定、施行日は推定など）を付けて載せる。額が出ない法律は理由を付けて載せる。1本ずつの承認は要らない。承認の記録は `ranking.json` の `approval`（`scope: all-laws`）に残す。
2. **議員は全員を実名で公開する。** 公人としての公開記録（衆参・委員会の提出・採決・質問・役職）だけを使う。私生活（住所・家族・健康）は入れない。点数は行動と結果だけで、公約や発言の中身は入れない。項目の許可リストは `tests/test_public_members_safety.py` が守る。
3. **議員の額は因果の鎖から出す。** 「提出・推進・反対した（会議録）→ 法律の結果 → 損失（統計と式）」を一次資料つきで示し、成立への寄与を Shapley 値で配分する（`causal-shapley-v1`）。確かさが低と参考の法律は配分に使わない。衆院の起立採決は個人の賛否が残らないので、衆院分は党へ帰属させる。配分の前提は読者がつまみで動かせる。
4. **対象は全法律。** 産業の対応が無い法律（司法・選挙・防衛・年金など）は GDP・財政などの全体指標で参考の額を出す（確かさ「参考」）。測れないものは外さず、理由を出す。

## 0003・0007 との関係

- 0007 の「判断の材料はファクトと実測だけ」「2系統の AI が一致したものだけ採用」は変えない。
- 0003 と 0007 にあった「公開は対象を名指しした一括承認の後」は、法律については本決定の常時承認に、議員の実名については本決定の全員公開に置き換える。
- 訂正は `docs/corrections.md` の流れで受け、ルールの変更が要る異議はルールの新版として扱う（0007 §5）。

## 影響

- 公開前の安全は、人の承認ではなく機械の検査で守る：出典チェック（`scripts/source_check.py`）、議員ページの安全検査、push 前の個人名義検査。どれかが赤なら取り込まない。
- 参考の額が大半を占める（2,775本）。画面は確かさの印を額と同じ強さで見せる。
- 戻すとき（たとえば実名の公開をやめる）は、この ADR を置き換える新しい ADR を書き、配布ファイルから該当項目を外す PR を出す。公開済みの内容はキャッシュに残りうる。
