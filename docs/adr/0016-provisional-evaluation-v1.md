# 設計記録0016：暫定評価 provisional-v1（他国の政策カードと日本の直近の法律）

日付：2026-10-29。状態：表示と枠組みを採用（別枠・確かさ低）。理論値と精度（95%）の部分は別の設計書（根拠の台帳）が決まるまで未採用。設計決定0015の「検討案」を具体化する。現行の計算仕様 method-spec-v2.2 は上書きしない。

## 決めたこと
1. **別枠**：暫定は確定の順位に入れない。画面は /ranking の「国賊ランキング（確定）／暫定国賊ランキング（他国の実績）」の切り替え。確かさは「低」固定。
2. **政策カード**：他国の政策1件ずつの産業の伸びの差の差。窓は開始前3年・開始後2年（開始年末を基準）で、結果を見る前に固定した（data/foreign-policy-v1/cards.json）。比較国ごとの差を出し、**最小〜最大を幅**にする。中央値や点は出さない。幅が0をまたぐなら「向きが定まらない」。
3. **日本への当て方**：4条件（目的・対象産業・手段・開始時期の水準）が合うときだけ。合否は2系統（Haiku 5本と Sonnet）が一致したものだけ採用。幅 × 日本のその産業の規模（最新年の名目付加価値）。移植係数は入れない。「下限0〜上限＝他国の効果」は、効果が負のとき逆転するので採らない（0015のとおり）。
4. **学習用カード**：中国・ベトナム・インドは低所得国の追い上げで日本に当てない。失敗例（インドなど）も表に入れる。
5. **危機の年**：窓に 1997〜98・2008〜09・2020〜21 が入るカードは除外せず印を付ける（比較国も同じ年を経験するため。除外すると高所得国のカードが残らない）。

## 限界（画面にも出す）
追い上げ成長、同時期の別政策、制度差、統計の質、名目系列（韓国コンテンツは実質が無い）。他国政策の年月日は二次資料が多い。

## 次（この記録の範囲外）
理論値（マクロ・ミクロの定説の式、メタ分析の弾性値）、95%のバックテストとコンフォーマル予測、「参考値」の全件出し。根拠の台帳と評価方法の設計書ができてから、method-spec の版を上げて入れる。

## 試した結果（2026-10-29）
直近（2022年以降）449本を、政策カード8本のうち日本に当てる対象の5本（韓国コンテンツ・ドイツ再エネ・オランダ医療保険・米国金融・オランダ郵便）に対して2系統（Haiku・Sonnet、各5束）で判定した。4条件が両方の系統で一致した法律は0本。近かった4本は near_misses.csv に理由つきで残した。カードを増やす（理論値を足す）ことで暫定の対象は増える。

## 理論値（参考値）の第一弾（2026-10-29）
方針（ねく）：マクロ・ミクロ経済学の定説の式で理論値を出し、他国の実績は検証と幅の根拠に使う。出せない種類も数字は出し、「参考値」の印・達成した精度・理由を添える。精度の目標は95%（幅に実測が入る割合と、幅の狭さをセットで示す）。
- 機構6つ（財政乗数・税の超過負担・規制のハーバーガー三角形・最低賃金の雇用弾性値・R&D補助・標準費用モデル）の式と弾性値を出典つきで調べ、2人が引用を照合した（`docs/理論値の機構と弾性値_下書き.md`）。弾性値は根拠の台帳が正本を作るまでの下書き。
- 直近449本の振り分けは2系統一致12本、片方だけ40本（採用しない）。両系統で入力がそろい計算できたのは2本（標準費用モデル）。税とR&Dの2本は課税ベース・弾性値・基準のR&D費が一次資料に無く、出さなかった。**制約は式や弾性値より入力の量だった。**
- バックテストは未実施（n=0）。被覆率95%と幅は「未検証」と画面に出す。コンフォーマル予測は、実測のある過去の法律で理論値が出せるようになってから（母数は最低でも20本程度要る）。
