# 設計決定0012：労働生産性は就業者1人当たりGDPへ差し替える

日付：2026-10-22。状態：現在会話の採用を記録する。労働生産性に限る triage v2 の派生表と、そこから作る公開の順位・法律の結果・法律一覧は 2026-10-23 に実施済み。議員ページの配分ファイルは変えていない。impact-v1 の過去の表、人物への配分の再実行、履歴の書き換えは含まない。ロードマップは、差し替えの実施と、財政系列・旧基準・履歴書き換えの不採用を記録する。議員配分と impact-v1 の過去の表は未実施である。

## 決定

1. 労働生産性の国際比較は、取得済みの世界銀行 `SL.GDP.PCAP.EM.KD`（就業者1人当たりGDP）へ経路ごと差し替える。
2. 財政の付加価値系列はつなげない。
3. 旧基準の国民経済計算は貼り合せない。
4. 過去の評価結果や履歴は書き換えない。差し替え後の再計算は新しい実行として扱う。

## 根拠と境界

公式の指標API（`https://api.worldbank.org/v2/indicator/SL.GDP.PCAP.EM.KD?format=json`、2026-10-22に観測）の名前は `GDP per person employed (constant 2021 PPP $)` で、説明は経済全体の就業者数で割ったGDPを2021年のPPP固定国際ドルに換算したもの、と読める。これは人口1人当たりGDP（`NY.GDP.PCAP.*`）でも、労働力人口（`SL.TLF.TOTL.IN`）でもない。

取得済みの `data/acquired/r3-series/r3-series.csv` は、この指標を `WB:SL.GDP.PCAP.EM.KD` として13か国・1991〜2025年で持つ。単位欄の文言は取得時の「PPP固定米ドル。基準年は未確認」のままで、基準年の列は空欄である。水準のドルを円と読まず、日本の開始前最後の年を100とする既存の指数化だけを使う。古い労働力人口当たり系列の年と新しい系列の年はつながない。

開始前5年を見て最低3年、比較の割合、配分の0.3・0.5・0.7、欠測を0にしない扱いは変えない。この記録は設計決定0008と0009を置き換えない。

## 実施と未実施

労働生産性に限る triage v2 の派生表と、その表を入力にする公開データの再生成は実施済みである。対象は `data/derived/impact-v1-triage-v2/` の impact.csv と indicator-map.csv、`data/derived/all-laws-v1/outcomes.csv`、`app/public/distribution/ranking.json`、`laws.json`、`laws-detail/`、`members-reference.json` の順位表の照合値である。`data/derived/impact-v1/spec.md` の国際比較の一文は、同じディレクトリの保存済み CSV に合わせ、労働力人口当たりの旧系列の説明に戻した。段階1・悪影響は4から2、保留は40から42になり、移ったのは閣法-142-15 と閣法-142-59 である。

`app/public/distribution/members.json` は main のままである。この作業機で同じ計算をやり直すと、閣法-193-59 の配分比の浮動小数の末尾だけが変わり、公開検査が固定している値と一致しない。労働生産性の判定ではなく、人物への配分の再実行でもない。末尾を機種に依らず一つに固定する変更は、この差し替えには入れない。`data/derived/impact-v1/` の impact.csv と indicator-map.csv は未更新である。保存済みの対応表は22行で、労働生産性は労働力人口当たりの旧系列のままである。今の対応表は分野の拡張、金融・保険業の付加価値、利用件数と客室数の後からの配線を含むので、労働生産性の行だけ戻してもその表には戻らない。`run-impact-v1.mjs --triage v1` はその保存先を書き換えずに終わる。版を分ける再実行そのものは失敗にしない。就業者1人当たりGDPを書くのは v2 だけである。`docs/ロードマップ.md` は差し替えの実施と、財政系列をつながないこと、旧基準を貼り合せないこと、履歴を書き換えないことを記録する。雇用の流動性の向きは、この4決定の外で未決である。履歴は書き換えていない。
