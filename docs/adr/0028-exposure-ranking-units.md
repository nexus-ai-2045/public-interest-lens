# 設計決定0028：曝露ランキングの足す単位・役割の重ね方・院の分け方

日付：2026-11-19。状態：**決定（実装済み、画面には出していない）**。ねく 2026-11-19「すべて推奨で」に従い、おすすめで決めた。どれも戻せる。関連：設計決定0027（点数設計 v2.1）、0026（衆議院の責任）、0014（配分）。

## 1. 背景

設計確定 v2.1 は、識別できる単位を「産業×期間の群」までとし、群の差を法律へ配らないと決めた。その上で、人には「関与した群の伸び損ね額を役割の固定比率で配った額」（曝露。因果でなく記述）を出す（案B）。集計器（`app/src/exposure-ranking.ts`）を実データにつなぐと、次の問題が出た（レビュー2系統で確認）。

1. 群を macro-v1 の「産業×窓」にすると、窓は1年ずつずれた最大10年の累積なので、同じ産業の同じ年を最大10回数える。全産業（_T）と各産業も重なる。古い時期に関与した人ほど額が大きくなる。
2. 法律が1本だけの群は、群の差がそのままその法律の額になる（群の差を法律へ配る経路になる）。
3. 固定した定数「上位3本の占有率の上限 50%」が階層の条件に使われていなかった。
4. 賛成・反対の記録は参議院の個人票だけで、衆議院の会派単位の賛否が入っていなかった。
5. 関与の表（allocation-v1）は「法律単位の額がある法律」だけ（7本）で、群の法律には足りない。

## 2. 決定

| # | 論点 | 決定 |
|---|---|---|
| 1 | 足す単位 | **産業×年**（重ならない単位）。額は「比較国の中央値の伸び − その年の日本の実質の伸び」の差 × 前年の名目付加価値（正が伸び損ね）（`scripts/build_industry_year_gap.py` → `data/derived/exposure-v1/industry-year.csv`）。幅は比較国の伸びの第1・第3四分位。法律は、窓が覆う各年の群に属する。同じ産業×年の額は1回だけ配る |
| 2 | 全産業（_T） | 産業別と重なるので**足さない。別欄**（`wholeEconomy`）。順位には使わない |
| 3 | 1本だけの群 | 法律が1本だけの産業×年には関与を置かない（枠は未配分） |
| 4 | 役割の重ね方 | 役割は別々の行動なので、**同じ人が同じ法律で複数の役割を持てば足す**（閣僚は閣議決定0.2＋発議0.4、賛成票の記録があれば＋賛成の枠）。「二重に配らない」は党と個人の間の決まりで、役割の間の決まりではない。各役割の枠の中は人数で均等。1人が1本の法律から受ける割合は、持つ役割の比率の和を超えない。全員（人＋会派＋未配分）の合計は比率の合計を超えない（性質テスト） |
| 5 | 院の分け方 | 賛成0.2・反対0.2 を**院で半分ずつ**。衆議院の0.1は会派へ（会派単位の賛否の記録。会派に均等）、参議院の0.1は個人票へ。記録の無い院の半分は未配分に積み、もう片方の院へ寄せない |
| 6 | 参議院の個人票 | 関与の表ではなく、投票の一次資料（成立した日の、題名が一致する押しボタン投票）から群の全法律ぶん取る。同姓同名で人物台帳に結べない票は、重みだけ枠に入れて未配分にする |
| 7 | 提出者 | 衆法・参法は議案の提出者の欄から取る。名前の分からない「外N名」と委員会提出は人に置かず未配分。閣法は提出時の閣僚の全員（`app/src/cabinet-members.ts`、全議員の表と共有。総理大臣が会期中に替わる回次は付託日で決め、交代より後に付託された閣法は未配分）。閣僚の1人でも人物台帳に結べない閣法は置かない（結べた人へ寄せない） |
| 8 | 関与した法律数の下限 | 曝露では法律単位の額を作らないので、`minContributingLaws`（5）は**「関与した法律の本数」**として使う（定数の値は変えない。読み替え） |
| 9 | 上位3本の占有率 | 上位3本の寄与（法律ごと、内部でだけ計算）の絶対値の和が全体の 50% を超える人・会派は階層に入れず、理由を出す。出力には比率だけを出し、法律の ID と法律ごとの額は出さない |
| 10 | 全員を載せる | 人物台帳の全員を、点あり（階層つき）か点なし＋理由のどちらかで1回ずつ載せる |
| 11 | 額を出さない人の合計 | 額を出さない人・会派の分の合計は出てよい（複数人の合算で、個人の額ではない）。額を出さない人・会派が1つだけのときだけ伏せる。丸めはしない |

## 3. 代替案

- 足す単位を「重なる窓の数で割る」：窓ごとの基準年が違う額を割って足すことになり、「同じ年を1回だけ」が成り立たない。不採用。
- 足す単位を「固定の基準年からの水準の差」：古い年の差が後の年の法律にも乗る。年ごとの伸びの差のほうが「その年に起きたこと」に対応する。不採用。
- 会派の分を所属議員へ等分：行動の記録ではない仮定が要る（設計決定0026 の案F）。不採用（会派のまま出す）。
- 衆議院の会派を議席数で重み付け：議席数の表がリポに無い。表が入ったら見直す（下の限界）。
- 賛成の枠を記録のある院へ全部寄せる：参議院議員だけ額が倍になる。不採用。

## 4. 影響と既知の限界

- 産業×年の額は macro-v1 の累積額（開始年基準の水準の差の累積、開始前の伸びの差を織り込む）とは別の量で、桁が小さい。2つを比べない。
- 衆議院の会派賛否の記録は第187回国会（2014年）以降だけ。それ以前の法律は衆議院の半分が未配分になる。会派に均等で、会派の大きさを無視する。反対会派が空の法律は、全会一致か記録なしかを区別できず、未配分に置く。
- 参議院で投票が1つに決まらない法律は、参議院の半分が未配分になる。
- 総理大臣が会期中に替わる回次のうち、交代より後に付託された閣法は閣議・発議の分が未配分。会期の途中で内閣改造があると、通して在任した閣僚だけになり、1人あたりが大きくなる。
- 「総理大臣が会期中に替わる回次」は、成立した閣法の衆議院付託日の最初と最後の間に交代があるかで決める。会期の始まりから最初の付託まで、または最後の付託から会期の終わりまでに交代があると見逃す（今のデータでは該当する閣法は無いことを確かめた。会期の日付の表が入ったら直す）。
- 内閣の名簿で氏名が空の閣僚がいる回次の閣法は、閣議・発議の分が未配分（名簿の修理は別の変更）。
- 階層は、幅が先頭の人と重なる間は同じ階層とする決まり。産業×年の幅が広いと、多くの人が同じ階層になる（下の数字）。階層の作り方は、順位の信頼水準のつまみ（v2.1 つまみ②）と合わせて別に見直す。
- 書き出す JSON は公開用に変えたもの（`toPublicExposureRanking`）。階層に入らない人・会派は額と内訳の額を出さない（関与した法律が1本の人の額は、その1本の額そのものになるため）。階層に入った人でも、関与した法律が5本未満の内訳が1つでもあれば内訳の額を全部出さない（1つだけ伏せても合計からの引き算で読めるため）。額を出さない人・会派の合計は `hidden` に件数つきで出し、合わせて1つだけのときは `hidden`、totals の全部（期待値と未配分を含む）、未配分の内訳の額を伏せる（期待値−未配分−出ている額で読めるため）。なお計算はすべて公開の一次資料から作り直せるので、この伏せ方は「1本ぶんの額を見せない」ための表示の決まりで、秘密を守る仕組みではない。検算は公開用に変える前に行う。
- 出力はまだビルドと画面につないでいない。

### 比率を変えたときの順位の動き（人名は書かない）
