# 設計決定0026：共有額は固定の配分基準で法律ごとに分ける（確かさ「中」以上だけ順位と議員へ）

日付：2026-10-31。状態：**採用（基準の文書。実装は次の「検証→配分」PR）。** ねく 2026-10-31「一定の基準を決めて出すしかない」。0025（共有額の参考値）の決め4「配分はしない」を、この基準で置き換える。仮定を足さない原則は、**重みの観測できた数を確かさに写す**ことで守る。

## 1. 決めたこと

同じ産業・同じ期間の群 g（総枠 X_g。産業の付加価値の差。幅つき）に属する法律 i に、次の式で額を機械的に分ける。

    a_i = X_g × w_i / Σ_j w_j      w_i = s_i × b_i × t_i

| 項 | 意味 | 観測できるとき | 観測できないとき |
|---|---|---|---|
| s_i 対象の付加価値シェア | 法律の対象業種・対象者が、群の産業に占める付加価値の割合 | 産業連関表・JIPの産業細分類で数えられる | 群内の平均（＝等分） |
| b_i 拘束の強さ | 議案本文の拘束表現（しなければならない・してはならない・禁止・義務・命ずる・罰則）の数。群内の平均で割る（0.5〜2 に切る） | 議案本文が取れている | 1（群内の平均） |
| t_i 期間 | 施行日から窓の終わりまでの年数 ÷ 窓の長さ | 施行日がある（ほぼ全件） | 施行日が無い法律は群に入れない |

- 全件に同じ式・同じ係数を当てる。係数を法律ごとに変えない。
- **合計の検査**：群ごとに Σ a_i = X_g、各 a_i ≥ 0。X_g を超えたら失敗（既存の `public-distribution` 検査に足す）。
- 切り方（0.5〜2）は、本文の長さだけで額が決まらないための歯止め。

## 2. 確かさ（観測できた重みの数）

- 高：s・b・t の3つとも観測できた。
- 中：2つ観測できた（t は施行日でほぼ常に観測できるので、実質 b か s のどちらか）。
- 低：t だけ。

**順位と議員への配分には「中」以上だけを入れる。「低」は法律ページと一覧に表示するだけ**（`others` に残し、`sharedReference` の印つき）。合計・順位・議員の額に足さない。

## 3. 記録（各法律に持たせる）

式の版・係数・群・X_g と幅・w の3項と観測の有無・出典（議案本文のURL、産業連関表の表、施行日）・確かさ・計算の日付。/methodology と法律ページの根拠カードに出す。

## 4. 限界（画面に書く）

- Σ a_i = X_g は「群の差が、この群に入っている法律で説明される」という上限の読み。群に入らない原因（景気・技術・他国の動き）は分けていない。**額は法律ごとの効果の推定ではなく、業界の差のうち帰属させる枠の按分。**
- b は条文の量であって実効の強さではない。罰則の有無と執行のゆるさは見えない。
- s はサブ産業の細分類が取れる法律だけ観測できる。多くは b と t だけの「中」になる。
- 係数の選び方に正解は無いので、感度（±1段階で順位がどれだけ入れ替わるか）を /methodology に載せる。

## 5. 凍結300本での妥当性の確認（式を決める前の測定）

1. 観測率：300本のうち、s・b・t が観測できる割合（確かさ「中」以上になる割合）。
2. 合計の検査：全群で Σ a_i = X_g、a_i ≥ 0。
3. 感度：b の切り方を（0.5〜2）と（0.25〜4）で変え、群内の順位の相関（Spearman）が 0.9 以上。
4. 検証済みの法律との整合：検証で「範囲＝全体」と判定された法律は群内で w が大きく、「範囲＝一部」は小さい向きになっているか（向きだけ見る）。

1〜4 のどれかが崩れたら、基準は採らず、この文書に理由を足して調整役へ。

## 6. 認知の罠と収束

- 「式があるから確かだ」：式は按分の約束であって、効果の測定ではない。確かさの印と限界の文言を消さない。
- 「重みを工夫すればもっと正確になる」：係数を足さない。増やす前に、3項のどれが観測できているかを直す。
- 収束：まずこの文書を採って、実装は検証→配分の PR で1回だけ。
