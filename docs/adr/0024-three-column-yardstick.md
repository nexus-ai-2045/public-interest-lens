# 設計決定0024：額の物差しを三欄にする（付加価値／国の収支／採算）

日付：2026-10-30。状態：採用（2026-10-31：三欄を全3,415本の1表にし、ロジック検査の違反を0にした）。ねく 2026-10-30「マクロ・ミクロの経済学とビジネスの損得を土台に、人情は省いて機械的に正しく計算する」。

## 決めたこと
1. **評価の土台：** 現代のマクロ経済学（GDP・付加価値）とミクロ経済学（誰が得して損したか）を基礎に、ビジネスの採算（投資対効果）の見方を添える。レイオフなどへの配慮は計算に入れない。ただし失業期間の付加価値の損失のような測れる量は残す。
2. **額は三欄に揃える。**
   | 欄 | 中身 | 順位・合計・配分 |
   |---|---|---|
   | 付加価値の増減（本線） | 産業の付加価値（GDP）の変化を円で | **これだけを使う** |
   | 国の収支（別表） | 税収の増減、給付・補助の支出など、国の財布の動き | 足さない・使わない |
   | 採算（参考） | 付加価値の増減 ÷ 国の支出 | 使わない。国の支出が分かる法律だけ |
3. **二重計上を作らない。** 税や補助金の移し替えは、それ自体は得でも損でもない。国の収支の欄を本線に足さない。
4. **確かさの印は必ず付ける。** 低いものは「参考」で折りたたむ。
5. **産業全体の差を1本の法律に丸ごと当てない**（R60）。範囲の合わない額は付けない。

## 実装の現状（2026-10-31）
- 三欄の表：`data/derived/three-columns-v1/columns.csv`（`scripts/build_three_columns.py`、`rebuild_public.py` の4段目）。全3,415本を1行ずつ。評価台帳（ledger.csv）にも同じ欄を足した。
  - 付加価値の変化：個別の因果の鎖（段階1〜3、順位に使う）／コロナ対応の費用便益と全体指標の参考の額（確かさ「参考」、順位に使わない）。損失は負、便益は正の円。
  - 国の収支：`tax-impact-v1/fiscal.csv`（財務省の税制改正の増減収見込み、平年度、億円）。付加価値の欄とは別の列で、順位・配分に入らない。見込みが取得済みの12本のみ（1998〜2010年度・2017・2020年度は旧表が未取得で、理由つきで空）。
  - 採算：付加価値の変化 ÷ 国の支出。国の支出が一次資料で分かるコロナ対応の給付・補助の支出の規模（中）がある法律だけ。ほかの法律は国の支出の一次資料が揃うまで空。
- 規則の一本化：`scripts/evaluation_rules.py`（狭い題名の語・向きと符号・出典つき関与）を、全法律の結果・全体指標・公開ランキング・ロジック検査・台帳が共有する。古い「単一の額」前提の重複判定は削除した。
- 検証の違反の直し：向きと額の符号が逆の17本、出典つき関与が無い額の13本（重なり込みで22本）は、額を付けず保留にした（`outcomes.csv` の経路が「市場（向きと額の符号が逆）」「市場（議員の関与の出典なし）」で、公開ランキングも同じ判断を使う）。狭い題名に経済全体の額を当てていた参考額122本は付けず、理由つきにした。ロジック検査の基準は L1〜L6 すべて0。
- 残り：国の収支の14年度分の取得、国の支出（予算額）が分かる法律の採算、画面（/ranking の詳細）への三欄の表示。

## 認知の罠
- 「額が出た」ことと「正しい」ことは別。三欄に分けても、本線の額の正しさは検証スレッドの抜き取りで確かめる。
- 国の収支が大きい法律を「経済効果が大きい」と読みやすい。別表にしたのはそのため。
