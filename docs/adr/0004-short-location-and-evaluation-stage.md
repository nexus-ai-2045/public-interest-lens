# 設計決定0004：短い表示先と評価段階の分離

日付：2026-10-02。状態：ユーザー採用済み推奨案のローカル実装。公開リポジトリへの配送・サイト配信は別の承認と証拠を必要とします。

## 背景

画面選択用の行動キーには説明文と証拠一覧を含み、旧表示先はその全体を符号化していました。意味が重複する条件と自動選択まで保存するため、アドレスが長く、資料の訂正と表示先が結び付きます。実評価の補助画面も主画面の外観を共有せず、未読込に「レビュー待ち」と表示していました。

## 決定

- 表示先は順位の`/ranking`、人物の`/people/<id>`、行動の`/actions/<id>`、非公開保存評価版の`/evaluation`へ分けます。分野・方向・期間等は非既定の比較条件だけを残します。旧問い合わせ形式は読み取り、新形式へ置き換えます。
- 架空の行動には明示的な安定識別子を付けます。既存の算定キー・集計式は変更しません。説明文の訂正で表示先を変えず、空・重複・不明な識別子ではエラーにします。実資料の行動識別子は既存の改訂契約を継続します。
- 一時検索はブラウザの履歴状態へ保存します。明示的な共有では検索条件も含めます。選んだ根拠は行動の表示先へ結び、再読込と共有で復元します。自動選択された人物・根拠や既定の重みを通常のアドレスへ追加しません。
- 「この結果を共有」は算定版と架空データ全文の照合値へ束縛します。登録した照合値と実データが異なる場合は固定共有を拒否し、回帰テストが逆戻りを検知します。旧版がなければ最新結果へ自動置換しません。新しい短縮リンク用データベースは作りません。
- 架空版と非公開実評価版は共通ヘッダーと既存の二次元配置・色を使います。資料の真偽・算定状態を配色だけで伝えません。
- 非公開実評価は未読込、人物・行動の照合待ち、根拠不足・評価保留、保存評価版・独立検証要確認を区別します。保存点数や照合値だけから公開レビュー待ち・公開承認を導出しません。

## 検証と停止線

### ローカル保存版の再読込（2026-10-03）

開発サーバーで明示的に非公開保存先を設定した場合だけ、既存の保存評価版を取得します。評価版を指定した表示先はその版のファイルを読み、現在版へ置換しません。既存のハッシュ・参照検査を再利用し、保存点数を再採点せず表示します。取得失敗時は手動入力を残します。配信ビルド・プレビューでは自動取得の入口を提供せず、ブラウザの永続領域へ保存しません。

非公開保存先は同じリポジトリの `.local` 配下に限定し、`5MB`超・私的パス項目・版不一致を拒否します。記載人物数と保存された人物照合数を別表示し、保存検証記録をブラウザによる再検証へ読み替えません。開発時の再読込は従来の手動再選択規則の限定例外です。

旧表示先からの移行、直アクセスと再読込、戻る・進む、人物検索の0件、明示的な根拠選択、共有条件、同日訂正への照合値束縛、不明な人物・行動・評価版を検証します。両テーマ390・1440ピクセル、キーボード、動きを減らす設定も確認します。

ローカル開発サーバーの直アクセス成功は、`Sites`配信環境の書換え設定の成功ではありません。配信時は同じ表示先の直アクセス・再読込を別に実測します。非公開保存評価版は再読込時に同じファイルを選び直し、原本や全文をブラウザの永続領域・公開配信へ保存しません。実評価の根拠不足、配送、公開、ブランチ整理の残務はこの画面工程の合格で解消済みにしません。
