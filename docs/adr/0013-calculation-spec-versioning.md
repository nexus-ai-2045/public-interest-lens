# 設計決定0013：計算方法の仕様を版つきで固定し、変えるときは版を上げる

日付：2026-10-24。状態：採用（ねくさんの指示「その時その時で計算の仕方をコロコロ変えてもしょうがない」、2026-10-24）。

## 1. 決定

1. 損失額・便益額・確かさ・責任の配り方の計算は、**計算方法の仕様**（以下、仕様）として1か所に固定する。式の正本は `app/src/method-spec.ts`、読む用の清書は `docs/計算式.md`（正本から自動で作る）、公開サイトでは `/methodology` に数式で出す。
2. 仕様には全体の版（`method-spec-v1.0` のように）と、部品ごとの版（`impact-rule-v1`、`loss-rule-v1`、`benefit-rule-v1.2`、`macro-v1`、`observation-split-v1`、`causal-shapley-v1`、`certainty-v1`）を付ける。公開データ（`ranking.json` の `generatedFrom.rules`、`members.json` の `rules`）に出る版は、仕様に「採用」として載っていなければならない（テスト `app/src/method-spec.test.ts` で確かめる）。
3. **計算を変えるときは、必ず版を上げる。** 1回ごとの調整で式・しきい値・対応表を変えない。法律ごと・人ごとの例外は作らない。
4. 版を上げるときは、同じ変更の中で次の3つを残す。
   - 変更理由（だれの指示か、どの誤りを直すか）。
   - 影響：前の版と新しい版のデータベースを `python3 scripts/compare_db.py 前.sqlite 新.sqlite` で比べた結果（法律と議員の上位20の入れ替わり、確かさ別の本数と額の合計）。この ADR の「6. 変更の記録」に要点を書く。
   - `app/src/method-spec.ts` の式と版、`docs/計算式.md` の作り直し。
5. 版の上げ方：
   - 大きい版（v1 → v2）：何を額にするか・だれに配るかの考え方が変わる（例：配り方を「成立への寄与」から「行動 × 向き × 結果」に変える）。
   - 小さい版（v1.0 → v1.1）：しきい値・対応表・既定のつまみが変わる。
   - 直し（コードが仕様どおりでなかった誤りを直す）：仕様の版は変えず、変更の記録に「直し」として書く。
6. 責任の配り方は、今の式（`causal-shapley-v1`）を **配分 v0** とし、「損失額の責任の配り方を見直す」の作業で決まった式を **配分 v1** としてこの仕様に取り込む。以後の配り方の変更は、この仕様の版上げで行う。設計の中身は見直しの作業（設計決定0014、配り方の変更）が持ち、この仕様は式の清書と記録の形を持つ。両者の合意は 2026-10-24。

## 2. 物差し（すべての額をそろえる単位）

| 何を | 決めたこと | 状態 |
|---|---|---|
| 結果の物差し | GDP（産業別の付加価値、国民経済計算 2008SNA）。世界シェア・株価・雇用は額にせず補助の記録にする | 採用（ねくさん 2026-10-24「とりあえず GDP」） |
| 実質化（数量） | 産業の伸びは**連鎖方式の実質付加価値**（OECD 表6 の LR）で測る。名目を物価でわって作り直さない | 採用（loss-rule-v1） |
| 円への換算 | 伸びの差（比）に、開始前最後の年の**名目付加価値**を掛ける。額の単位は「その年の円」 | 採用 |
| 年をまたぐ額の比較 | 別の年の円を同じ円にそろえるときは **GDP デフレーター**（生産の物価）を使う。**CPI は家計の物価**なので、付加価値の額の換算には使わない。CPI は物価・賃金の実質化（家計の側の指標）にだけ使う | 決定。表示への導入は v1.1 |
| 国際比較（伸び） | 伸びの比で比べるので、為替も購買力平価も使わない | 採用 |
| 国際比較（水準） | 1人当たり GDP・就業者1人当たり GDP など水準を比べるときは**購買力平価（PPP）**。市場の為替は使わない | 採用（設計決定0012） |
| 世界シェア | 市場の為替のドル（世界銀行 `NY.GDP.MKTP.CD`）。補助の記録だけ | 採用 |
| 比較の国 | 17か国・地域の固定の一覧から、窓の年の観測がそろう国（3か国以上） | 採用 |
| 趨勢（政策の前から続く動き） | 開始前5年の伸びの差を反実仮想に織り込む | 採用。潜在成長率（内閣府・日銀の推計）で置き換えるかは v2 の候補 |
| 名目と実質の国際比較 | 国どうしの比較は必ず実質（連鎖の数量 LR）の伸びで行う。名目（自国通貨）の伸びの差は大半が物価の差になる（2000→2023年、名目は日本1.13倍・他国1.93〜3.65倍、実質は日本1.16倍・米国1.62・韓国2.30・ドイツ1.31倍。「原因の軸」の作業の計算）。物価は各国・各産業の暗黙のデフレーター（名目÷実質）で別に記録する | 採用 |
| 連鎖の実質の足し算 | 連鎖方式の実質は足し算できない（産業を足しても全体にならない）。産業の合計や構成比は名目で出し、伸びは各系列の実質で出す | 採用 |
| 産業の物価の作り方 | 品質調整の方法が国で違う（英国の情報通信の物価0.38倍、日本の C26 は名目0.60倍・実質3.53倍）。情報通信・電子部品など品質調整の大きい産業の実質の差には「物価の作り方の差を含む」の印を付ける | 採用（印は v1.1） |
| 経済全体と産業固有の分解 | 産業の差 ＝ 経済全体の差 ＋ 産業固有の差 に分け、経済全体の差は全体にかかる決定（金融政策・財政・為替）に、産業固有の差は産業の決定（法律・規制・国策）に配る。同じ差を両方に配らない | 採用（原因の軸の額で使う。法律の額への適用は v1.1） |
| 系列の接続 | 定義・基準年の違う系列はつながない。旧基準の国民経済計算は貼り合わせない | 採用（設計決定0012） |
| 二重計上 | 同じ観測を共有する法律は、観測の額を本数で割る。移転（税・交付金）は便益にも損失にも数えない | 採用 |
| 新型コロナ | 2020年より前に始まる窓は2019年で切る | 採用 |

## 3. 決定（法律以外）の扱い

法律でない決定（日銀の金融政策、税制、為替の合意・介入、予算の配分、国債の発行、地方へのお金、閣議決定の国策）も、同じ枠組みに入れる。データベースの `decisions` 表に、決定日・決めた主体・一次資料・数値（金利・買い入れ額・予算額・目標）を持たせ、指標の系列と年度・決定日で結ぶ。

| 決定 | 効果の出し方（仕様に入れる順） | 状態 |
|---|---|---|
| 法律 | 今の式（2章、`docs/計算式.md`） | 採用 |
| 国策（閣議決定の戦略：e-Japan、Society 5.0、半導体戦略、クールジャパンなど） | 数値目標と達成状況を記録として並べる。額は、目標の分野の付加価値で法律と同じ式（確かさ「参考」） | 記録から始める（v1.1） |
| 日銀の決定会合 | 決定日の前後の市場の動き（イベントスタディ）と、不意打ち分からの局所射影。政策委員の賛否を向きとして使う | v2 の候補 |
| 税制・予算・国債 | 差の差（影響を受ける産業と受けない産業）。財政乗数は公的機関の推計（内閣府の短期日本経済マクロ計量モデルなど）を「定説」の印で使う | v2 の候補 |
| 為替の合意・介入 | イベントスタディ。署名・交渉した大臣は役職の帳簿 | v2 の候補 |
| 海外の政策 | 日本の決定と同じ表に、国と決定日をつけて並べ、日本との時間差を記録する | 受け皿のみ（v1.0） |

- 実測で出せない決定の効果に経済学の定説を使うときは、出典つきの値だけを使い、確かさは「参考」より上にしない。
- 重なる決定は1つのモデルで同時に推定し、分けられない分は等分して「同じ観測を共有」の印を付ける。どの決定でも説明できない残りは未帰属にし、だれにも配らない。

## 5. 取得元

データベースに入れる系列と決定の取得元は `data/db/source-registry.csv` に一覧にする。通信先に届かないもの（2026-10-24 の確かめで、日銀 `www.boj.or.jp`・`www.stat-search.boj.or.jp`、IMF、FRED、BIS、EU・米国・英国の法令サイト）は「通信先の許可待ち」として扱い、届くようになったら取得する。`*.go.jp` は 2026-10-24 の確かめで通信先としては届いた（サイト側が 403・404 を返すものは個別に経路を探す）。
