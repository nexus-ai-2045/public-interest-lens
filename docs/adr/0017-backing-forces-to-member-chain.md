# 設計決定0017：背後の力の帳簿を、議員の因果の鎖につなぐ（backing-forces-v1）

日付：2026-10-29。状態：採用（ねくの指示「全部推奨を採用でGO」2026-10-29、ロードマップ R29）。実装した範囲と、後の PR に回す範囲を分けて書く。

## 1. 境界と責務（先に決める）

- **主役は国会議員**。省庁・団体・政治資金・内閣・裁判所・教育界は「背後の力」で、**点数（純額・順位）の外の別帳簿**。この決定は、別帳簿を議員の因果の鎖（行動 → 結果 → 損失）に**参考として結ぶ**ことだけを担当する。額は配らない。
- **結び目は法律**。議員は法律に行動（提出・賛否・質疑）で結ばれている（allocation-v1、決定0014）。背後の力の記録も、名指しした法令名で法律に結ぶ。議員と背後の力は法律を介してだけつながり、直接の因果は主張しない。
- 属性（出自・国籍・信仰・家族）と有権者個人の属性・投票先は扱わない（決定0014の固定事項を引き継ぐ）。個人（学者・委員・官僚・個人の寄附者）は名指しせず区分でまとめる。

## 2. 実測できるものと、推定になるものを分ける（ねくの問い 2026-10-29）

| 層 | 中身 | 状態 |
|---|---|---|
| 実測 | 法律の損失（OECD 同産業との比較）／省庁の抵抗・団体の立場・寄附の件数（一次資料つき） | 画面は「実測の件数」と印を付ける |
| ルールによる推定 | 主体への額の配分（allocation-v1 の行動×向き、決定0014） | 既存。背後の力には**額を付けない** |
| 現実性の確認 | ロビー・政治的つながり・組織票の研究の推定値で配分の割合を検算 | 根拠値の台帳（別スレッド）が入るまで保留。入ったら幅の確認に使う |

「その主体のせいで何円」は観測からは出ない（因果の識別が要る）。この決定は件数と結び付けまでを実測の層に置く。

## 4. 結び付けの規則（backing-forces-v1）

正本は `scripts/build_backing_forces.py`。入力は既存の表だけで、数え方は `scripts/build_org_ledger.py` の `records()` に一本化した（重複して数え直さない）。

1. 記録の「該当法令・関連法令」から法令名を取る（成立した法律の題名の頭にある名前だけ。長い名前を先に取り、直前が漢字・かなの一致は別の名前の一部として取らない。略称は `law-aliases.csv`）。
2. 記録の日付に対して、**順序だけ**で法律を決める（年数のしきい値は使わない）：同名の法律のうち、日付以後で最初に公布されたもの（次の改正の前に記録）と、日付より前で最後に公布されたもの（直前の改正の後に記録）。
3. 所管：閣法の所管の省庁（決定9）の省庁全体の抵抗の件数を、画面側で既存の2表から結ぶ（弱い結び付け。その法律に限った記録ではない）。
4. 結べない記録は `unlinked.csv` に理由つきで残す（法令名の記載なし／法令名ではない／題名に無い）。取りこぼしを隠さない。

## 5. 正本と派生（SSOT）

- 記録の正本：`data/acquired/blocking-actors/`（原本照合済みだけ）→ `org-ledger-v1`（件数）。
- 結び付けの正本：`data/derived/backing-forces-v1/`（`law-links.csv`・`unlinked.csv`・`member-contacts.csv`・`manifest.json`・手で保守する `law-aliases.csv`）。
- 画面の `members.json` はそこからの派生。点数に影響しないことを vitest（議員・政党・法律の出力が結び付けの有無で同一）で固定した。
- 団体名は `org_names.org_key` で一本化（審議会の団体・政治資金・支持基盤が同じ鍵）。

## 6. 配分の重みに使う案（未採用。採用の条件つき）

ねくの考え：主体への配分は、行動の記録に加えて、(1) その議員がどれだけロビーとつながっていたか、(2) 組織票（どの団体が推薦・支持しているか）でも変わる。

- 採用しない理由：件数や寄附額から「何％動いたか」を出す係数の根拠が、いまのリポジトリには無い。根拠無しの重みは、点数を恣意的にする（注意：寄附額が大きい＝影響が大きい、とは限らない）。
- 採用の条件：(a) 根拠値の台帳に、ロビー・政治的つながり・組織票の研究（メタ分析＞査読論文＞WP）の推定値が入る、(b) 結果が分かっている政策のバックテストで、重みを入れた方が既存の配分より外れが小さい、(c) 計算仕様を版上げし（決定0013）、人間レビューを通す。
- それまでは、**重みではなく結び付け（参考表示）**に使う：支持基盤の団体が、背後の力の記録で立場を示した団体と同じ団体名キーのとき、議員と法律の間に「接点の記録」を出す（`member-contacts.csv`）。「接点の記録だけ（因果は示さない）」の印。

## 8. 認知の罠（記録）

- 同じ法令名＝原因ではない。結び付けは「その法律の周りに記録がある」で、議員の行動の原因ではない。
- 件数の多さ＝影響の大きさではない。記録は規制改革の場で集まった**止めた側の事例**で、省庁全体の割合ではない（決定11）。
- 記録の無い法律＝力が無い、ではない。結べた法律は議員に配った法律のうち少数（取得先が規制改革に偏る）。
- 寄附・推薦と賛否の一致は因果ではない。賛成した議員が推薦団体に近い立場なのは、元から同じ考えだった可能性がある。
