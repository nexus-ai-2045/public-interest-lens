# 設計決定0003：実評価の改訂束縛と配信境界

日付：2026-10-01。状態：ユーザーが承認した`v1`計画の契約（識別子`ADR 0003`）。実装・実資料検証・公開は別の達成状態です。

## 背景

架空モデルの説明文を含む選択キーを、そのまま実在行動の永続`ID`へ転用すると、引用訂正で行動が増殖します。取得の成功や`AI`出力の`verified`という自己申告も、人物同定・引用照合・政策影響の検証を証明しません。

## 決定

- 架空表示用の入口は維持し、実評価は別の入力契約へ分離します。数値集計の本体は共通化します。
- 行動識別子`actionId`は提供元・行動・人物・政策の安定した記録キーから導出し、意味内容の改訂識別子`revisionId`を分離します。取得時刻は行動識別子に混ぜません。
- 賛成・反対・投票なし・不明を別状態として持ちます。反対票の単純反転、党籍からの推測、同一政策の矛盾を最大係数で押し切る処理はしません。
- 保存原本を再読する検証側と分析入力を分離します。実評価は人物同定、行動改訂、分析改訂へ束縛した検証結果を要求します。入力`JSON`内の自己承認は検証権限を持ちません。実行側の`TrustedContext`を必要とし、改訂後は旧検証を拒否します。
- 機械算定の成功から公開許可を生成しません。表示候補は人間レビュー待ちで、実在人物の公開版は対象・ソース状態・評価版・配信範囲の承認を別に確認します。
- `GitHub`は正本、`Sites`は派生配信先です。原本・検索用`SQLite`・`AI`ログ・個人パス・検証記録は非公開ローカルへ残し、公開する引用・所在・集計・取得範囲は別の表示候補にします。ローカル検証用出力をそのまま配信しません。
- 2026-10-02の承認で、非公開実評価の版と表示条件を`URL`に保持する入口を追加します。参照版がなければエラーを表示し、架空版や別の評価版へ黙って切り替えません。第221回閣法53号の投票行全体を接続実証に使いますが、全国の代表順位とは表示しません。

## 帰結と検証

人物や分析を確認できない実資料は保留のまま閲覧できます。全件保留でも収集や契約の試験は成果ですが、`M2`実評価の成立や`v1`完成とは扱いません。安定した識別子、改訂後の旧検証拒否、引用改ざん、立場矛盾、重複、未知の賛否、再実行、前正常版の保持を回帰テストで確認します。

`M0`から`M4`の進行状態は `PROJECT_SSOT.md` と `docs/operations.md` に集約し、新しい台帳を作りません。2026-10-02時点で`M0`の画面とロードマップは`PR` #8でマージ済み、対象限定整理は残務です。`M1`はローカル実資料の表示・検証済みですが遠隔配送前で、`M2`の実在同定・独立検証・根拠付き評価は未成立です。件数・検査結果・再開手順は運用正本を参照し、古い配送待ち記録を現在状態としません。契約の実装や人工入力の試験を実在人物の採点成功と読み替えません。今回の到達点は`M1`配送、`M2`成立、`M3`レビュー材料準備までであり、配信と`M4`の運用保証は含みません。

`Sites`・自動スケジュール・外部送信・マージ・削除の許可は、本設計決定やテスト結果から連鎖させません。実行入口と結果保存は既存運用文書へ戻します。
