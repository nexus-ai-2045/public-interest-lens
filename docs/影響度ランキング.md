# 影響度ランキング：深掘りの優先順位の基準（impact-rank-v0）

日付：2026-10-29。ねくの指示「どれぐらい影響度があるかで深掘りするかを決める。メタ分析と論文の数字で出せるはず」。台帳（`data/evidence/ledger.json`、3者照合ずみの値）の効果量だけから出す。

## 一本の式

**影響度 ＝ 産業内の効果量（GDP 水準に直した%） × 対象産業の GDP 比 × 確かさの重み**

- 効果量：台帳の `verified` の値。年率（%pt/年）の差は、停滞の期間（1995〜2025年の30年）を掛けて水準にする。水準の効果（%）はそのまま使う。
- 対象産業の GDP 比：内閣府 国民経済計算の経済活動別 GDP を丸めた概算（製造業 約20%、電気ガス水道・運輸郵便・情報通信 約13%）。**公式統計としての台帳入りは未了**（下の残り）。
- 確かさの重み：台帳の `confidence`（高1.0・中0.6・低0.3）。
- 判定：影響度 1.0 以上は**深掘り（優先）**、0.3〜1.0 は**深掘り（次点）**、0.3 未満は**暫定値のまま止める**（実測が出るまで掘らない）。

## 読み方と、認知の罠

- **1位の ICT は、日米の差そのもので、全部が政策の帰属ではない**（企業の経営慣行・人口・産業構成も混ざる）。「ここを掘れば10%取り戻せる」ではなく「掘る価値の桁が大きい」と読む。帰属は後続のシフトシェア分解（設計書7章）と機構ごとの理論値で絞る。
- 【天井】の TFP 差（約30%）は、**TFP に対応する仕組み**（参入障壁・新陳代謝など）の合計の上限で、順位の対象ではない。資本投入の寄与（ICT 資本の使い込みなど）と需要側の政策は別の成分なので、この天井で制限しない。TFP 系の仕組みの影響度の合計がこの天井に届かない分は、まだ見つけていない TFP 系の仕組みか、帰属できない差。
- 人口の高齢化（-9.6%）は政策の帰属対象外。基準線としてだけ置く。
- 金融政策（QQE）は需要側で、技術を阻んだ話ではない。別枠として残す。
- 行政手続コストは**損失額**で、付加価値の増減とは性質が違う。重みを掛けても桁が小さいので止める判定は変わらない。
- **換算式が足りず、順位に入れられなかった**もの（止める判定もしない。換算できてから判定する）：R&D 税制・補助（rd-09 は単年の支出の増加率、rd-02 は資本ストックへの弾力性で対象が違う。既存ストック・減耗・効果の期間でストック増加率に直す必要がある）、ゾンビ企業による投資抑制（stagnation-06）、公共インフラの生産弾力性（human-06・07：日本の資本ストックの国際差が要る）、教育・労働市場・税の弾力性（日本に差の根拠が無いか効果が小さい）。
- 確かさ「中」が大半なのは、台帳の値が日本の実測でなく外国の研究や公的試算だから。精度95%の測り方（設計書5章）で磨く前の、優先順位づけ用の粗い物差し。

## 残り（追加はこの表にだけ積む）

1. 産業別 GDP 比を、公式統計（内閣府）の値として台帳に入れる（概算の丸めを置き換える）。
2. 順位の上位3つ（ICT・金融政策別枠を除くと参入障壁・新陳代謝）を、設計書の補正（乗数・代替・ラグ）を掛けた理論値と、他国実績で検算する。
3. 換算式が未定の仕組み（ゾンビ・インフラ）の換算を決める。
