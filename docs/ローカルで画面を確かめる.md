# ローカルで画面を確かめる（Vercel を待たない）

更新日：2026-10-18。画面の確認は Vercel のデプロイを待たず、手元（クラウドの環境でも Mac でも）で公開版をビルドして localhost に出し、ブラウザで開いて済ませる（2026-10-17 ユーザー指示）。Vercel の無料枠（1日100回）を使い切っても作業は止めない。

## 一発で確かめる

```
cd app
npm ci                 # 初回だけ
npm run preview:check  # 公開版をビルド → localhost:4180 に出す → 主要6画面をパソコン幅とスマホ幅で開く
```

- 開く画面：`/`、`/ranking`、`/members`、`/world`、`/methodology`、`/demo/motion`（`app/scripts/local-preview-check.mjs` の `PAGES`）。画面を足したら、そのタイトル（document.title に含まれる語）と一緒にここへ足す。
- 合格の条件：応答が 200、ページのエラー（`pageerror`）が無い、本文が空でない、画面ごとのタイトルが出ている（ルートが消えても 200 で別の画面が出るため）。ポートが使用中で起動できなければ失敗にする（別のサーバーを検査しない）。1つでも外れたら終了コード1。
- 画像：`.local/preview/<日付>/pc_ranking.png` などに保存する（`.local/` は Git に入れない）。
- ビルド済みなら `npm run preview:check -- --no-build`。ポートは `PREVIEW_PORT` で変えられる。

マージ前は、これを含む事前チェック `python3 scripts/preflight.py --smoke`（リポジトリの直下で）を回す（設計決定0010）。

## 操作まで確かめる（E2E）

```
cd app
npm run test:e2e:public                 # 公開版をビルド → localhost:4181 → 主要4ページの表示と操作をパソコン幅とスマホ幅で
E2E_NO_BUILD=1 npm run test:e2e:public  # ビルド済みの dist を使う
```

- 対象：`/ranking`（一覧・絞り込み・行の詳細）、`/members`（一覧・つまみ・URL での復元）、`/world`（グラフ）、`/methodology`（見出し）。テストは `app/e2e/public/`、設定は `app/playwright.public.config.ts`。
- データの件数は毎朝変わるので、固定値ではなく「0より多い」「操作の前後で変わる」で確かめる。
- 事前チェック `python3 scripts/preflight.py --smoke` がスモークの後にこれを回す（設計決定0011）。

## ブラウザはクラウド内蔵の Chromium

画面の確認・スクリーンショット・ブラウザ操作は、クラウドの環境の Chromium（`/opt/pw-browsers/chromium`）で行う。持ち主の Mac の Chrome は使わない（2026-10-18 ユーザー指示、設計決定0011）。官公庁サイトのように通信先で届かないものは、Chrome で迂回せずロードマップの R16 で解く。

## 手で開く

```
cd app
VITE_PUBLIC_SITE=true npm run build
npx vite preview --host 127.0.0.1 --port 4180
```

Mac なら Chrome で http://127.0.0.1:4180/ranking などを開く。開発中の即時反映が欲しいときは `npm run dev`（ポート 5173）。ただし公開版と同じ見え方を確かめるのは `VITE_PUBLIC_SITE=true` のビルドのほう。

## 落とし穴

- クラウドの環境では Chromium が `/opt/pw-browsers/chromium` にある。`playwright install` はしない（スクリプトは自動でそこを使う。別の場所なら `CHROMIUM_PATH`）。
- 配布ファイル（`app/public/distribution/*.json`）を作り直した後は、ビルドし直さないと画面に出ない。
- 本番（https://kokuzoku.nexusai2045.com ）への反映は、main へのマージで Vercel が自動で行う。無料枠の上限の間は反映されないので、枠が戻ってから本番を確かめる。マージの必須チェックは `verify` だけで、Vercel の赤ではマージを止めない（`docs/ロードマップ.md` の「進め方」）。
