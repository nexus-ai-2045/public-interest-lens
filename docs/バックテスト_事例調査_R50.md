# バックテストの事例を足す調査（R50・R51、2026-10-29）

設計決定0020の追記（v1.1）を受けて、本命（識別が強い／日本の研究／結果指標が計算の指標と同じ／計算が判定を出している）の事例を10件以上にできるかを調べた。結論：**今回の調査では1件も足せなかった。計算の式も変えていない。**

## R51：計算側に足せる指標があるか
v1.1 で「計算に同じ指標が無い」と止まった10件の結果指標は、運賃、消費者余剰、引受手数料、為替スプレッド、郵便物数、料金プランの選択確率、賃金帯・年齢性別・非正規など特定集団の雇用だった。
- 家計調査・消費者物価（`data/acquired/domestic-stats/cpi_items_annual_*`）に足せる価格は、通信料（固定・携帯）、鉄道運賃（JR・JR以外）、電気代、ガス代など。運賃（航空・タクシー）、手数料、スプレッドの系列は無い。足せる価格の系列に当たる事例は、今の10件には無い。
- 集団別の雇用・賃金、手数料、スプレッドは、個票か市場データで、リポジトリにも公的な集計表にも無い。
- したがって、指標を足しても本命の件数は増えない。method-spec は変えない（版上げなし）。足す価値があるのは、事例が先に見つかった指標（下の調査で出なかった）。

## R50：文献調査
領域8つ（電力小売自由化、民泊、通信・携帯、航空、小売・酒・医薬品ネット販売、労働者派遣・最低賃金、タクシー・鉄道・バス、郵政・金融・農協）で、次の条件をすべて満たす行を Haiku 8本が探した：日本の政策／差の差・操作変数・回帰不連続・合成対照・RCT・対照のある事象研究／結果指標が産業の生産・雇用・価格・旅客数のどれか／効果の数値を原文で写せる（DOI は Crossref で照合）。
結果は**8領域とも0件**。理由は、識別がある日本の研究は少なく、あっても次のどれかだった：
- 手法が傾向スコアマッチングや固定効果で、識別が弱い（小売：松浦・菅野 2009）
- 結果指標が雇用・生産ではなく、不安感や価格（派遣：Kuroki 2012）
- PDF が暗号化されていて、効果の数値を原文で確認できない（RIETI の複数の論文）

## 次の選択肢（判断が要る）
1. 本命の条件を緩める（識別が中程度＝マッチング・固定効果まで）。件数は増えるが、v1 の考えどおり「緩めた参考」としてしか使えない。
2. 本命を「日本の研究」に限らず、外国の同種の政策の研究から日本の同種の法律の向きを当てる検証（移植の検証）に広げる。暫定評価の考え方（設計決定0015・0016）に近いが、別の定義になる。
3. 暗号化 PDF の論文などを人が開いて数値を確認する。件数は増えるが、人手が要る。
おすすめは **2**。日本の事後評価は少なく、条件を満たす日本の研究は今後も増えにくい。暫定評価（他国の実績から日本を予測する）の精度を測るのが目的なら、2のほうが目的に合う。
