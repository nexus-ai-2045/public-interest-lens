## 働き方改革関連法（`workstyle-v1`）

### なぜこの比較群か

上限規制は大企業に2019年4月、中小企業に2020年4月から適用されました。建設業は2024年3月まで適用が猶予されていました（自動車運転・医師も猶予ですが、労働力調査の産業区分と一致しないため使いません）。

判定ルールは開始後1年目を除き、2〜5年目（2020〜2023年）の差を見ます。中小企業は2020年に適用されるため、比較群になりません。建設業は2020〜2023年の間、上限がかかっていない状態のまま残るので、比較群にできます。

### 固定する定義

- 期間：開始前は2014〜2018年（判定ルールの上限5年）、開始後は2019〜2023年。2024年以降は建設業にも上限がかかるため、判定には使いません。
- 向き：低いほど良い（`better: 'lower'`）。
- 経済全体の指標・対象分野の付加価値比率：未取得の間は `null` のまま渡し、段階2以上を主張しません。
- 統計の産業分類が途中で改定された場合は、その年をつながず、改定の注記を残して保留します（`PROJECT_SSOT.md` の系列接続禁止）。

### 既知の弱点（評価時に反証として記録する）

- 新型コロナの影響は業種ごとに違い、2020〜2021年の差に混ざります。
- 建設業では2024年の適用を見越した前倒しの対応が、2020〜2023年に始まっていた可能性があります。これは効果を小さく見せる向きに働きます。
- 製造業内の中小企業は2020年から適用されるため、開始後2年目以降の対象群は大企業と中小企業の混合です。

### 人物との結びつけ

関与は参議院本会議（2018-06-29、法案成立）の個人別投票記録で確定し（押しボタン投票であることは取得時に確認）、党の方針から個人の賛否を補完しません。主導（法案提出時の厚生労働大臣）は公式の在職記録で確認します。直近3回の国政選挙の立候補者と照合できた人物だけを v1 の対象にします。
