# v0.0.1 ローカル試作のレビュー材料

日付：2026-10-09。これはGitHubリリースでも、実在人物の評価の公開でもありません。基準コミットは `codex/finish-delivery-20261006` の `0ea92f43b7cb5fc97318f0b0522a1f872c749225` で、その上の未送信の変更です。

## 実装状況

- 既存のReact / TypeScript / Vite、架空ランキングの算定、`/__local__` の保存版読込、結果期間の評価器は残しています。
- 公開配布版を追加しました。世界銀行の日本の実質GDP・名目GDP・人口（1980〜2025）と、金融庁公開ページに基づく「金融再生プログラム」1件です。
- 画面は、実施、観測、比較と反証、人物と機関、不足資料を分けて読めます。内部の版識別子は出典の詳細に置いています。
- ローカル原本が無いときだけ配布版を表示します。指定版が無いときは止め、別版へ置き換えません。

## できること

- 40年を入口に、30・8・4・2年と任意期間で統計を見る。欠測は0にしません。
- 2002〜2005年の結果が、40年・30年の窓に入り、直近4年には入らないことを確認する。
- 竹中平蔵、伊藤（2002年の副大臣と2005年の大臣は同一と断定しない）、岡本（名は引用範囲に無い）の公的な発言を、点数なしで読む。
- 金融庁、検討会、主要行の関係を、所属や名簿だけでは加点しない形で読む。
- 何が足りないかを、ページ内の不足資料として見る。

## できないこと

- 実在人物の採点。現在0件です。未評価を0点にはしていません。
- GDP停滞の原因帰属、全国の責任割合、GDP損失額。影響の規模は保留です。
- 不良債権比率8.4％と2.9％、額26.8兆円と7.4兆円は、公式発表の引用です。再集計でも因果認定でもありません。
- 工程表の現行URLと、内閣府の旧会見URLは取得日に404です。本文が開けていない項目は実施済みにしていません。
- 非公開原本、実DB、内部ログはこのリポジトリにありません。`/evaluation` の保存版は、ローカルにファイルがある場合だけです。
- 公開push、マージ、サイト配信、認証や課金の変更はしていません。
