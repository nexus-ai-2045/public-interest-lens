# 評価エンジンの出典照合

日付：2026-11-20。対象：現行評価エンジン（`method-spec-v3.0` / 点数設計 v2.1）が使う基準・重み・閾値・評価項目。照合した場所はリポジトリ内の docs・コメント・データファイルに書かれた出典だけ。推測で出典を足していない。

リポのゴールの正本は `PROJECT_SSOT.md` と `docs/ロードマップ.md`（G1〜G9、R番号）。公開方針の正本は `docs/adr/0008-publish-everything-with-certainty-marks.md`。表1の列「G」は、その主張が満たそうとしている完了条件。食い違いは §2.2。

Web 確認は 2026-11-20 に、リポジトリに書かれた URL へ HTTP GET/HEAD を送った範囲。ボット拒否（403）はリンク切れに数えない。404 だけをリンク切れとする。

## 0. 読み方

| 印 | 意味 |
|---|---|
| 確認済み事実 | リポジトリの文面、または今回の HTTP / Crossref 応答 |

| AI 解釈 | 主張と出典の対応づけ、根拠の強さの判定 |
| 未確認 | 有料本文、403 で開けなかった頁、今回到達しなかった Crossref |

出典の種類は依頼どおり次の4つだけ：学術論文 / 公的資料 / 先進国の事例 / なし。

根拠が弱いものは表でも問題表でも「弱い」と書く。列「G」はロードマップの完了条件。G7・G8・G9 に直接対応するエンジン定数は、この63件には無い。

## 4. 限界

- 有料の本文は開いていない。DOI 403 は「頁が無い」ではない。
- Crossref は途中から 429。mapping の一部と台帳の既存フラグ以外は、DOI の再確認が未了。
- 先進国の事例（M3 政策カード）は、このエンジンの現行 mapping には載っていない。設計書は M3 を系統として書くが、値の出典表はこの照合の対象外。
- 架空データ用の A1・A2 と、実資料用の A3 は別経路。混ぜて一つの「エンジンの重み」とはしていない。
- コードの挙動は変えていない。
