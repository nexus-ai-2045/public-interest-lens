# 計算式と実装の突き合わせ

原因: 成立した法律の額と人への配分は、緩和・廃止・解除を条文の向きとして読まず、指標の差の符号と役割の符号だけを使う。未成立の提出の点だけが、題名と仕組みの語で緩和をプラス、強化をマイナスにする。

## F-緩和の中身

測定は 2026-11-20 時点の `data/derived/all-laws-v1/outcomes.csv`（3,426行の成立法）と `data/derived/unenacted-bills-v1/direction.csv`（965行）、`data/derived/macro-v1/macro.csv`。

### 点数や金額に入るか

成立した法律の結果では、題名に「廃止」を含む23本は額あり0本（保留11、評価対象外10、測定できない2）。題名に「規制」を含む50本も額あり0本。題名に「緩和」「自由化」「撤廃」「解除」を含む成立法は0本。組織手続か定型改正なら評価対象外になり、法律ごとの額は付かない（`scripts/build_all_laws_outcomes.py` 58行、399〜401行）。題名が基本法・整備法・設置法・差押禁止なら、廃止や緩和という言葉が無くても評価対象外になる（同 223行）。廃止・緩和・解除そのものを対象外にする語は、この正規表現に無い。

群の記述の額には入る。`macro.csv` の結果が「額」の行は、廃止や規制の題名でも産業の差の円が付く。例は閣法-142-57（真珠養殖事業法を廃止する法律案、中央値は負）と閣法-142-72（風俗営業等の規制の改正、中央値は負）。曝露ランキングはこの「額」の行だけを産業×年に展開する（`app/src/exposure-inputs.ts` 113〜116行）。法律の結果の「額あり」とは別の入口である。

因果の点 Score_p に、緩和・廃止・解除を足す処理は無い。架空表示の点は影響度×役割係数で、緩和という役割は無い（`app/src/ranking.ts` 17行、107行）。証拠評価も同じ係数（`app/src/evidence-evaluation.ts` 127〜128行）。

未成立の提出法案だけ、別欄の提出の点に入る。規制緩和・規制の撤廃・自由化・競争促進はプラス、参入・価格・数量の規制強化はマイナス、停止・凍結・中止は不明で点0（`scripts/build_unenacted_direction.py` 26〜34行、112行）。direction.csv では P2 が11本（根拠に「緩和」）、N3 が2本、X1 が3本。解除という語に当たる行は0本。この ±1 は「失わせた額」に混ぜないとファイル先頭に書いてある（`scripts/build_submitter_points.py` 3〜6行）。公開の未成立画面は規模点だけで、向きも円も出さない（`app/src/unenacted.ts` 1行、`app/src/UnenactedBills.tsx` 34行）。

画面の性格分類は点に入らない。題名の「緩和」は「既得権益・業界を守る」側の語で、絞り込みにだけ使う（`app/src/law-character.ts` 16行、20〜24行）。

### 入るときの符号

法律の額の符号は、指標の差 Δ と「低いほど良い」が一致すれば貢献、それ以外は悪影響（`app/src/impact-rule.ts` 59行）。損失額は正が失った額で、中央値の符号がこの向きと逆なら額を出さない（`app/src/loss-rule.ts` 89〜90行）。緩和・廃止・解除では符号を変えない。

曝露の符号は群の差の符号に役割比率を掛けたもの。反対だけ −1（`app/src/exposure-ranking.ts` 46行）。緩和する法律への賛成も、強める法律への賛成も、同じ正の比率である。

未成立の提出の点は、プラスが +1、マイナスが −1、不明が 0（`scripts/build_unenacted_direction.py` 112行）。重み 0.1 を掛けた列も同じファイルに書く（`scripts/build_submitter_points.py` 16行、34行）。順位や曝露には足していない。

### 強めたときと同じ基準か。対称か

成立した法律は、緩和も廃止も解除も、強めた法律と同じ関数に入る。別のしきい値は無い。対称なのは測定の手続きで、符号の意味は対称ではない。緩和を強めの逆符号にする分岐は、impact-rule、loss-rule、exposure-ranking、ranking、evidence-evaluation のどれにも無い。

未成立の規則は語ごとに非対称である。緩和・撤廃・自由化はプラス、参入・価格・数量の規制強化はマイナス、停止・凍結・中止は不明のまま（`scripts/build_unenacted_direction.py` 27行、30行、32行、85〜86行）。解除という語の規則は無い。題名がどの規則にも当たらなければ不明で点0（同 48行）。バックテストの同種判定は、緩和と強化を別の手段とし、研究の符号を反転して当てない（`docs/adr/0021-backtest-transplant-v2.md` 49行）。これは法律の点の式ではない。

### 同じ人に、止めた分と外した分が二重に付くか

相殺はしていない。曝露は法律ごとの関与を足す（`app/src/exposure-ranking.ts` 180〜184行）。同じ関与を1つにまとめる鍵は、法律・役割・院・配り先で、廃止される側の法律との対ではない（`app/src/exposure-inputs.ts` 175〜182行）。同じ人が、止めた法律と、その後に外した法律の両方に関与していれば、両方の枠が足される。引く処理は無い。

未成立の提出の点は、その人の成立した法律の曝露や損失額に足していない（`scripts/build_submitter_points.py` 6行）。同じ人が両方に載ることはあるが、合計するコードは無い。
