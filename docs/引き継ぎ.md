## 3. 書き方と作業の作法

- 数字は必ず「Y本中X本、どの定義で」を書く。
- 日本語で書く。個人名・端末のユーザー名・個人のメール・個人のパスは、どこにも書かない。
- コミットは nexus_ai の名義（nexus-ai-2045 の GitHub noreply）。push の前に repo-preflight を通す（[AGENTS.md](../AGENTS.md)）。
- 公開リポの PR 本文・issue・コミットに、claude.ai のリンク、セッションの行、`Co-Authored-By` 行を入れない（preflight の名義検査で赤になる）。PR の題名と本文の見出しは日本語（dependabot の PR も、題名と見出しを日本語に直してから通す）。
- 毎回 Claude の `/code-review` を通す。open PR は8本まで。マージは自分で、条件は進め方 2章の 6〜8。
- `docs/計算式.md` は `app/src/method-spec.ts` からの生成物。正本を直して `cd app && node scripts/build_formula_doc.mjs`。
- push はいつでも許可（2026-11-01）。push を止めるフックや設定があれば直す。

## 4. 環境の制約

| 制約 | 中身 |
|---|---|
| 通信が断られる先 | 経産省・e-gov（旧 API）・官邸・congress.gov・国立国会図書館 WARP（403）。e-Gov 法令 API v2 はクラウドから取れる（2026-11-19 確認）。詳細は [官公庁の原本取得](官公庁の原本取得.md) |
| クラウドから | ブランチの削除とタグの push は 403。Mac で行う |
| Mac | gh のトークンが読めず、PR を作れない（クラウドで作る）。Mac の自動実行はリモートのブランチ削除を止める（手で実行）。`~/.claude/settings.json` の env に DO_NOT_TRACK などを入れると壊れる |
| 名義検査の誤検知 | クラウドのコンテナでは、端末名が2文字のため個人名義の検査が誤検知する（CI は緑）。issue repo-preflight#82 |
