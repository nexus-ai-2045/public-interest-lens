# データベース（kokuzoku-db/v1）

法律・議員・党・団体・決定（国策・金融政策・税・予算・国債・地方財政・為替）・指標の系列・一次資料・配分を、関係のついた1つの SQLite にまとめたものです。表の定義は [data/db/schema.sql](../data/db/schema.sql)、計算の版は [設計決定0013](adr/0013-calculation-spec-versioning.md) と [計算式](計算式.md) にあります。

## 作り方と使い方

```sh
python3 scripts/build_database.py            # data/db/kokuzoku.sqlite（約55MB、Git に入れない）と app/public/distribution/charts.json
python3 scripts/query_db.py                  # よく使う問い合わせの一覧
python3 scripts/query_db.py 議員の内訳 person=麻生太郎
python3 scripts/query_db.py 法律の配り先 law=閣法-196-2
python3 scripts/query_db.py 年ごとの額 --csv > 年ごと.csv
python3 scripts/query_db.py 産業の付加価値 country=JPN industry=J   # 名目・実質（連鎖）・暗黙のデフレーター
sqlite3 data/db/kokuzoku.sqlite              # 自由に SQL を書くとき
```

- 入力はリポジトリの中の JSON/CSV だけで、通信はしません。同じ入力からは同じ中身ができます（作った時刻は入れず、入力の SHA-256 を `meta` に入れる）。
- 毎朝の自動更新（`scripts/rebuild_public.py` の最後）で作り直します。データベースの中身を手で直さず、元の JSON/CSV を直してください。
- 計算の版を上げるときは、前と後のデータベースを作って `python3 scripts/compare_db.py 前.sqlite 新.sqlite` で影響（上位の入れ替わり、確かさ別の本数と額）を出し、設計決定0013 の変更の記録に書きます。

### 財政・為替介入・骨太の方針（data/acquired/fiscal、scripts/fetch_fiscal.py）

毎朝の自動更新が月1回だけ原本を取り直し（`fetch_fiscal.py update --monthly`）、データベースを作るときに読みます。原本は `.local/fiscal/raw`（Git の外）、取得の記録は `data/acquired/fiscal/manifest.csv` です。

| ファイル | 中身 | 表 |
|---|---|---|
| fx_interventions.csv | 財務省 外国為替平衡操作の実施状況。実施日・額（億円）・売買通貨 | decisions（`為替-日付`）・decision_amounts |
| fiscal_flows.csv | 財務省 財政統計 第19表（当初・補正）・第20表（決算）・第4表（歳入）、総務省 地方財政白書（歳入決算 総括の純計） | fiscal_flows。一般会計の当初・補正は decisions（`予算-年度-当初`・`予算-年度-補正`）に結ぶ |
| policies.csv | 内閣府 骨太の方針の PDF と、1頁目から読んだ閣議決定日 | decisions（`国策-honebuto-年`） |

fiscal_flows の `category` の読み方（額はすべて円）：

- `主要経費別`：足すと表の「合計」になる経費（社会保障関係費・国債費・地方交付税交付金など）。年度で項目の名前と分け方が変わる（昭和20年代は「重要経費」で、終戦処理費などがある）。
- `主要経費別（内訳）`：上の経費の内訳。`item` は「親／内訳」。昭和44年度の決算の文教及び科学振興費は、取得元の表で内訳の和が計より10億円多い（表のまま）。
- `主要経費別（合計）`：合計・主要経費計・重要経費計・総合計。
- `主要経費別（合計の外）`：「合計」の後にあり「総合計」にだけ入る行（前々年度の決算不足補てん繰戻）。
- `歳入（主要科目別）`：租税及印紙収入・公債金・歳入合計（決算）。公債金はその年度に国債で賄った歳入で、借換債は入らない。
- `地方財政（歳入）`：都道府県と市町村の純計（地方税・地方交付税・国庫支出金・地方債・歳入合計など）。

読み方で決めたこと（表の癖）：補正は年度内のすべての補正予算の合計（純額）。古い年の括弧書きの額（他の経費の一部を含めた額）は使わず、重ならない本来の額を使う。令和元・2年度の第19表にある名前のない行（臨時・特別の措置を除いた額とみられる）は使わない。昭和20・30年代の公共事業費の内訳の内訳（(1)(2)…）は上の行に含まれるので入れない。予算の成立日は未取得。

問い合わせ：`python3 scripts/query_db.py 財政の合計`、`python3 scripts/query_db.py 主要経費別 from=2020-01-01 to=2024-12-31`、`python3 scripts/query_db.py 決定 kind=為替 from=2022-01-01 to=2024-12-31`。

照合（2026-10-24 は 362 のうち 362 が一致、不一致 0、照合できない 0）：

- 特別会計：主要経費の足し上げ＝表の「合計」。一致した（会計・表・年度・段階）だけを入れ、不一致のある年度は年度ごと外す。平成24〜27年度の表は「合計」が地方交付税交付金・地方特例交付金・地方譲与税譲与金を含まない（11段階すべてで、差がこの3つの額と円単位まで同じ）。この年度は3つを除いた足し上げと比べて一致とし、checks.csv の備考に書き、DB の合計の行は「合計（地方交付税交付金・地方特例交付金・地方譲与税譲与金を除く）」とする。主要経費の行（3つを含む）はそのまま入れる。
- 国債：「計」＝小計＋各債、「小計」＝4条債＋特例債、発行の無い年度の欄が空、普通国債残高が2つの表で同じ（実績の年度）。平成2・6〜8年度の特例債の欄の（ ）＜＞［ ］書き（臨時特別公債・減税特例公債・震災特例公債）は、特例債を「小計 − 4条債」とし、括弧書きは区分 `国債発行額の内訳` に分けた。
- 地方財政：同じ年度を載せた白書の版どうし（112）と、fetch_fiscal.py の取り込み（2018年度〜、42）。推移の表の「国庫支出金」は交通安全対策特別交付金等を含む（表の注、年に約500億円多い）ので、`国庫支出金（交通安全対策特別交付金等を含む）` として分けた。
- 骨太の方針の閣議決定日：一覧の題名から読んだ日と、fetch_fiscal.py が PDF の1頁目から読んだ日（12年分すべて一致）。
- 数値目標：AI の読み手2系統（Haiku）。系統A は本文を通読、系統B は「目指す・目標・までに・達成・黒字化…」で行を探して前後を読む。目標値・単位・目標年が同じで、両系統の原文がどちらも全体のまま本文に有り（「…」で略した原文は前後の片がこの順で有る）、本文の中で見つかった範囲が重なり、目標値が単位つき・数字の境目つきで（「３割」「全て」「ゼロ」を含む）本文のその範囲にあり、目標年も本文のその範囲かすぐ前（30字）に書かれているものだけ採る。年の別（年・年度）は本文の書き方で決める。「20%台」「1～2%」のような幅のある目標は1つの数で表せないので採らず、「以上・程度・未満」などは単位に残し（「%以上」「兆円超」）、数の前の「約・少なくとも・おおむね」も「万人（約）」のように残す。食い違い（347件）は `.local/fiscal-more/target-disagreements.csv`。読み手の結果か本文が無い文書は前回の行を残す。読み手（AI）は毎朝の更新からは回らないので、本文を取ったのに読み手の結果が無い決定は checks.csv に「照合できない」（国策：数値目標の読み手2系統）として出る（2026-10-24 は 0 件）。骨太の方針 2018・2020 の PDF は日本語フォントを埋め込んでいないので、文字にするには poppler-data（Adobe-Japan1 の CMap）が要る（無いと行番号だけになる。そのときはその決定の本文を置かず（ほかの決定は取る）、結果に「日本語が取れない」と出し、次の回に取り直す）。本文の取得元は `.local/fiscal-more/text/<決定ID>.url` に残し、本文URL が変わったら本文を取り直して読み手の結果を消す（読み手待ちに戻る）。

足すときの注意：一般会計と特別会計を足さない（繰入が重なる。特別会計の額は純計ではない）。国債の stage は数字の性格（決算＝実績、補正＝補正後の見込み、当初＝当初の見込み）で、予算の「補正」（補正による増減）とは違う。国債費はいつも当初予算の額で、一般会計の主要経費「国債費」と重なる。比率（%）は区分 `…の比率`。

問い合わせ：`python3 scripts/query_db.py 特別会計の主要経費別 from=2020-01-01 to=2024-12-31`、`国債 from=2000-01-01 to=2026-12-31`、`地方の歳入`、`国策の数値目標`。

まだ入っていないもの：2012年以前の骨太（国立国会図書館 WARP か官邸の旧ページ）、地方財政計画、日銀・IMF・FRED・BIS（通信先の許可待ち）。

判定：目標年があればその年の値で「達成・未達」、その年がまだ来ていなければ「期限前（到達／未到達）」、終わったのに実績がまだ無ければ「値なし（期限後・実績待ち）」。目標年の無い目標は「期限なし（到達／未到達）」で、届いた年は決定の年から探す。PB の黒字化は0を上回ったとき。実質賃金の「2029年度までの5年間で年1%程度」は、目標年までの5年度の前年度比の年平均で見る（途中は届いた年度までの平均で「期限前」）。成長率・物価上昇率・引上げ率の目標年の無いものは、1年だけの反動で到達としないよう、決定の翌年から最新までの平均で見る。名目GDPの額は目標の年の別に合わせて暦年か年度の系列を使う（年の無いものは年度）。達成の値は目標の単位（「以上・超・程度・（約）」を除く。PB は兆円）。「超」は上回ったときだけ、「程度・約」は目標値以上で到達とする。
